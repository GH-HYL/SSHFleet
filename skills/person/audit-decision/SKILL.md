# 决策工单审计

**用途**：审「只产决定、不产代码」的那类工单（探路地图里 `Type: grilling` 的那些），在它 `Status: resolved` 之后、照着往下写规格之前。

**审的不是决定对不对，是纸面有没有洞。** 决定好不好，只有开发者和实践能判；纸面通不通，机器和人分工审得出来。

**为什么要有它**：这类工单没有现成审计。而它的失效方式很固定——**讨论时都想清楚了，落纸时漏了、写歪了，后面写规格的人照着歪的写**。等发现时，改的是规格与验收，再往后改的是代码。

## 不判

决定该不该这么做、选哪条路、代码怎么写——都不归这里。ADR 有没有出处、与旧篇打不打架归 `/audit-adr`；规格会不会磨掉架构归 `/audit-spec`；实际代码有没有另造一套归 `/audit-quality`。

**「有没有替开发者拍板」不在这里判**——执行者第五问会顺带露出它，但那是副产品，不单列。

## 零、进门：这批是不是决策工单

**判据机械三条，全满足才审**：

- 有 `Type: grilling`（或同类「只产决定」的类型）；
- 有 `## Question` 与 `## Answer` 两节，且 `Status` 已 `resolved`；
- 答案里出现「归 NN 号」「留给别处」这类转交，或引用了 ADR。

**不是 → 一句话收尾，不输出任何问题。** 实施工单归 `/audit-quality`，还没结算的工单归它自己继续谈。

## 一、分工：子 Agent 审纸面，执行者审对话

- **子 Agent 没有上下文**——这既是它的价值也是它的边界。它只看见文字，文字接不上它就一定卡住，正好当那个「第一次读这份东西的人」。
- **它审不出「说定了但没落纸」**——那一问只有执行者答得了，见第六节。
- **不给子 Agent 对话内容。** 给了它就会顺着写的人的措辞读，替他的盲区背书。

## 二、派几个

- **一张工单一个**，审深度：只给它那张工单 + 它那篇 ADR，别的一概不给。
- **再加一个只审接缝**，审横向：给它所有工单的答案 + 所有 ADR 的《决定》节。
- **接缝那个是必须的。** 实践里最有价值的洞（载体缺失、职责数对不上、转交错位）全部出自它——单张审计看不见「两张都对、合起来不对」。

## 三、单张 Agent 的四问

1. **问完没有**：`## Question` 每一条（含「顺带核到一处」这类插问），`## Answer` 有没有正面回答。漏答、答非所问、用「归别处」推掉却没说清推给谁，都算。
2. **出处**：答案里每条结论，指不指得回这篇 ADR 的《决定》《理由》，或 ADR 明确引用的别处。指不回的照实列——那不是错，是「写答案的人自己定的」，但要数清有几条，复审时要看。
3. **判不判得出**：只拿这份答案，能不能说出「什么样算违反这条」。说不出的，写明缺什么才判得出。
4. **与 ADR 一致**：答案有没有多出 ADR 没有的、漏掉 ADR 有的、或与 ADR 说法不一致。

## 四、接缝 Agent 的四问

1. **互斥**：哪两张的哪两条字面不能同时成立。必须写出「照字面执行会撞在哪」，写不出就不算。
2. **转交能不能接**：凡是「归 NN」「留给别处」的，接收方按字面接得住吗——指向的地方存不存在、职责对得上吗（把设计选型推给一个只管机械校验的工单，就是接不住）。
3. **链上空白**：所有工单合起来，从头到尾有没有哪一段没人答。
4. **同一件事被定了两次**：两种说法，或两次规定但口径不同。

## 五、硬规矩

- **每条结论必须指到「哪个文件、哪一句」**；指不到的一律驳回。
- 子 Agent **只读指定文件**，不许读工单以外的（它会拿别处的结论当真相）。
- 子 Agent **不评价好坏、不给改法**，只报事实缺口。给了改法，讨论就被它带偏。
- **预留驳回预算**：子 Agent 会误读（把「两个站两件事」读成「重复定」这类）。误读照原文驳回，不丢人，但必须写进报告——否则下一轮会再报一遍。

## 六、执行者的第五问：对话落差

逐条对着 `## Question` 问：**这条在讨论里说过什么，纸上落了没有。**

三种落差最容易漏：

- **原话被改写，改写后没留痕**。原话一个意思、纸上一个更精确的说法——精确没问题，但两处都没写「这俩是一回事」，读的人得自己拼。
- **当场认下的代价没写**。讨论时说「这个我认」，纸上只留了「不建议那样」，代价本身丢了。
- **两篇之间的代价口径不一致**。同一件事一处算代价、一处不算。

## 七、处置与报告

- **洞**（纸上缺东西，不是措辞）→ 改决定，并留档（进 ADR，或写进工单补记）。
- **说法不齐** → 只改措辞与指向，**决定文字一个字不动**。
- **驳回** → 写清理由。
- **报告五节，顺序固定**：真洞 / 说法不齐 / 驳回 / 执行者自审 / 处置。洞在前，因为它要改决定；驳回也要写，它是下一轮的免报清单。
- **数字要数得出来**：几条洞、几条不齐、几条驳回。展示只给结论，逐条明细写进报告文件。

## 八、代价

一趟四个子 Agent，三张工单十几分钟。

换来的是「纸上没有洞」。这个代价比等写规格时才发现便宜得多——那时候改的是规格与验收，再往后要改代码。
