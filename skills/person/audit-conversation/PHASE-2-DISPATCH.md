# 二、分发

> 全局约束与段间导航见 [SKILL.md](./SKILL.md)；本文件只讲本段做法。

## 2.1 分三路

**三份提示词都带这句**：只报问题，不给修法，不排优先级。

按侧重点分三路，每路读整段对话、只答自己那一个问题。**拆的是问，不是对话**——按时间切段，谁也判不出变轨点。

## 2.2 提示词写死四样

每路的提示词写死四样：只读分析、会话导出在哪、截止到哪条、受众是谁；判据指到 `PHASE-1-SURVEY.md` 的哪一节，不抄条文。子 agent 看不到本轮对话。

## 2.3 三路细则与先后

| 路           | 判据      | 报告要什么                                                                                    | 什么时候派       |
| ------------ | --------- | --------------------------------------------------------------------------------------------- | ---------------- |
| **A 时间轴** | Q1        | 变轨点（第几轮 → 原来定的 → 改成什么 → 依据）；最终结论清单（编号 + 一句话 + 依据）        | 先派             |
| **B 出处**   | Q2、Q3    | 逐条：文档位置 → 文档写的 → 依据（U几 / 原话）                                              | A 的回执到手后派 |
| **C 查漏**   | Q4 + 受众 | 该在而没在（约束性原话 → 文档没有 → U几）；不该在而在（混进来的过程、沿革、推断、机器视角） | 与 B 并行        |

A 的回执是后两路的坐标：哪句是最终结论、第几轮变的，都以它为准。
