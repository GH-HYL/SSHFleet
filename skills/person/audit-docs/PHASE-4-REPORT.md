# 四、汇总

> 全局约束与段间导航见 [SKILL.md](./SKILL.md)；本文件只讲本段做法。

回执只做收集、不许改论述；这一段是主观活——挑哪些、怎么并、哪几条要开发者拍板，都由执行者判断。

**第一段：核查结果归拢。** 这一轮做过哪些考证、测试，为什么做、结论是什么，哪些判断被推翻又重验过。**输出到终端，不落盘。**

**第二段：已定的缺陷。** 执行者自己能拍的：事实错误、引用了不存在的东西、边界被破坏、该删的废话。逐条列全，不展开。**输出到终端，同时落本次审计目录暂存。**

**第三段：要开发者定的事。** 说法打架的、有歧义的、取舍拿不准的。**用 `/my-grill` 问，问题不落盘。**

**顺手记一行卡点**：这一轮技能本身哪里不顺手（哪条规矩没落地、哪处写漏了），写到本次审计目录的 `卡点.md`，下次改技能时用。
