# 选择并说明

把一次决策摆成**几条路**，每条给出原因与代价，标出推荐哪条。

**一轮的形状**：

```
**问题**：<要定的是什么>

**A. <这条路一句话>**
- 原因：<为什么是它，对着当前问题说>
- 代价：<选了要付什么、放弃什么>
- <代码、命令、配置片段——服务于这条路的才写>

**B. ……**

➡️ 推荐 <X>：<一句话理由>

**还没说定的**：<影响这次选择、你还没交待的事>
```

- **路数跟着问题走**：两条就两条，四条就四条。
- **代价一栏不许空**：说不出代价，说明这条路还没想透。
- **代码按需给**：有实现差异才附，纯取舍不给。
- **一次把能问的都问出来**，编号列出。
- **答案依赖未定项的问题留到下一轮**，别替开发者猜。
- **事实自己查**：选项、代价、代码都去找；查不到就说查不到，别编一条路撑场面。
