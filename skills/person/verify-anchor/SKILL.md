# 验锚

**用途**：ADR 定稿前，试它撑不撑得住后面每一道工序。只有一个判法——**下游每道工序要从这里拿走什么，这里有没有**。缺一样，那道工序就会自己发挥。

**不判**：决定好不好、该不该这么做。那是开发者的判断，不外包。

**前提**：在写 ADR 的那个会话里跑，原话只活在那个上下文里。已被本 ADR 后文作废的段落、标了 superseded 或部分作废的部分，不判——只判当前生效的文本。

## 下游要什么

判据清单，不是流程。

- **重写规格**：决定 + 范围边界。缺边界，规格会把「不做的事」写成待办。
- **发工单**（无判法）：一条决定能不能切成几片独立可验的活。切不开，工单退化成流水账。
- **implement**：seam（调用方与测试跨过的那个面）与禁止路径。缺了，AI 自己挑面、自己发明格式。
- **逐笔复查**：每笔提交对得上哪条决定。缺了，夹带查不出来。
- **质量审计**：可判定的判据 + 定死的词。缺了，只能靠「同一形式出现两处」反推。
- **合并**（无判法）：不可逆动作与回滚条件。缺了，合错退不回来。

「发工单」与「合并」两条没有判法：前者要看工单怎么拆，后者要看代码里有没有不可逆动作，而本技能不读代码。碰上就写「需开发者判」，别编。

## 一、出处

ADR 由 AI 在约束下生成。风险不是写得差，是**把一句模糊的话写成一条精确的决定，而精确的方向由它选**。

- 它标了哪句原话。没标 = **无出处**。
- 标了的，核那句原话是否真支撑这条决定。**原话支持方向，不等于支持具体选择**——「按你推荐目标」支持的是方向，落成哪个数还是它选的。
- 「执行者提议，作者未反对」算出处，但强度低于「作者选定」——这一档要在输出里单列，不能和拍过板的混在一起。

## 二、判得动

先分叉：**结构决定**（模块、接口、落点、谁独占某个形式）过四问；**行为决定**（做不做、什么时候做、报什么）只过第一、第四问——第二、第三问问的是接口与抽象，行为决定没有这两样。

**一、能不能写成「某形式只许一处出现」？** 写不出 = 愿望，没有判据。

**二、它定的东西落在哪个 seam 上？** 说不出调用方从哪儿进来、拿到什么 = 面没定。

**三、删掉它，复杂度消失还是散到调用方？** 消失 = 白加一层。

**四、它的违反长什么样？** 写不出具体样子 = 太软，可以表面遵守、实质绕开。

**补法必须对应所报的那一问。** 报第二问却拿第一问的答案补，两问都不算过。

## 三、词

新造、改义、退役的词各列一行。词表归 `grill-with-docs` 维护，本技能只列不写；写入另开工作，等授权。

## 输出

**先报总数**：第一行写「共 N 条决定」。判完再对一次，对不上就是漏了。

N 数不出来时（「## 决定」下面一段散文，一句里含两个决定），按分句拆开计；拆不开就报「决定边界不清」，别硬凑一个数。

```text
共 N 条决定

#<编号> <决定原文，照抄>
  无出处：<哪句原话都没对上>
  出处偏弱：<原话摘要>——执行者提议，作者未反对
  判不动：<缺哪一问> → <补一句什么就能判>
  下游缺口：<哪道工序拿不到东西>
  词：<新增 / 改义 / 退役>
```

前两行互斥：有出处就不写「无出处」，弱出处按「出处偏弱」写，别并进前者。

**一条一轮**：只带这一条的原文和判据，判完落一行，再读下一条。

某项无问题写「无」。**不改写原文**——改写之后就不是开发者的决定了。**不用未解释的术语**：说「别处自己拼 `[y/N]`」，不说「违反 single-writer 不变量」。

末尾：共 N 条；无出处 A（含出处偏弱 E）；判不动 B；下游缺口 C；词 D。

对账：N 对决定条数，A 对「无出处 + 出处偏弱」的行数，C 对「下游缺口」出现次数，D 对「词」列了几行。

## 边界

- 不评价决定内容，不建议替代方案——那是选题，不是复查。
- 不产出内容，只报缺口。
- 不读代码、不跑测试，此时还没有代码。
- 只在决定段定稿后、授权开工前跑。开工之后判代码，归质量审计。
