# 验锚

**它只做一件事：把 ADR 跟这次会话对一遍。** 会话一关就没了——后置审计手上只有 ADR、spec 和代码；而写这篇 ADR 的那套上下文正在这里，也只有在这里。

**不是「再想一遍」。** 同一套上下文再判一遍，只会得到同一个判断。所以判的办法是**指位置**：原话引得出来、关联 ADR 指到哪一节、spec 指到哪一段。指得到的才算核过；指不到的照报，写「指不到」——指不到本身往往就是缺一处依据。

**前提**：思路已对齐、决定段写完、还没说「授权开工」，且在同一会话里。判前先看「更新记录」放了哪几条——被本篇后文作废的、标了部分作废的那部分不判。

**走法**：锚与软**逐条**过，只带这一条的原文，别一次读全篇——整篇一起看，两条互斥会被读成「两条都对」。打架留到最后统一看，那时才需要同时拿着全部决定。漏是最后拿会话反查一遍。

**不判**：决定好不好、该不该这么做、接缝选在哪儿、代码对不对。那些归选题、规格与后置审计。

## 一、锚

每条决定都要指得回一处：作者原话、既有 ADR 的某条、本次会话说定的某句。**指不回去的，就是执行者替作者做了决定**——这是 AI 写 ADR 唯一的失真方式，也是这个技能存在的理由。

- 没指 = **无锚**。
- 指了的，核那处是否真支撑这条。**原话支持方向，不等于支持具体选择**——「按你推荐目标」支持的是方向，落成哪个数还是它选的。
- 「执行者提议，作者未反对」算锚，强度低于「作者选定」。这一档单列，不和拍过板的混在一起。
- 事后补出来的锚（「就按刚才说的」）多半是「补成这句」：写决定的是执行者，点头的是作者，照样按弱锚记。

## 二、打架

- **同篇互斥**：两条决定一处要求、一处禁止。单看都可判，并列起来照字面执行必然错一处。
- **跨篇抵禁令**：既有 ADR 里点名不许做的事，与本篇字面或实质相同。旧 ADR 一句「别干这种活」，新篇不提就等于默认放开。查本篇声明过「关联」的那几篇，**还要查会话里提到过、正文引用过的**——出事的那几篇往往正是没被声明进去的，声明清单当不了范围。
- **管辖空洞**：同一处两篇都不覆盖，将来谁判。留白 = 谁都能讲通。

## 三、软

**每条都要能写出一条违反它的具体样子。** 写不出 = 太软：表面遵守、实质绕开都能过，审计只能靠猜，猜出来还得人裁。结构决定与行为决定同一问，不分叉。

## 四、漏

对着这次会话数一遍，看有没有该成为决定却没落的：

- 说定了的边界，尤其「不做」
- 决定里出现删除、覆盖、迁移、一次性变更时，有没有写清回滚，或写明「不可逆、先留退路」——缺了，合错退不回来
- 讨论中被否掉的选项——否掉的理由不显然时，不落就没人记得为什么不行
- 当场定死的词

**漏掉的决定不会出现在决定段里**：条数永远数得出来，漏的第 N+1 条数不出来。

## 输出

**判了几条就出几条，没问题的写「无」。** 省掉的条目会被读成没判过。问题多时可以按「要人裁的」排在「补一句就行的」前面，但排序不许代替完整——排到最后没写，就是漏。

**每条缺口后面说「补哪一类东西」，不写具体句子。** 写了句子，这条决定就是执行者起的草、作者只点头，出处照样是弱的。

**一段散文里含两条决定时，报「边界不清」。** 不是嫌它没编号——是下游没法单独指认这一条，逐笔复查对不上，审计也说不清违反的是哪条。

```text
#<编号> <决定原文，照抄>          ← 有节号用节号，没有的照抄首句
  无锚 / 弱锚：<原话或出处哪一处>——执行者提议，作者未反对 ｜ 补：<缺哪一类>
  互斥：与 #<编号>｜ADR-NNNN「<哪一句>」
  管辖空洞：<哪一处将来没人判>
  太软：写不出违反的样子 ｜ 补：<补哪种反例>
  不可逆没写退路：<哪一步>
  词：<新增 / 改义 / 退役>

漏：<会话里说定、决定段没落的>（原话：<引得出来的那一句>）
```

**不改写原文**——改写之后就不是开发者的决定了。**不用未解释的术语**：说「别处自己拼 `[y/N]`」，不说「违反 single-writer 不变量」。

## 边界

- 不评价决定内容，不建议替代方案——那是选题，不是复查。
- 不产出内容，只报缺口。判不了的写「判不了」，别编一个像判过的结论。
- 不读代码、不跑测试，此时还没有代码；开工之后判代码，归质量审计。
- 词表归 `/domain-modeling` 维护，本技能只列不写；写入另开工作，等授权。
