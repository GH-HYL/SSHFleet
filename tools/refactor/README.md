# 重构期临时追踪（用完即删）

**这份目录是专门给「新工程建站」这次重构用的临时追踪文件，重构完成（阶段 10 切换之后）连同 `.gitignore` 里那段白名单一起删掉。** 它不属于要交付的工程内容，正常代码与文档都不该引它。

为什么它在版本库里：2026-11-02 开发者要换到 Ubuntu 开发环境，`build/` 下的沙盒不进版本控制、换机器就没了，而下面两样东西重建一次不划算。所以把它们从沙盒里拎出来，按开发者的话「在忽略文件里加白名单」带过去。

## `ab.sh` —— 新老两版参数矩阵比对

同一组 argv 分别喂给新老两个二进制，比 `stdout`／`stderr`／退出码，归一程序名与版本行。阶段 03 用到的那一版是 39 例：35 逐字同、5 认下（`KNOWN_EXPECT` 里逐条写着为什么）、0 真差异。阶段 09「逐字比对」还要接着用它，每个阶段交付前也拿它过一遍。

用法：**拷进沙盒根目录**（沙盒里要有老版二进制、新版二进制与一份 `run/config/`），然后：

```bash
./ab.sh                                   # Windows：二进制叫 *.exe
AB_OLD=../sshfleet_old AB_NEW=../sshfleet2 ./ab.sh   # Linux：没有后缀
```

认下的新差异往 `KNOWN_EXPECT` 加一行「标签|为什么」，并在那一阶段议题里记一句来历——否则下一个人会把认下的差异当成回归。

## `eawgen/` —— 终端显示宽度区间表生成器

`modules/SSHFleet2_Go/internal/message/width.go` 里那 120 段东亚宽区间，是这个 23 行的小程序从老工程同版 `golang.org/x/text`（v0.42.0）逐字符扫出来的。生成器单独一个模块（`module eawgen`），不并进主工程的 `go.mod`——主工程零第三方依赖这条不动它。

```bash
cd tools/refactor/eawgen && go run .
```

产物贴回 `width.go` 的表里；`ranges.txt` 是那一次的产物留档（与表同形），换 `x/text` 版本时拿它对差异。
