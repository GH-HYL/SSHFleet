================================================================================
SSHExec GUI 工具设计方案 (Windows)
================================================================================

一、设计目标
-------------------------------------------------------------------------------
基于现有 sshexec.py 核心逻辑，使用 Go 语言开发 Windows 原生 GUI 工具，实现：
1. 图形化参数配置（完全替代命令行参数输入）
2. 严格的参数互斥与校验（逻辑对齐 core.py）
3. 后台静默执行 Python 脚本
4. 实时捕获并展示标准输出/错误流
5. 执行结果的统计与可视化展示

*注：本工具仅负责前端交互、参数组装与进程调度，不修改后端 Python 执行逻辑。*

三、界面布局详细设计
-------------------------------------------------------------------------------

1. 模式选择区 (互斥单选)
-------------------------------------------------------------------------------
[模式选择] ---------------------------------------------------------------
○ 执行命令 (-c)   ○ 执行脚本 (-s)   ○ 上传文件 (-u)
○ 下载文件 (-d)   ○ 打包日志 (-z)

规则：
- 五选一，严格互斥。
- 切换模式时，下方参数表单即时刷新。

2. 参数配置区 (动态表单)
-------------------------------------------------------------------------------
[通用参数] ---------------------------------------------------------------
CSV 节点文件:  [ C:\nodes.csv          ] [浏览...]
备注信息:      [ 自动生成/手动修改     ]

[条件参数 - 根据模式动态显示] ----------------------------------------------

► 命令模式 (-c) 选中时:
   远程命令:
   +---------------------------------------------------+
   | ls -l && echo "hello"                             |
   +---------------------------------------------------+
   环境变量:    [ PATH=/usr/bin:$PATH ] (可选)
   执行权限:    ○ direct    ● sudo

► 脚本模式 (-s) 选中时:
   本地脚本:    [ C:\scripts\deploy.sh ] [浏览...]
   执行权限:    ○ direct    ● sudo

► 上传模式 (-u) 选中时:
   本地路径:    [ C:\local\data         ] [浏览...]
   远程路径:    [ /opt/remote/          ]

► 下载模式 (-d) 选中时:
   远程路径:    [ /var/log/app.log      ]
   本地目录:    [ C:\downloads          ] [浏览...]

► 打包模式 (-z) 选中时:
   [提示] 打包模式无需额外参数，将自动打包历史目录中最新的日志。

3. 高级参数 (折叠面板)
-------------------------------------------------------------------------------
▼ 高级参数 ---------------------------------------------------------------
├─ 连接超时 (-T): [ 10  ] 秒
├─ 执行/传输超时(-t): [ 60  ] 秒 (注：上传/下载默认300)
├─ 并发数 (-n):   [ 0    ] (0=自动=节点数)
├─ 私钥路径 (-k):  [ ~/.ssh/id_rsa ] [浏览...] (留空=不使用)
├─ 环境变量 (-e):  [ 可选，仅命令/脚本模式 ]
└─ [√] 禁用交互确认 (--disinteractive)

4. 执行控制与输出区
-------------------------------------------------------------------------------
[执行控制] ---------------------------------------------------------------
[ 开始执行 ] (绿色)  [ 停止执行 ] (红色)  [ 清空日志 ]

[ Yes ] 输入y并回车
[ No ]输入n并回车
[实时日志] ---------------------------------------------------------------
+-----------------------------------------------------------------------+

| [12:01:04] SUCCESS: 执行成功                                           |
| total 12                                                              |
| -rw-r--r-- 1 user user 123 Apr 15                                     |
| [12:01:05] INFO: 节点 192.168.1.10 完成                               |
+-----------------------------------------------------------------------+


四、参数校验与业务逻辑 (对齐 core.py)
-------------------------------------------------------------------------------

1. 互斥规则
-------------------------------------------------------------------------------
模式        必须参数               互斥规则
-------------------------------------------------------------------------------
-c       -f, -c               不可与 -s/-u/-d/-z 共存
-s       -f, -s               不可与其他模式共存
-u       -f, -u, -p           不可与其他模式共存
-d       -f, -d, -p           不可与其他模式共存
-z       无                   必须单独使用，不可带任何其他参数

2. 路径与输入校验
-------------------------------------------------------------------------------
- 路径处理: 自动去除首尾空格；支持绝对/相对路径。
- 私钥 (-k): 
   - 勾选但未指定路径 -> 默认 ~/.ssh/id_rsa。
   - 若默认路径文件不存在 -> 视为不使用私钥。
- 备注 (-r): 
   - 未填写时自动生成（命令取首词，脚本/文件取文件名）。
   - 自动过滤非法字符 (/:*?"<>|\)。

3. 默认值策略 (读取 config.toml)
-------------------------------------------------------------------------------
参数       默认值来源
-------------------------------------------------------------------------------
-m        config.execution.mode (默认 direct)
-t        config.execution.timeout_execute (命令/脚本) 
          或 config.execution.timeout_transfer (上传/下载)
-T        config.execution.timeout_connect
-k        config.execution.private_key
端口/用户  config.account.port / config.account.user
密码       若 CSV 为空，优先使用 config.account.password (Base64解码)

五、执行流程
-------------------------------------------------------------------------------
1.  UI 收集输入 -> 2. 前端校验 (必填/互斥) -> 3. 读取 TOML 配置 ->
4.  合并默认值 -> 5. 组装命令行参数 -> 6. 启动后台进程 (os/exec) ->
7.  Pipe 捕获 stdout/stderr -> 8.  实时转发至 UI 文本框 ->
9.  等待进程结束 -> 10. 解析退出码/日志 -> 11. 展示统计结果

六、命令行组装示例
-------------------------------------------------------------------------------
# 命令模式
python3 sshexec.py -f nodes.csv -c "ls -l" -m sudo -T 10 -t 60 -n 5

# 上传模式
python3 sshexec.py -f nodes.csv -u C:\local\app -p /opt/app -t 300

# 打包模式
python3 sshexec.py -z

七、技术选型 (Go + Windows)
-------------------------------------------------------------------------------
层级          推荐方案
-------------------------------------------------------------------------------
GUI 框架      Fyne (首选，跨平台，原生Windows外观，易分发)
备选          Gio (现代UI) / GTK3 (成熟但依赖重)
进程调用      os/exec (标准库)
输出捕获      StdoutPipe / StderrPipe
配置解析      github.com/pelletier/go-toml/v2
日志渲染      TextView + 等宽字体 (Consolas/Menlo)
打包分发      Fyne CLI (fyne package) 或 UPX 压缩

八、UI/UX 优化建议
-------------------------------------------------------------------------------
1. 布局: 采用卡片式 (Card) 分割区域，视觉层次分明。
2. 控件: 模式切换使用 RadioGroup；路径输入框统一右侧配 [浏览] 按钮。
3. 反馈: 输出区使用等宽字体；成功日志(绿)、错误(红)、警告(黄)。
4. 按钮: 开始(绿)、停止(红)，状态明确。
5. 防呆: 参数非法时，[开始执行] 按钮置灰，Hover 提示原因。
