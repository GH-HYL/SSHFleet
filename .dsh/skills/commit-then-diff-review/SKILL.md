# 提交后 diff 复查

改完直接提交，不先汇报。提交时用 `git add -p` 挑这一轮的改动，别整目录加。

提交后看 `git show` 的 diff，逐条对回本轮要求：

- 每处改动能说出对应哪条要求
- 没有夹带：顺手的重构、格式化、改注释都算
- 没有漏的要求

对不上就改，amend 后再看一遍。

**算做完**：diff 里找不出一处说不出对应要求的改动。

## 边界

- 只核这一笔提交对不对得上本轮要求，不写审查报告——要分轴出报告用 `/code-review`。
- 对不上又改不了的（要求本身写错了），停下来问，别默默留着，也别在提交信息里糊过去。
