# diff 复查

要核的是这一轮改动所在的那笔提交——刚提交的，或早先某笔。

自己提交时用 `git add -p` 挑这一轮的改动，别整目录加。

看那笔提交的 diff（`git show`，不给参数就是 HEAD），逐条对回本轮要求：

- 每处改动能说出对应哪条要求
- 没有夹带：开发者本轮明确提到的除外；要抓的是那些没提过、也没说明过就自己改的——顺手重构、格式化、改注释都算
- 没有漏的要求

对不上就改。改的是自己刚提交的那笔才 amend，先 `git log -1` 确认 HEAD；已前移或不是自己那笔，就另起一笔。改完重看一遍 diff。

**算做完**：diff 里找不出一处说不出对应要求的改动。

要求本身写错了、改不动的，停下来问，别默默留着，也别在提交信息里糊过去。
