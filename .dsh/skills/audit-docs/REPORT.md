# 汇总给开发者：三段式

本附件是**收尾规程**：回执落盘之后，怎么把它们讲成一份给开发者的回复。轴与判据在本体 `SKILL.md`。

回执只做收集、不许改论述；这一步是主观活——挑哪些、怎么并、哪几条要他拍板，都由你判断。**直接输出到终端，不另存文件。**

## 第一段：我怎么核的

核查完之后的总结，让他看到你怎么想的：查过什么、哪些判断被推翻、还有什么没把握。

## 第二段：已定的缺陷

你自己能拍的：事实错误、引用了不存在的东西、边界被破坏、该删的废话。列出来，让他知道都有什么事。

## 第三段：要你定的事

要他拍板的都在这里：说法打架的、有歧义的、取舍拿不准的。**用 `my-grill` 问。**
