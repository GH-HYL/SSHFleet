# 汇总给开发者：三段式

本附件是**收尾规程**：回执落盘之后，怎么把它们讲成一份给开发者的回复。轴与判据在本体 `SKILL.md`。

回执只做收集、不许改论述；**收尾**是主观活——挑哪些、怎么并、哪几条要开发者拍板，都由执行者判断。

## 第一段：核查结果归拢

核查完之后的汇总：查过什么、哪些判断被推翻、哪些又验证了一遍。只讲这一轮干了什么；已定的缺陷与拿不准的留给后两段，本阶段不必提及。**输出到终端，不落盘。**

## 第二段：已定的缺陷

执行者自己能拍的：包括但不限于事实错误、引用了不存在的东西、边界被破坏、该删的废话。逐条列全，不展开——这是开发者后续整改的依据。**输出到终端，同时落本次审计目录暂存。**

## 第三段：要开发者定的事

要开发者拍板的都在这里：说法打架的、有歧义的、取舍拿不准的。**用 `my-grill` 问，问题不落盘。**
