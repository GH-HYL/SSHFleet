# 大型重构全面审计

对一次**大面积重构**（多提交、多包、决策散在 ADR 与议题文档里）做多轴并行审计。主 Agent 只做摸底、分发、仲裁、聚合，不亲自审；每条轴一个子 Agent，文件域互不交叉。

**与 `/code-review`、`/docs-review` 的区别**：那两个审「一次 diff」的标准与规格符合度；本技能审「一次重构」——范围大到单轴装不下，且议题文档里充斥实施层主张（怎么修、行号、清单），**不能当审计基准**，必须以 ADR 大方向为纲、把议题文档本身也当被审对象。

## 一、摸底（主 Agent 亲自做，产出审计的输入）

1. **议题与决策**：读议题目录（spec、audit/摸底清单、工单）与关联 ADR。**把 ADR 的「决定」逐条抄成「大方向锚」**——这是发给每个子 Agent 的基准，防止他们被议题文档里的具体修法带偏。
2. **git 范围**：`git log --oneline` 前后翻找，从议题自述的摸底基准（如 audit.md 写的「摸底基准 cfb7ecc」）到 HEAD；用 `git show --stat` 确认主提交的文件面。用户没说范围就自己定，并说明理由。
3. **结构**：代码落点（哪个模块目录）、复现环境（有无现成测试机/账号）、交付约定（如哪个文件允许写 file:line）。
4. **识别议题文档的不可靠部分**：摸底清单里的行号、计数、「具体怎么修」全是**实施层主张**，审它们是否属实，而不是拿它们当标准答案。

## 二、切轴（每轴一个子 Agent，文件域白名单隔离）

按包/层切，典型切法（按重构实际调整）：

| 轴 | 审什么 |
| --- | --- |
| 架构 | 报文/常量等唯一定义落点是否最优、依赖方向、层级边界（执行侧不下结论/判定层不起名）、窄接口、调用链 |
| 执行侧（按摊拆多轴） | 每摊的生成点穷尽性、错误类型是否 errors.As 先于原文识别、追加不覆盖不变量、取消/中断路径 |
| 判定/核心层 | 旧常量删净否、唯一例外之外的给名点、次序抢占、语料/用例覆盖缺口 |
| 配置 | 关键词与实际产出**一一映射**（多出=认领永不产生的、遗漏=永远未归类，后者最重）；顺序；退役条目撤净否 |
| 呈现层 | 无译文层/前缀摘除、回落口径、统计口径、自有文本的界 |
| 测试与真机复现 | 构建/vet/全量测试 + 按场景分账号真机复现，先梳理复现方案再执行，跑不通如实记，**不许编造结果** |
| 文档三轴 | 借 `/docs-review`：一致性（ADR「不再约束」的句子清干净否）、事实准确性（行号/计数逐个回源码数）、规范符合度 + 根 README/手册/CHANGELOG 是否同步 |

隔离手段：每个提示词写明**文件域白名单**（明确「不碰 X，那归另一轴」）；跨轴疑点不子 Agent 间互传，回主 Agent 仲裁。

## 三、每份子 Agent 提示词的固定件

1. **大方向锚**：ADR「决定」的浓缩条目（编号），开头一句「以此为准，不要被议题文档里的具体修法带偏」。
2. **授权声明**：「只做只读分析，本轮未授权开工，不得修改任何文件」（按 AGENTS.md，子 agent 指令里没有授权句一律按未授权处理）。跑构建/测试的轴另写：临时产物只落 `build/`。
3. **文件域白名单** + 对照的议题文档章节。
4. **报告格式**：每条发现给 文件:行号 + 证据（命令/原文），区分【硬伤】（事实错误、边界被破坏）与【判断题】（可权衡，说明理由与代价）；没发现的轴明说「未发现问题」，不许凑数；限字数。

## 四、真机复现的分工

- 允许直接复现时，**按场景分账号**，避免多 agent 同账号互相打架；明确禁危险操作（如 `wsl --shutdown`）。
- 复现环境信息从议题文档抄（通常记在摸底清单里），账号密码原样下发。
- 复现 Agent 的行为异常回主 Agent，路由回对应实现轴定位。

## 五、仲裁与聚合（主 Agent）

1. **跨轴矛盾自己读源码裁**，不信任何一轴的转述（两轴对同一行结论相反是常事——各自只核了自己关心的那份）。仲裁结论记入汇总。
2. **提交信息/议题文档与实现不符**的事实问题转文档轴核对（CHANGELOG/手册有无同句）。
3. 聚合按「架构 / 实现 / 复现 / 文档」分节，**不合并不重排**，各条保留轴来源与硬伤/判断题标签；结尾一行：各节计数 + 各节最重的一条。
4. 【硬伤】一律列出修复方向；【判断题】交开发者拍板。

## 边界

- 只审计。修复、补语料、改文档都等开发者授权，另开工作。
- 议题文档「怎么修」的部分被审，但**审计思路不得被它塑造**——轴的切法来自代码结构与 ADR 层级，不来自工单的施工顺序。
- 不预设仓库结构；摸底查到什么用什么。
