# 三、收集

> 全局约束与段间导航见 [SKILL.md](./SKILL.md)；本文件只讲本段做法。

## 3.1 落盘

每收到一路完整回执，就排成一份文件落盘，不等其他路，也不做跨路合并。

## 3.2 等回执

**盯着各轴的回执**。某轴迟迟不到，接着等就是：子 agent 还在后台跑，主 agent 结束本轮就行，回执传回会自动唤醒它，不用守着，也别替它提前收工。真卡住了，开发者会来说。

## 3.3 目录与整理规矩

目录：`build/audit/<年月日时分秒>-<审计概述>/`

- `时间轴.md`
- `出处.md`
- `查漏.md`

**允许排版**——分节、小标题、列表、代码块、表格；**不许改论述**——不删句、不改口径、不替它把话说轻或说重、不补它没说的结论。**只汇总，不决策。**

`build/` 不进 git；除非开发者明说要留，不必归档。
