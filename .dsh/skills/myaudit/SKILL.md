# audit

**一切以本仓库的审计标准为准，本文件只做入口。**

执行前 **MUST 先完整读**：

`docs/agents/audit-framework.md`

- 三个问句（是不是事实 / 是不是该说的 / 能不能被下一个人接走）
- 六个维度（事实、结论、形式、内容、一致性、可执行性）
- 结论表格式与严重度档位
- 四条边界（只提结论不改文档、观感类不算缺陷、拿不准标「待作者确认」、范围外只报告）

以上全部照该文件执行，此处不重复。

## 执行要点

1. **事实必须实核**：文档里的 file:line、命令、提交号、版本号逐一对，能对上才算；不许只看文档自述。
2. **结论落点**：写进**被审文档**的 `## Comments`（或按作者要求独立成报告），格式严格按标准的结论表，一条一条，不许合并成一句总评。
3. **审计者签名**：写明哪个 agent、哪一轮、针对哪个提交。
4. **未验证项明写**：因环境、权限、时间没查成的，单独列出，不隐去。
