# 三、收集

> 全局约束与段间导航见 [SKILL.md](./SKILL.md)；本文件只讲本段做法。

## 3.1 回执落点

**子 agent 直接写自己的回执文件**，落本次目录的 `回执/`，一轴一份，文件名带轴号；复核员的也放这里，分发审的缺口另落 `分发缺口.md`。返回文本可以简略，完整证据在文件里。`回执/` 与 `分发缺口.md` 只读。

## 3.2 等回执

**盯着各轴的回执**。某轴迟迟不到就接着等，别替它提前收工；真卡住了，开发者会来说。

## 3.3 跨轴矛盾

**跨轴矛盾不在子 agent 间互传**，一律回主 Agent 核实：自己读源码核过的，写明是自己核的、怎么查的；核不了的进第三段交开发者定。
