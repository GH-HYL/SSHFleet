# Triage 标签

相关技能用五个标准分诊角色来表达状态。本文件把这些角色映射到本仓库 issue 载体中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| ------------------------- | -------------- | ---- |
| `needs-triage`            | `needs-triage`    | 待维护者评估 |
| `needs-info`              | `needs-info`      | 等待提出方补充信息 |
| `ready-for-agent`         | `ready-for-agent` | 描述完整，可交给 AFK agent 执行 |
| `ready-for-human`         | `ready-for-human` | 需人工实现 |
| `wontfix`                 | `wontfix`         | 明确不做 |

当某个技能提到某个角色时（例如「打上 AFK-ready 分诊标签」），使用本表中对应的标签字符串。

需要改用其他词汇时，直接编辑右侧一列即可。
