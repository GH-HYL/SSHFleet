# 触发词表

**口述表里的词，就用对应技能，不必等斜杠。** 审计、交接这类大动作由开发者自己敲，不进表。

| 触发词 | 技能 | 备注 |
| --- | --- | --- |
| 授权开工 | `/implement` | 有 spec 或工单才走它，没有先问一句 |
| 拷问 | `/my-grill` | 先按 `/grill-with-docs` 推进，每问四段 |
| 落规格 / spec | `/to-spec` | 不问话，直接综合已有对话 |
| 工单 | `/to-tickets` | 规格定了才拆 |
| ADR / 决策 / 词表 | `/domain-modeling` | 词表、ADR 模板与读法都在这 |
| 复查 / 核对 | `/commit-then-diff-review` | 交付之后由开发者提出来才做 |
| 两轴审查 | `/code-review` | `implement` 自带的那道，不靠口述触发；要单独用请敲斜杠 |
| 写测试 / tdd | `/tdd` | 一次一片，先红后绿，接缝上测 |
| 缺陷 / bug | `/diagnosing-bugs` | 先建复现回路再动代码 |

表里写的是技能名。**上下文里识别不到某个技能，立刻中断会话并汇报。**
