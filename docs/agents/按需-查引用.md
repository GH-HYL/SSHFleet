# 查引用

`codegraph` 给的是这一块的形状：符号在哪个文件、谁引用它、它又引用了谁、源码连着上下游一起到手。

索引在 `.codegraph/`，自忽略、不入库。先 `codegraph sync`——索引落后时它答的是旧答案；换机器或工具升级过，用 `codegraph index`（`sync` 不换引擎）。

| 我要 | 命令 |
| --- | --- |
| 不知道符号在哪个文件 | `codegraph query <名字>` |
| 谁引用它 | `codegraph callers <符号>` |
| 它又引用了谁 | `codegraph callees <符号>` |
| 源码连着上下游一起看 | `codegraph node <符号>` |

三样它看不见，回落 `grep -rn '<符号>'`：闭包与局部变量、字段读写、拼出来的名字。
