# 测试环境

两件事常连着做：在本机跑 `go test`（二进制编到哪、临时文件落哪、在哪台机器上编），和连目标节点（手工跑工具、验上传下载、验 `--sudo`、验终端文案）。两半各占一节。

## 跑测试的场地

`go test` 的场地：测试二进制编到哪、临时文件落哪、在哪台机器上跑。手工连工具的**目标节点**另占一节。

### 在哪跑

| 你在 | 要验的 | 去哪 |
| --- | --- | --- |
| Linux（本工作区跑 Ubuntu 26.04） | Linux / bash 语义 | 本机直接跑 |
| Linux | CentOS 7.9 的行为 | Podman 起容器（见下文「目标机」） |
| Windows | Linux / bash 语义 | WSL2；cmd / PowerShell 的输出不是目标机行为 |
| Windows | 编出来的 exe | Windows 本机跑原生 go 编的 exe——WSL 里编的是 linux 版，`path` / `filepath` 按 `GOOS` 在编译期就定死 |

Windows 侧原生跑会多出「软链接特权」与「探针二进制缺 `.exe`」两类假红，还会撞 360 的进程防护，所以测试一律在 WSL 里跑；只有要验 Windows 版 exe 时才回本机编那一份。

开发机本身是 Linux 时，`podman` 用 `~/.local/bin` 里那个包装（rootful，按 tag 补挂载与 IP），别直连 `/usr/bin/podman`。

### 看某条命令的输出

与工具无关，只验 shell 语义：

- Linux 本机：`bash -lc '<命令>'`
- 要 CentOS：`podman exec <容器> bash -lc '<命令>'`
- Windows：`wsl -d Ubuntu-26.04 -- bash -lc '<命令>'`

### 跑集成用例

对象是 `modules/SSHFleet_Go_bak/internal/ssh` 下带 `//go:build integration` 的用例；`go test ./...` 不加载它们。下表是这套的变量；新工程那族在 `modules/SSHFleet2_Go/internal/execute`，变量名以那套代码为准。

| 变量 | 作用 |
| --- | --- |
| `SSHFLEET_TEST_HOST` / `PORT` / `USER` / `PASSWORD` | 缺一个就整批 skip |
| `SSHFLEET_TEST_FULLDIR` | 64MB 卷上的可写目录，填 `/mnt/small64/w` |
| `SSHFLEET_TEST_SUDO=1` | 打开需要提权的两条 |
| `SSHFLEET_TEST_RACE=1` | 并发占盘那条，默认关 |

跑：`go test -tags integration -count=1 ./internal/ssh/`。

### 沙盒：产物与临时文件不出工作区

`go test` 会把测试二进制编到 Go 的临时工作目录再执行。不指走，它就落在 `%TEMP%\go-build…` 或 `/tmp/go-build…`——**工作区外的可执行文件会被 360 静默删除或弹窗拦截**（「程序正在创建文件链接，会绕过安全软件的文件防护」这类），现象是构建莫名失败、跑一半中断、不报原因。

**产物与临时文件 MUST NOT 出工作区**（含 `$TEMP`、`/tmp`、`~/`），一律落 `build/` 下当天的沙盒。沙盒名用「用途_日期」（`gotmp-20261118`）：**不必建完就删**，同一个问题常要验几轮；**清理按天**——只留今天与昨天两个沙盒，更早的整个删掉。**沙盒里常含临时凭据，MUST NOT 进版本库。**

**编译缓存（`GOCACHE`/`GOMODCACHE`）走默认位置**，不必指定——可复用，不是产物。

### 入口：`tools/test.sh`

入口只有这一条。它转进 WSL、把三个变量指到当天的沙盒，参数原样交给 `go test`：

```bash
bash tools/test.sh ./...                                    # 全量
bash tools/test.sh -run TestFoo ./internal/execute/         # 单条
```

在 Git Bash 里直接敲就行（脚本自己判断在 Windows 还是 WSL 里，Windows 那支只做转交）。手工跑时照抄它内部这一段：

```bash
cd modules/SSHFleet2_Go
SANDBOX="$(cd ../.. && pwd)/build/gotmp-$(date +%Y%m%d)"
mkdir -p "$SANDBOX"
export GOTMPDIR="$SANDBOX" TMP="$SANDBOX" TEMP="$SANDBOX"
go test -count=1 ./...
```

- **别用 `git rev-parse --show-toplevel` 取工作区根**：WSL 里以 root 进 `/mnt/c` 下的仓库会被 git 判成 dubious ownership，那条命令交回空串，`mkdir` 当场报 `cannot create directory ''`。
- **`GOTMPDIR` 管 Go 自己的临时工作目录，`TMP`/`TEMP` 管测试进程里的临时文件**（`t.TempDir()` 之类）。只设前一个不够。

## 目标机

工具要连的那些机器从哪来。两条路只在「目标机从哪来」上不同，跑测试与产物的规矩一样：开发机是 Windows 时，目标是 WSL 里那份 sshd；开发机本身是 Linux、要几台不同发行版时，用 Podman 起。跑 `go test` 的场地在上文「跑测试的场地」那一节。

**本工作区的开发机是 Windows 11 + WSL2，没有 podman**，所以 Podman 那半在这里不适用。

### 本机这一套：Windows + WSL2

目标机就是 WSL 里那一份 sshd：`127.0.0.1:2201`（同时听 22），账号 `sshfleet` / `Sshfleet#2026`、NOPASSWD sudo；三节点场景用 `127.0.0.1/2/3` 指同一个 sshd，测的是「三台同型号机器」，不是「三台不同机器」。

Go 全局装在 WSL 的 `/usr/local/go`（`/usr/local/bin/go` 是它的软链；`go` 若解析到 `/mnt/c/Program Files/Go/bin` 就是取到了 Windows 那一份，用 `which go` 核一下）。

要连目标机却找不到机器时，先想到这里。

连哪套都一样：**非必要不用 root**——它的特权会让某些触发路径被跳过，测不出来；确需时照用。

### 把工具真跑起来

目标机用本机这一套那一台；开发机是 Linux 时才用下面 Podman 起的两台。差别在配置与产物：不碰 `modules/SSHFleet_Go_bak/config/SSHFleet.conf`（作者本机配置），把 `SSHFleet-for-linux.conf` 连同三份 `keywords_*.conf` 拷进 `build/<用途>_<时间戳>/config/`，`[credential]` 的 `encrypt` 改 `false`、清单写明文密码，命令加 `--yes`。结果读 `history/SSHFleetTools.log` 的 `r=` / `s=` / `u=` / `d=` / `p=` 行。

要验的行为已经有用例 → 按上文「跑集成用例」那一节跑；要看整条链路（终端文案、归档、xlsx）→ 走这一条。

### 换 Linux 开发机：Podman 起两台

只在开发机本身是 Linux 时用。**Podman 镜像 MUST 用已重新封装的**，不用原生镜像。

```bash
podman run -d --name u1 --hostname u1 --ip 10.88.1.201 -p 127.0.0.1:2201:22 \
    --tmpfs /mnt/small64:rw,size=64m,mode=0755 localhost/sshfleet-ubuntu:26.04

podman run -d --name c1 --hostname c1 --ip 10.88.1.202 -p 127.0.0.1:2202:22 \
    --tmpfs /mnt/small64:rw,size=64m,mode=0755 localhost/sshfleet-centos:7.9
```

起完建可写目录——卷是运行期挂的，`w` 不在镜像里：

```bash
ssh sshfleet@10.88.1.201 'sudo mkdir -p /mnt/small64/w && sudo chmod 777 /mnt/small64/w'
```

- 镜像里只有一个账号 `sshfleet`，`NOPASSWD` sudo 直接过；root 直登与 root 口令都关着。
- `--tmpfs` 按需：64MB 卷只服务「目标盘装不下」类用例。`/tmp` 限小加 `--tmpfs /tmp:rw,size=32m,mode=1777`，`mode=1777` 别省（见下文「坑」）。
- 别加 `--network=host`：容器里绑不上 22。
- 容器不常驻，先 `podman ps` 看一眼；重名再起会失败。
- 库里另有四个 `*forpod:*-sshfleet-{base,tiny-tmp}`（四账号 + 预挂卷 + 自检 Banner 的夹具版），不要用来起新台。

### 要非默认的目标机，自己加

镜像只有一个账号、没有小卷、`/tmp` 不限小，这些都在运行期加。`ssh` 进去用 `sudo`，或宿主上 `podman exec`（默认 root）。

| 要什么 | 怎么做（以 `u1` 为例） |
| --- | --- |
| 第二个账号 | `podman exec u1 useradd -m t1`，再 `echo 't1:口令' \| podman exec -i u1 chpasswd` |
| 密码已过期 | 接上一条，`podman exec u1 chage -d 0 t1` |
| 登录被禁 | `useradd -m -s /usr/sbin/nologin t2`（`/sbin/nologin` 也在，写前者两边都认） |
| 远端不吭声 | 登录 shell 换成只 `exit 1` 的桩：`/usr/local/bin/quiet` 两行 + `chmod 755`，`useradd -m -s /usr/local/bin/quiet t3`。会话建得起来、零输出、退出码 1 |
| 700 的 root 目录 | `sudo mkdir /ro && sudo chmod 700 /ro` |
| `/tmp` 限小 | 重建容器，加 `--tmpfs /tmp:rw,size=32m,mode=1777` |
| 另一块盘 | 同上 `--tmpfs /mnt/big:size=512m`，再建可写子目录 |

**WSL 里那一份 sshd 也一样加，只是把 `podman exec` 换成交互式命令。** `sshfleet` 是现成账号，要别的账号就在 WSL 里建，不用碰容器：

```bash
wsl -d Ubuntu-26.04 -- bash -lc 'sudo useradd -m -s /bin/bash tmp1 && echo "tmp1:口令" | sudo chpasswd && echo "tmp1 ALL=(ALL) NOPASSWD:ALL" | sudo tee /etc/sudoers.d/tmp1'
wsl -d Ubuntu-26.04 -- bash -lc 'sudo userdel -r tmp1'   # 用完删掉
```

**WSL 测不出来的，仍要容器**：CentOS 7.9 的行为（`C.UTF-8` 缺失、python 只有 2.7、没有 systemd）、64MB 小卷、真正的多台不同机器。

### 坑

下面这些是容器那一套的；WSL 那边的坑见上文「本机这一套」与「要非默认的目标机」。

- **CentOS 7 没有 `C.UTF-8`**：带 `LC_ALL=C.UTF-8` 连过去，远端每个命令前刷一行 `setlocale: cannot change locale`。ADR-0030 的由来，不是工具的问题。
- **CentOS 那台没有 systemd**：1 号进程是 `sshd -D`（el7 的 systemd 219 只认 cgroup v1）。别指望 `systemctl` / `journalctl`，看进程与 `/var/log/secure`。
- **挂 `--tmpfs /tmp` 会盖掉镜像钉好的 `1777`**：CentOS 官方 rootfs 是 `0775`，普通账号建不了目录，报「建远端目录失败：Process exited with status 1」。
- **`/tmp` 限小与大文件上传互斥**：判暂存侧空间那条要求 `/tmp` < 40MB，「贴着边也能传成」那条要传 60MB 上下，别放同一个容器。
- **`-s app.py` 在 CentOS 上失败是真实形态，别修**：CentOS 镜像只有 python2.7、没有 python3，`sudo: python3: command not found`、分类「执行失败(退出码1)」正是老发行版的样子；Ubuntu 镜像带 python3 3.14，同一份脚本能跑。
- **root 不能当测试账号**（容器与 WSL 都适用）：程序里 `effectiveSudo := useSudo && cfg.User != "root"`，root 登录会把 sudo 路径整段跳过。
- **容器重启清空 tmpfs**：`/tmp` 与 `/mnt/small64` 内容没了，`w` 要重建。

### 自备项与排障

- **「两个候选编码都缺」要自己造**：Ubuntu 只有 `C.utf8`、CentOS 只有 `en_US.utf8`，ADR-0030 的「挑不到就不设」默认测不到。在 CentOS 上删掉唯一候选：

  ```bash
  ssh sshfleet@<centos> 'sudo localedef --delete-from-archive en_US.utf8'
  ```

  删完 `locale charmap` 回 `ANSI_X3.4-1968`，工具的 `LC_CTYPE` 留空。Ubuntu 删不掉——`C.utf8` 是 glibc 内置，会回 `not in archive`。
- **排障日志**：Ubuntu 是 systemd 容器，`podman exec <名> journalctl -u ssh`；CentOS 看 `/var/log/secure`。
