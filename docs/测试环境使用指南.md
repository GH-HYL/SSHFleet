# 测试环境使用指南

> 要找台目标机验东西，读这一页；`docs/个人开发规范.md` 三·4 只留指针与两条硬约束。

## 一、先认开发机

| 你在 | 要验的 | 去哪 |
| --- | --- | --- |
| Linux（本工作区跑 Ubuntu 26.04） | Linux / bash 语义 | 本机直接跑 |
| Linux | CentOS 7.9 的行为 | Podman 起容器（第三节） |
| Windows | Linux / bash 语义 | WSL2；cmd / PowerShell 的输出不是目标机行为 |
| Windows | 编出来的 exe | Windows 本机跑原生 go 编的 exe——WSL 里编的是 linux 版，`path` / `filepath` 按 `GOOS` 在编译期就定死 |

`podman` 用 `~/.local/bin` 里那个包装（rootful，按 tag 补挂载与 IP），别直连 `/usr/bin/podman`。

## 二、三种场景

### A. 看某条命令输出（与工具无关）

- Linux 本机：`bash -lc '<命令>'`
- 要 CentOS：`podman exec <容器> bash -lc '<命令>'`
- Windows：`wsl -d Ubuntu-26.04 -- bash -lc '<命令>'`

### B. 跑集成用例

对象是 `modules/SSHFleet_Go/internal/ssh` 下带 `//go:build integration` 的用例；`go test ./...` 不加载它们。

| 变量 | 作用 |
| --- | --- |
| `SSHFLEET_TEST_HOST` / `PORT` / `USER` / `PASSWORD` | 缺一个就整批 skip |
| `SSHFLEET_TEST_FULLDIR` | 64MB 卷上的可写目录，填 `/mnt/small64/w` |
| `SSHFLEET_TEST_SUDO=1` | 打开需要提权的两条 |
| `SSHFLEET_TEST_RACE=1` | 并发占盘那条，默认关 |

跑：`go test -tags integration -count=1 ./internal/ssh/`。变量名以代码为准。

### C. 把工具真跑起来

目标机同第三节；差别在配置与产物：不碰 `modules/SSHFleet_Go/config/SSHFleet.conf`（作者本机配置），把 `SSHFleet-for-linux.conf` 连同三份 `keywords_*.conf` 拷进 `build/<用途>_<时间戳>/config/`，`[credential]` 的 `encrypt` 改 `false`、清单写明文密码，命令加 `--yes`。结果读 `history/SSHFleetTools.log` 的 `r=` / `s=` / `u=` / `d=` / `p=` 行。

要验的行为已经有用例 → 走 B；要看整条链路（终端文案、归档、xlsx）→ 走 C。

## 三、起两台

```bash
podman run -d --name u1 --hostname u1 --ip 10.88.1.201 -p 127.0.0.1:2201:22 \
    --tmpfs /mnt/small64:rw,size=64m,mode=0755 localhost/sshfleet-ubuntu:26.04

podman run -d --name c1 --hostname c1 --ip 10.88.1.202 -p 127.0.0.1:2202:22 \
    --tmpfs /mnt/small64:rw,size=64m,mode=0755 localhost/sshfleet-centos:7.9
```

起完建可写目录——卷是运行期挂的，`w` 不在镜像里：

```bash
ssh sshfleet@10.88.1.201 'sudo mkdir -p /mnt/small64/w && sudo chmod 777 /mnt/small64/w'
```

- 账号只有一个：`sshfleet` / `Sshfleet#2026`，`NOPASSWD` sudo 直接过；root 直登与 root 口令都关着。
- `--tmpfs` 按需：64MB 卷只服务「目标盘装不下」类用例。`/tmp` 限小加 `--tmpfs /tmp:rw,size=32m,mode=1777`，`mode=1777` 别省（见第五节）。
- 别加 `--network=host`：容器里绑不上 22。
- 容器不常驻，先 `podman ps` 看一眼；重名再起会失败。
- 库里另有四个 `*forpod:*-sshfleet-{base,tiny-tmp}`（四账号 + 预挂卷 + 自检 Banner 的夹具版），不要用来起新台。

## 四、要非默认的目标机，自己加

镜像只有一个账号、没有小卷、`/tmp` 不限小，这些都在运行期加。`ssh` 进去用 `sudo`，或宿主上 `podman exec`（默认 root）。

| 要什么 | 怎么做（以 `u1` 为例） |
| --- | --- |
| 第二个账号 | `podman exec u1 useradd -m t1`，再 `echo 't1:口令' \| podman exec -i u1 chpasswd` |
| 密码已过期 | 接上一条，`podman exec u1 chage -d 0 t1` |
| 登录被禁 | `useradd -m -s /usr/sbin/nologin t2`（`/sbin/nologin` 也在，写前者两边都认） |
| 远端不吭声 | 登录 shell 换成只 `exit 1` 的桩：`/usr/local/bin/quiet` 两行 + `chmod 755`，`useradd -m -s /usr/local/bin/quiet t3`。会话建得起来、零输出、退出码 1 |
| 700 的 root 目录 | `sudo mkdir /ro && sudo chmod 700 /ro` |
| `/tmp` 限小 | 重建容器，加 `--tmpfs /tmp:rw,size=32m,mode=1777` |
| 另一块盘 | 同上 `--tmpfs /mnt/big:size=512m`，再建可写子目录 |

## 五、坑

- **CentOS 7 没有 `C.UTF-8`**：带 `LC_ALL=C.UTF-8` 连过去，远端每个命令前刷一行 `setlocale: cannot change locale`。ADR-0030 的由来，不是工具的问题。
- **CentOS 那台没有 systemd**：1 号进程是 `sshd -D`（el7 的 systemd 219 只认 cgroup v1）。别指望 `systemctl` / `journalctl`，看进程与 `/var/log/secure`。
- **挂 `--tmpfs /tmp` 会盖掉镜像钉好的 `1777`**：CentOS 官方 rootfs 是 `0775`，普通账号建不了目录，报「建远端目录失败：Process exited with status 1」。
- **`/tmp` 限小与大文件上传互斥**：判暂存侧空间那条要求 `/tmp` < 40MB，「贴着边也能传成」那条要传 60MB 上下，别放同一个容器。
- **`-s app.py` 在 CentOS 上失败是真实形态，别修**：CentOS 镜像只有 python2.7、没有 python3，`sudo: python3: command not found`、分类「执行失败(退出码1)」正是老发行版的样子；Ubuntu 镜像带 python3 3.14，同一份脚本能跑。
- **root 不能当测试账号**：程序里 `effectiveSudo := useSudo && cfg.User != "root"`，root 登录会把 sudo 路径整段跳过。
- **容器重启清空 tmpfs**：`/tmp` 与 `/mnt/small64` 内容没了，`w` 要重建。
- **产物不出工作区**：沙盒落 `build/<用途>_<时间戳>/`，按天清理。

## 六、自备项与排障

- **「两个候选编码都缺」要自己造**：Ubuntu 只有 `C.utf8`、CentOS 只有 `en_US.utf8`，ADR-0030 的「挑不到就不设」默认测不到。在 CentOS 上删掉唯一候选：

  ```bash
  ssh sshfleet@<centos> 'sudo localedef --delete-from-archive en_US.utf8'
  ```

  删完 `locale charmap` 回 `ANSI_X3.4-1968`，工具的 `LC_CTYPE` 留空。Ubuntu 删不掉——`C.utf8` 是 glibc 内置，会回 `not in archive`。
- **排障日志**：Ubuntu 是 systemd 容器，`podman exec <名> journalctl -u ssh`；CentOS 看 `/var/log/secure`。

## 七、收尾

`podman rm -f u1 c1`，镜像留着。
