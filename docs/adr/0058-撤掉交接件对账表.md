# ADR-0058: 撤掉交接件对账表——它守的那一段已经没有两张纸

- **状态**：accepted
- **日期**：2026-11-17
- **决策人**：
  - **作者明示**（2026-11-17）：「都按你的建议走」。此前执行者报过两条路（补对象 / 撤判据），并说明「补对象走不通」的实测依据；作者未单独就本条再拍板，按上一句整体授权。
  - **执行者实测**：`Pairs` 生产零赋值、判据零次循环（下述）。
- **前身**：ADR-0035 决定三与 2026-11-02 更新记录；ADR-0045（检查器要能发现自己被拆掉）

## 背景

ADR-0035 决定三立了一条规矩：同一个口径往下传时，后一张纸除本棒结论外不许比前一张宽。2026-11-01 把它从「暂缓」改成可核，判据落成「闸门那张纸的字段集 = 解析那张纸的字段集 + 一个叫 `Conclusion` 的格子」，只核同一口径那一段。

2026-11-02 的更新记录写了一件改变前提的事：**闸门这一棒改成等宽、不造新纸**，塔尖把同一张 `contract.Plan` 递给执行站。同一条记录给对账表留了话：「在等宽的这一棒上没有可判对象，所以它最后一次对账推到全部阶段落完，不是欠账」。

五站已落完。这次复查核到的是：`guard/scan.go` 里的对账表 `Pairs` 在全工程**没有一处赋值**（只有测试里直接塞值），`check_handoff.go` 的循环因此永远 0 次。它每月照常输出「0 violations」。

## 决定

**一、撤掉这条判据，不补对象。** 判据函数、对账表类型、`Module.Pairs` 字段、对应红线与测试一并删除。

**二、ADR-0035 决定三那句规矩仍然成立。** 同一个口径往下传，除本棒结论外后一张不许比前一张宽；但它从此只靠规格审计与人读守，不再有一条机械判据假装守着。

## 理由

**为什么补不出对象。** 判据的形状是「后一张 = 前一张 + 一格结论」，它预设每一棒都造新纸、纸上都落一格结论。闸门改成等宽之后：

- 前两棒（解析交闸门、闸门交执行）是**同一张** `contract.Plan`，没有「前一张」与「后一张」之分；
- 闸门的结论按设计不进纸：不让走的时候纸不往下递，放行了就没有需要写在纸上的第二句结论；
- 补一对 `Plan → Plan` 会当场要求一个 `Conclusion` 字段，而这个字段一旦加进去，就是在替闸门造一张它按设计不该造的新纸。

后两棒（执行交结算、结算交报告）本来就在换口径，ADR-0035 决定三明说不管它们。所以「同一口径上相邻两棒的一对纸」在现行流水线里一处都不存在。

**为什么不能留着空转。** 一条永远不报的检查比没有更坏：它让人把绿色当成证据，也让下一个人以为这条规矩有人守。ADR-0045 立的正是这个理——检查器要能发现自己被拆掉；这一条是同一个病的另一种形态：检查器看不见自己没有对象。

## 影响

- 红线从 46 条降到 44 条（这条判据占了 `TestCheckHandoff` 与 `TestCheckHandoffMissingPaper` 两条）；删条目按 ADR-0037 决定五走程序（名单与指纹同步，议题是本篇的实施载体）。
- `guard` 少一类判据（类六之二），检查报告的类别清单跟着短一行。
- 报告里不再出现「交接件」这一类。读报告的人若想知道加宽风险，只能从规格审计的结论里看。
- 「越传越窄」今天真有的机械守点是另外两条，都**不管宽度**：纸面白名单（管契约里哪些格能装字，ADR-0044 更新记录）与站的出口白名单（管谁能造、谁只能收，ADR-0037 决定三）。撤掉本条之后，「宽度」这件事在全工程没有任何机械守点。

## 代价

- **这条规矩从此没有机械守点。** 谁在交接件上多加一格数据，编译器不报、测试不红、检查器不看，只有做规格审计的人可能发现。这是本条真正付出的东西。
- **撤掉一条红线会给后来的人一个错觉**：以为宽度约束被放弃了。ADR-0035 决定三仍在，只是守的方式从机械降为人读——这一段必须写进更新记录，否则下一轮复查会把它当漏项补回来。

## 退路

要撤回这一条：代码从 git 取回那两个文件与四处引用（`CheckAll` 的一行、`Target.Pairs` 一格、报告类名、真工程测试的调用），红线名单补回两条，按 ADR-0037 决定五补回算「新增」、不需要再写 ADR；但**必须在议题里记一笔为什么撤回**，否则下一轮复查会当成新发现再撤一次。这个撤回成本是可接受的，不属于「不可逆」。

## 备选方案

| 备选 | 否掉的理由 |
| --- | --- |
| 补一对 `Plan → Plan` | 要求一个 `Conclusion` 格，而闸门的结论按设计不进纸；加了就是逼闸门造一张它不该造的新纸 |
| 改成「字段集不比上一棒少」而不要求结论格 | 仍然需要两张纸；前两棒是同一张，没有可比的两边 |
| 保留空转，注释说明「暂无对象」 | 与 ADR-0045 对着干：绿色被当成证据，且这个「暂无」已经挂了半个月 |
| 把判据挪到「换口径」的两棒上 | ADR-0035 决定三明说换口径不受这条管；挪过去就是改那条决定的口径，代价远大于撤一条空转 |
