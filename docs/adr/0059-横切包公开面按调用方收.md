- **前身**：ADR-0044（纸只装结构化事实，拼好的句子一律回 `message` 成形）；ADR-0037 决定三（出口白名单与「为红线够得着而导出」的反向风险）

## 背景

ADR-0044 把「话只能由 `message` 造」落在**类型**上：`message.Line` 的字段不导出，别的包连一句话都构造不出来。这条约束今天仍然成立。

但公开面的宽度把它的意义磨掉了一层。拼句包有 202 个公开函数，每 20 行一个公开名字；其中四成包外一次都没被调过。同一个屏因此有两个门牌：一屏「起不来」有一个给生产的入口，还有一个注释写着「测试与日志拿它比对、不上屏」的入口，两者是同一实现。调用方读代码时，看到的是两百个平权的名字，没有一个告诉他「这个包只做一件事：事实进去，一屏话出来」。

ADR-0037 已经记过反向风险：为了让红线测试够得着而把一个内部函数导出。这次核到的形态是它的镜像——为了让测试比对一句话而多开一个门牌，与为了红线多开一个导出。

## 决定

**一、横切包的导出判据是「包外有没有生产调用」，不是「本包用不用」。** 包外零生产调用、本包内仍有引用的名字，收回包内（改小写），本包内的引用跟着改。**测试的引用不算生产调用**——红线测试为了够得着而引用一个导出名，不是「有人在用」，那类情形归第三条。这条判据对横切包通用；**本轮只落证据覆盖的两个包（拼句包、凭据包），其余横切包不动**。

**二、一个屏不许有两个门牌。** 这里说的「门牌」是**同一个屏的两个公开入口**（两个名字造同一句话，其中一个只为测试比对而开）。这样的第二个入口撤掉，测试改从公开的那一屏取正文。测试要验的是使用者看到的那句话，不是另一个同实现的副本。**本条是取向，不设机械判据**：判「两个名字是不是同一屏」是语义，检查器只能判到「一个函数体是不是只有一句转调」这种表面形态，而那个形态在正当场合也存在；发现它的时机是规格审计，不是编译。

**三、为了红线够得着而导出的，保留。** 注释写明它是给红线测试的、生产不走这条路（ADR-0037 点名的反向风险）。这一类不按第一条收。**它与第二条不是同一形态**：第二条收的是「同一个屏的第二个入口」，这一条留的是「一个内部件为了让红线看得见而导出」——后者本身不是一个屏的入口，不会让调用方多一个「该调哪个」的选择。

**四、生产与测试都零调用的自由函数删掉。** 调用方一律走方法式，留一个壳就是给下一个人两个入口。

**五、不合并 29 个 `Refuse*`。** 拒绝与起不来是 ADR-0034 有意分的两种失败：起不来是三十多个类别、同一句话按环节成形；拒绝是二十九个场景、调用点自带上下文。合表前得先把这二十九个场景抽成共同的事实形状——那是一次领域建模，不是排版。本条只管公开面的宽度，不管它的形状。

## 理由

**公开面就是接口，宽度决定深不深。** 一个包 202 个名字、四成没人用，调用方无法从名字上判断该调哪个；每加一句话的文案就多一个公开符号，接口随需求线性膨胀。收回之后，加文案的人面对的是「在既有入口里加一种类别」，而不是「再造一个名字」。

**为什么按包外调用判。** 「本包用不用」是实现的内部事实，对调用方没有意义；一个名字只有本包在用，它就还是内部件，公开出去只是让外面多一条可走的路。

**为什么不能只加注释。** Go 里给导出名加「内部用」的注释不改变任何东西：它仍然是公开面，仍然能被调，仍然要在每次读代码时被看见。只有改小写才是结构上的收。

## 影响

- 拼句包的公开函数从 202 收到约 160（以实施时的机械清单为准，不以本篇的数当验收）。
- 解析站那八个测试文件改从公开屏取正文，源码里的「比对用入口」不再存在。
- 红线名单若因此改动引用到的符号，按 ADR-0037 决定五走程序（名单与指纹同步）；实测这四成名字不在红线引用面里，预期不改指纹，以实施时 `go test` 为准。
- 以后要新增一个公开出口，先回答「第二个调用方是谁」；只有本包用的，一律小写。

## 代价

- **测试不能再拿专用门牌比字。** 要比一屏话，就得走生产那条路取；那是对的，但改测试的人会多一步。
- **收回之后，包外确实有人用的名字会编译不过**，这是预期的红；这类名字一个不动，以包外引用清单为准。
- **「一屏一入口」靠人认，没有机械判据。** 今天没有一条检查能判「这两个名字是同一屏」，收不收回来看规格审计；这是本条的固有代价，不是漏项。

## 退路

要撤回这一条：把收回的名字改回大写即可，包外调用方不用动；若改回的名字落在红线测试的直接引用面里，按 ADR-0037 决定五补回名单与指纹（加回算改）。收回期间已经改从公开入口取的测试**不必改回去**——那条路更接近生产，留着不亏。

## 备选方案

| 备选 | 否掉的理由 |
| --- | --- |
| 保留现状，只在新代码上守 | 公开面已经是两百个，新代码守不住旧面；读代码的成本不会降 |
| 给四成名字加「内部用」注释 | Go 不认注释，仍公开、仍能调，只是多一行字 |
| 把 29 个 `Refuse*` 一并铺成类别表 | 超出本条射程，且要先做一次领域建模（见决定五） |
| 把拼句包拆成「屏」与「构造点」两个包 | 拆包不减少公开面，只是把两百个名字分到两个包里；ADR-0034 已认「话只在这一处成形」 |
