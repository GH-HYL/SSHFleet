# ADR-0060: 执行站入口的两个落点收成一张具名纸

- **状态**：accepted
- **日期**：2026-11-17
- **决策人**：
  - **作者明示**（2026-11-17）：「都按你的建议走，授权你改」。执行者此前把这一条列为六条工单的最后一条，理由与代价都报过。
  - **执行者实测**：塔尖那一处调用是 `paths.Terminal, paths.ExecLog` 两个同型字符串；报告站入口早在 ADR-0043 就收一组落点。
- **前身**：ADR-0043（报告站入口改收一组落点）；ADR-0035 决定三（只装下一站要用的）

## 背景

执行站的入口收四个参数，最后两个是 `termPath, execLogPath`，都是裸 `string`。调用方在塔尖，写的是 `paths.Terminal, paths.ExecLog`——两个字段名都对，但一旦有人手写这两个位置（测试里就是这么写的），把终端那一路写进执行日志，编译器一句话不说。后果不是崩溃，是屏上那句「完整内容见 <路径>」指着一份不存在的文件。

报告站的入口收的是归档那一整组落点，执行站只写其中两份。

## 决定

**契约里增一张两格的纸，执行站入口收它。** 两格各有名字：终端输出、执行期日志。塔尖从归档那组落点里摘这两格递进去。

**不收归档那一整组。** 执行站只写这两份，多给一格就是让它碰上不该碰的东西（ADR-0035 决定三「只装下一站要用的」）。

## 理由

**同型参数靠位置分辨，是接口税。** 两个 `string` 并排，语义全在次序里；调用方必须记住谁在前。加了名字之后，`Landings{ExecLog: …, Terminal: …}` 写反了当场编译不过，不必等测试。

**为什么不直接收归档那组。** 那组里还有目录、备份、清单副本——执行站一份都不写。收进来等于把「谁该碰什么」这条边界换成一句纪律。

## 影响

- `contract` 多一个类型，纸面白名单多两格（路径按事实登记，与密钥管理那几个路径同类别）。
- 两条钉执行站入口的红线测试引用面各多一个符号，按 ADR-0037 决定五留痕（名单与指纹同步改，断言数不变）。
- 塔尖多一行构造：从归档落点里摘两格。

## 代价

- **塔尖多一行装配。** 它原来只是把两个字段原样转手，现在要拼一张纸——严格说这比「只搬」多了一点。换来的是写反编译不过，这一笔换得划算。
- **契约多一个只服务一个调用方的类型。** 今天只有执行站用它；将来若有第二个站也要这两个落点，它是现成的，不必再造。
- **红线指纹动一次。** 引用面变宽不常见，但这次是入口形状变了，属「改红线」的正当情形，已在议题里记明。

## 退路

要撤回这一条：`execute.Run` 的签名改回两个 `string`，四处调用拆回原样，契约里那张纸与纸面白名单两格删掉；两条红线测试的引用面各少一个符号，按 ADR-0037 决定五改回（引用面收窄也算改）。撤回成本与落地成本相当，不属于「不可逆」。

## 备选方案

| 备选 | 否掉的理由 |
| --- | --- |
| 保持两个 `string` | 写反编译过；这一处今天靠调用方小心，明天靠谁记得 |
| 直接收归档那一整组落点 | 带上执行站一份都不写的格子，把边界换成纪律 |
| 把归档那组落点搬进契约 | 报告站与归档都要跟着改，爆炸面比这条收益大得多 |
| 只给两个落点各包一个具名单字段类型 | 多造两个只包一个字符串的类型，比一张两格的纸更绕 |
