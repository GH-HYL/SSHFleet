# ADR-0006: 危险命令检测去开头锚定——宁错杀不放过

状态：已接受（2026-08-18）

## 背景

危险命令规则（`dangerous_keywords.yaml`，43 条）全部带开头锚定（`^\s*` / `^\b`）和部分结尾锚定（`$`），要求危险模式必须位于命令开头才能命中。实测暴露三类漏检：

1. **命令替换内嵌**：`echo $(rm -rf /)` 中 `rm -rf /` 不在开头 → 漏检，但 bash 会真实执行命令替换。
2. **中间位置**：`x=1; rm -rf /tmp/*` 拆分子命令后仍漏检（前缀 `x=1` 干扰锚定）。
3. **文本引用**：`echo "rm -rf /"`、`grep -r "rm -rf" /etc/` 中危险字符串非命令开头 → 漏检（bash 执行时引号内内容同样会落入 shell 语法解析，存在真实执行风险）。

漏检的根因：锚定规则基于"危险命令必然单独出现在开头"的假设，而用户输入（尤其复制粘贴、脚本内容、嵌套 shell）不受此约束。

## 决策

**去掉全部规则的开头/结尾锚定，改为任意位置匹配（词边界 `\b` 约束），宁错杀不放过。**

### 规则变换规则

- 开头 `^\s*` → `\b`（如 `'^\s*rm\s+...'` → `'\brm\s+...'`）
- 开头 `^\b` → `\b`（去掉 `^`）
- 结尾 `(?:#.*)?$` / `$` → 删除（命令后接其他内容同样命中）
- 保留 `\b` 词边界：防止单词内部误匹配（`farm -rf` 不命中 `\brm`），但 `echo rm -rf /`（rm 前是空格，词边界成立）命中

### 分级不变

- `forbidden`（如 `rm -rf /` 根目录）：任意位置命中 → 直接退出
- `high`/`medium`/`low`：任意位置命中 → 警告 + 用户确认

## 后果

- **正面**：`$()` 内嵌、中间位置、文本引用（echo/grep 打印）等历史漏检全部封堵；剥壳函数（ADR-0005）与去锚定叠加后，引号包裹/嵌套包裹场景双保险；脚本模式同样受益。
- **负面（预期的错杀代价，用户明确接受）**：`echo "rm -rf /"` 这类只是打印文本的命令会被 forbidden 直接拦截退出；`grep -r "rm -rf"` 会触发 high 级警告（需确认继续）。安全优先于可用性。
- **改动面**：`dangerous_keywords.yaml`（43 条规则去锚定）；检测逻辑本身（dangerous.py）无需改动，剥壳/切分/去前缀清洗链保持不变。
