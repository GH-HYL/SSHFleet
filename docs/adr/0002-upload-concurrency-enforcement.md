# ADR 0002: 上传并发阈值从提醒改为默认约束

**状态**: 已采纳  
**日期**: 2026-07-23

## 背景

原实现中，上传并发阈值检查的行为与配置注释不一致：
- 配置注释写"提醒用，不强制约束"
- 但代码在用户同意时会修改 `args.n`，用户拒绝时仅打印警告继续执行
- 这导致"提醒"和"强制"的边界模糊，用户体验不清晰

## 决策

将阈值检查改为**默认约束，显式指定时跳过**：

| 场景 | 行为 |
|------|------|
| 未指定 `-n`，默认值超过约束 | 提示建议值（默认 Y），用户拒绝则退出 |
| 显式指定 `-n`，超过约束 | 仅提示建议值，不修改，继续执行 |
| 小文件（< 1MB）或约束值 >= 默认值 | 不触发检查 |

## 影响

- `confirm.py`：`_check_upload_concurrency` 重写，新增 `nodes_count` 和 `n_explicit` 参数
- `arguments_confirm`：检查顺序调整，在默认值赋值前判断 `-n` 是否显式指定
- `SSHFleet.yaml`：配置注释更新
