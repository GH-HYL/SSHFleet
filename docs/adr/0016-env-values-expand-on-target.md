# ADR-0016: 环境变量的值交给目标节点展开

- **状态**：已接受
- **日期**：2026-10-09

## 背景

`[execution.env]` 的每个值此前由 `ssh.QuoteForShell` 拼装：全是安全字符就裸拼，否则包**单引号**。单引号是 shell 里唯一"什么都不展开"的引号，于是值一律是字面量——`PATH = "/opt/bin:$PATH"` 到远端就原样变成 `/opt/bin:$PATH` 这串字符，既不展开也不报错。

这个限制没有任何地方声明过，而它的失败形态很难查：写的人本是照着 shell 的习惯写的，远端 `PATH` 变成一个不存在的目录之后，报出来的是 `command not found`，跟环境配置看不出关系。

同时，那份引号逻辑本来是给**打印**写的——日志里的命令行要能照抄重跑，所以对 `$` 必须补引号。被拿来做下发之后，两处要求正好相反，注释里"不下发、不参与任何解析"的断言也不再成立。

## 决定

1. 环境变量的值**一律包双引号**下发，不再裸拼、不再用单引号；工具只做一件转义：值里的 `"` → `\"`。
2. 值的其余字符原样交给目标节点，按 **shell 双引号语义**处理：`$VAR`、`${VAR}`、`$(命令)`、反引号都会展开或执行；要字面的 `$` 写 `\$`（`\\` 得到一个 `\`）。
3. **值以奇数个反斜杠结尾**在启动期报错并点名：那个反斜杠会吃掉收尾引号，远端整条命令变成语法错。
4. 引号逻辑与打印那份**分开**：新增 `ssh.quoteEnvValue` 只管下发，`QuoteForShell` 回到"只给打印用"，两处调用点各归各。

## 理由

- **为什么放开**：值要能引用目标机的环境，"在目标机原有环境上加一段"除了这个写法没有别的表达方式（追加 `PATH` 是最常见的用法）。不放开，用户只能把目标机的目录表抄全写上。
- **为什么一律双引号、不留裸拼**：规则只剩一条——值 = 双引号里的文本，不必逐条判断。裸拼那套（安全字符集、按需加引号）是给打印用的，两套并放会互相污染。附带好处：双引号嵌在下发行外层那对单引号里**不需要转义**，日志不会多出 `'"'"'` 那类噪声。
- **为什么只转义 `"`**：双引号里能破坏边界的只有 `"` 自己。其余字符若一并转义，用户就没有任何写法能得到字面的 `$`——`\$` 会被转成 `\\$`，变成"字面反斜杠 + 展开"。
- **为什么末端反斜杠要拦**：值是配置里写死的，在启动期点名比在远端收一句 `unexpected EOF` 好查。偶数个反斜杠是安全的（两个凑成一个字面反斜杠），所以判的是奇偶，不是"有没有"。
- **为什么拆成两个引号函数**：两者要求相反（打印要挡 `$`，下发要放开 `$`），共用一张"哪些字符安全"的表，必然有一边是错的。此前复用只是因为"当时恰好安全"；放开 `$` 之后，这个复用第一次真付了代价（同一张表要满足两个相反的要求）。

## 影响

- **`QuoteForShell` 退出下发路径**，只服务日志与 `report.txt` 的命令行还原；`ssh.ExportPrefix` 改用 `quoteEnvValue`。
- **出厂配置一个字节不变**（四个值里没有 `$`，展开与否无差异），但下发形态变成 `export LANG="en_US.UTF-8" …`——文档样例、日志里「命令行」一行都跟着变。
- **值不再是字面量**：配置手册与 `SSHFleet.conf` 注释写明"`$` 由目标节点展开，字面 `$` 写 `\$`"。`--no-shell` 仍不读这份配置。
- **展开的基准是目标机非交互会话那份环境**（`sh -c` 不读 `/etc/profile`），不是登录后的环境——所以靠 `$PATH` 拼出来的结果各机器可能不同，与 ADR-0015「让一批机器结果形态一致」的初衷相抵。想一致就把目录写全，这点写进配置手册。

## 备选方案

| 备选 | 否掉的原因 |
| --- | --- |
| 维持字面量，只补文档 | 用户要"在目标机原有环境上加一段"就永远没有写法，文档只能告诉他"做不到" |
| 只对含 `$` 的值改用双引号，其余照旧 | 同一个 `$` 会因值里有没有空格而行为不同（有空格就包成单引号→不展开），静默又难解释 |
| 值整串不加引号，原样交给远端 | 值里有空格就被拆词：`export A=a b` 会把 `b` 当成另一个变量名导出 |
| 用 `env` 外部命令承载 | 引入外部程序依赖，与"目标机只要 `/bin/sh` 在就能跑"的取向冲突（ADR-0015 已否过一次） |
| 在本地代目标机展开 | 工具不知道目标机的环境，展开不出正确结果，还会把"本地看到的"当成"远端发生的" |
