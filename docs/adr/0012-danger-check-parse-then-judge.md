# ADR-0012: 危险检测改为「解析层 + 判定层」，取代去锚定与整行剥壳

状态：规则结构部分已被 ADR-0013 取代（决策表 / 路径清单 / syntax 段回归平级正则）；
「解析层 + 判定层」分层与「可证明才拦」口径仍有效（2026-09-10 修订）

## 背景

ADR-0011 把检测定位为「分类提醒助手」，验收标准是**分类是否正确**。用该标准实测（58 条语料，
真实引擎）识别准确率 62.1%：17 条误判（业务目录判成删根、非递归判成递归、纯文本引用被拦）
+ 5 条漏判（`rm --recursive --force /` 完全无命中、分离旗标/大写 R/引号目标只到 high）。

误判与漏判同源：规则正则作用在**整行原始字符串**上，字符串里混有包装命令、引号、分隔符、
其他命令的参数。为了让规则在脏输入上仍能命中，才引入「任意位置匹配」（ADR-0006）与
「整行剥壳」（ADR-0005）——而这两种兜底手段同时就是误判的来源。一个字符集（`-[rf]+`）
既吞掉单个 `-f`，又表达不了分离旗标与大写 `R`；调正则无法收敛。

关键连锁：**间接执行（`$(...)`、`bash -c`、`eval`、`xargs`）能被拦住，靠的正是造成文本误判
的那个「任意位置匹配」**，是去锚定的副产品。因此不能只收紧正则——必须换成结构解析才能各自归位。

## 决策

**把识别拆成两层，正则保留但换掉作用对象。**

1. **解析层**（`src/check/shell_tokenize.py`）：引号/替换感知切分 → 分词 → 重定向剥除 →
   环境变量赋值与前导包装命令剥除（sudo 连其选项、nohup、time、setsid、stdbuf、xargs、env、command）
   → 命令词归一（`/bin/rm` → `rm`）→ 间接执行内部命令提取（`shell -c`、`eval`、`ssh host "…"` 单层，
   递归含命令替换与反引号，深度上限 5）。
   输出：**以真实命令词开头的命令段**。

2. **判定层**（`src/check/dangerous.py`）：规则作用于命令段，而非整行。
   - `rm` 走**决策表**（旗标条件 × 目标路径分类），旗标归一（`-rf`/`-r -f`/`-R`/`--recursive` → recursive；
     `-f`/`--force` → force；`--no-preserve-root`），目标路径归一（合并斜杠、词法解析 `.`/`..`、`/*` 视为根）；
     命中多条取最高风险。
   - 其余命令用**锚定正则**（`^` 开头）作用于「命令词 + 参数」——作用域收窄后，锚定重新成立，
     ADR-0006 的去锚定不再需要。

3. **配置 v2**（`dangerous_keywords.yaml`）：`syntax`（包装命令、间接执行命令，可自行扩展）/
   `path_classes`（路径分级清单，唯一一处）/ `rm_rules`（决策表）/ `commands`（锚定正则）。
   每条规则带 `enabled` 开关；启动即校验规则合法性并**指名报错**（缺字段、级别非法、正则无法编译、
   路径清单为空、规则总数不足）。

### 由此确定的判定口径

- **可证明才拦**：变量/命令替换目标（`rm -rf $DIR`）静态不可判定 → 只提醒不拦死（ADR-0011 优先级：
  不误判 > 不漏判）。
- 系统目录清单加 `/boot`、`/root`；`/proc /sys /dev /run` 等重启可恢复目录不入 forbidden，落 high。
- 系统目录 forbidden 要求递归旗标；`rm -f /etc/hosts` 落 medium「删除系统文件」。
- 纯文本引用（`echo "rm -rf /"`、`grep "rm -rf"`）不参与判定；命令替换与 shell/远端内部命令递归判定。
- 路径分类表只服务破坏性删除类命令（rm；dd/mkfs/truncate 用正则表达设备与路径），权限类不接。
- 脚本模式不追踪跨行状态（`cd`、变量、alias）——静态不可判定的现实边界，明确接受。

## 后果

- **正面**：语料准确率 62.1% → 100%（81 条）；本次全部误判/漏判结构性消除；文本引用、包装命令、
  间接执行由解析层统一处理一次，全部规则受益；误判修复不再需要逐条调正则。
- **负面（明确接受）**：刻意编码绕过（`base64 -d | sh`）、多层远端嵌套、跨行状态不覆盖（ADR-0011 已定）。
- **取代关系**：ADR-0005（整行剥壳）与 ADR-0006（去锚定、宁错杀）的前提均消失，二者被本 ADR 取代；
  剥壳函数 `remove_command_first_last_same_symbol` 已随解析层上线删除。
- **防篡改**：原「规则篡改校验」预留接口与「可配置」目标互斥，放弃；改为启动即校验（改错能立刻发现）。
