# 红线测试按 `go.mod` 认根

**状态**：已接受（accepted）
**日期**：2026-11-16
**决策人**：开发者——判定表族一「02-J6 判动」（已清空的议题档案）；做法由执行者推导，2026-11-16 15:31 他授权：「都你决定，我授权你修改adr，接缝的事情我不懂」。**故本条「决定」一节是推导出来的做法，不是他的原话**；他拍的是「改」这件事与「做法交你定」。

## 背景

塔尖那三条红线要起一个进程跑，得先有二进制。建站 02（2026-11-01）时，测试住 `internal/guard`，从那里上溯四级正好是仓库根，于是写下 `filepath.Abs(filepath.Join("..", "..", "..", ".."))`；产物丢 `build/建站02红线_2026-11-01`——那是当天的取证沙盒，那时全仓还没有统一的产物落点。

**变了三样，都是工程设计，没有一样是代码复杂度：**

1. **落点定了**：11-H1 之后「产物与临时文件不出工作区」成了纪律，落点统一到 `build/tmp/test/<包>`，十八个包各有一份 `tmpdir_test.go`，从包目录上溯找 `go.mod` 认根。
2. **仓库根与模块根分开了**：切换之后塔尖住 `modules/SSHFleet2_Go`。`../../../../` 指的是**仓库**根，而红线要编的是**模块**。两者只在本仓这一种布局下恰好对上。
3. **模块会被复制**：老工程原地留着当退路（ADR-0038），复制一份核对是常规动作；模块一复制或一 `git worktree` 到别处，上溯四级就落在别处。

## 决定

三条塔尖红线（`redline_tip_test.go` 一条、`redline_tip_endings_test.go` 两条）**不再上溯找任何根**：产物目录用本包的 `buildTmp()`（落 `build/tmp/test/guard/`），编译改成按模块路径编主包（`go build -o <绝对路径> sshfleet2`），不设 `Dir`。

认不到 `go.mod` 时的失败要单独一句话说清是环境问题，**不许**与「编二进制失败」同形。

三条红线的**判据一字不改**：`-h` 退 0 且版本行在首行下方、空参数同一屏、配置不在则非 0、起不来那屏带 `[ERROR]` 与 `[function:…]`、拒绝那屏不建本次归档目录。

## 理由

- 红线红的时候只能有一种解释：结构被动了。现在多出第二种解释「目录挪了」，而它长得跟真破坏一模一样——都是那条 `t.Fatalf("编二进制失败：%v\n%s")`。这与 ADR-0050 是同一条理由：第二种解释必须消掉，不是容忍。
- **判据强度不变**：判的东西一个字都没动，改的只是「从哪儿找到那个二进制」。这不是放宽，是换一把量尺的零点。
- **按模块路径编，比「先找根再进去编」少一层**：`go build <模块路径>` 从模块内任何目录都认得出主包，所以测试跑在哪一级目录都不影响；要在 `TestMain` 之外再定一份「根在哪」的规矩，就又多一个会和别处漂的说法。实测：在 `internal/keytool` 里 `go build -o <绝对路径> sshfleet2` 出得来二进制（本机 Windows，2026-11-16）。
- 复用 `buildTmp()` 而不新写一份：十八个包都在用它，红线与别的测试同一个落点，就不必为它单开一条规矩（先例：ADR-0034 决定四「纸不加格」的同一个取向）。

## 影响

- 模块被复制、或被 `git worktree` 检出到别处时，这三条仍绿——这是有意的。**实测**（2026-11-16，Windows）：改前把模块复制到 `build/tmp/` 下，`TestRedlineTipRunsHelp` 红在「编二进制失败：chdir …」；改后同样的复制全绿。
- 红线指纹会变，而且方向与原先猜的相反：`TestRedlineTipRunsHelp` 8→**7**、helper `tipEndingsProbe` 4→**3**、`copyRedlineDangerRules` 3→**2**——砍掉的是「定位仓库根失败」「建沙盒失败」两句环境失败，换成同一句「定位不到 build/tmp 沙盒」。次数变少不是断言变弱，但**它确实是「次数一少必是断言被掏空」这条判据的一个合法例外**，所以三处都写进了工单的 `## Comments`。
- **同一个毛病还有一处不在本 ADR 射程内**：`internal/parse/reconcile_test.go:26` 也上溯四级。它不在判定表里，本 ADR 不管它——写在这里只是让下一个人知道这一处存在，不要以为是漏了。

## 备选方案

- **先上溯找 `go.mod` 拿模块根、再 `Dir=` 进去编**：能用，但要把 `buildTmp()` 里那段上溯抄第二份（它只回沙盒路径、不回根），或者把十八份一样的 `tmpdir_test.go` 改得各不相同。按模块路径编省掉这一层。
- **把仓库根做成环境变量传进去**：多一条「跑测试前要 export」的约定。`tmpdir_test.go` 已经证明不必——它在 `init` 里自己钉，跑测试的人不必记得任何事。
- **红线干脆不编二进制、只做静态判**：那会把「起不来」「拒绝」两个结局在进程层的判据一起丢掉，等于撤掉 ADR-0034 决定三的落点。

## 复审

**未证实**：「模块复制到别处仍绿」是推导，加在本机实跑一次（Windows）；换平台未验。
