# 判据叶子包——同一把尺子只留一份

**状态**：accepted
**日期**：2026-11-12
**决策人**：开发者（2026-11-12 原话：「准」；讨论在交接件后第一轮，问的是「是否是 ip 还需要单独弄叶子包」）

## 背景

审计 4.3 记了六条「同一把判据两份」：合法 IPv4（解析站与 `mask`）、剥系统前缀（`message` 与凭据包）、单引号转义（三处两种形状）、`identityLabel`、解释器名归一、解释器名表。

其中两条已经出事：`010.0.0.1` 被当成合法节点（06-H1，实跑抓到）；凭据包那份剥前缀的函数比老版 `common.SystemReason` 少一支 `os.LinkError`，注释却写着「改这里要一起改那边」。

根因不是谁偷懒，是**够不着**：A4 单向（站之间不许互相依赖）、A14 每站一出口、横切包之间没有边（凭据包不许 import `message`）。一条判据只要被两处用到，就只能复制；复制出来的第二份漂了，没有任何东西会红。

## 决定

新建**第十个横切叶子包 `criterion`**：零业务，只放判定与取值这类纯函数，只依赖标准库；五站与其余横切包都可依赖它。第一版只搬两条有证据的——`IsIPv4` 与 `SystemReason`，四处的本地副本删除。

准入判据写进包注释：**两个以上包要用同一条判据、且任何一方都不该替对方提供时，才搬进来**。常量不进这里。

## 理由

- **没有别的家。** 能全员 import 的现成包只有契约包，可它按 ADR-0044 只装纸（结构化事实），放函数会让「纸」变抽屉；`message` 与 `mask` 装得下其中几条，但凭据包按 A13 不许 import `message`——`SystemReason` 那条恰恰是被这条逼出来复制的，塞现有包塞不进去。
- **名字得说实话。** 把「是不是合法 IP」塞进 `mask`（遮秘密）、把 shell 转义塞进 `message`（说话）只需三行改动，代价是下一个人不会想到去那里找尺子，第三条副本照样长出来。
- **紧的那把得留下。** 两份里更严的那份才是老版口径：老版 `common.SystemReason` 两支都剥，凭据包那份少一支。收进一处之后，严的那份成为唯一一份。
- **先例成立。** `exitcode` 只有四个常量与一张表，也是横切叶子包；包的大小不是判据，它装的东西有没有第二处要去用才是。

## 影响

- 包清单十八变十九，横切九个变十个：ADR-0032 第四条权限表、`GLOSSARY.md` 横切片一行、`map.md` 包数那一行要同步。检查器的规则表不跟着加一行，`TestProjectIsClean` 当场红。
- **横切包之间第一次开出一类新边**：任何横切包都可以依赖 `criterion`（它只碰标准库，依赖它不成环）。ADR-0032 第四条「横切包之间没有边、例外只有三条」按追加条读成四类边；`console` 与 `ask` 那两行的依赖清单也各加了一个名。
- 两条判据的行为测试进**自定义区**（`package criterion`）——它们断的是值，规范三.3 把值断言划出红线区；`parse/nodelist_test.go` 里那份前导零用例随之搬走，站点层面的那条（前导零不能当内联记录收下）留下。
- 凭据包剥前缀自此会多剥 `os.LinkError` 那一支——与老版一致；只有真碰到链接类错误才有差，现有 37 场 A/B 不覆盖这条路径。
- 这是本工程第一个「不产数据也不产能力、只放尺子」的包，边界靠准入判据守。放宽准入（比如「看着通用就放进来」）会让它变成第二个抽屉，这一条要靠复审时看包内容判断。

## 备选方案

- **塞进现有包**（`isIPv4` 进 `mask`、转义进 `message`、剥前缀留在两处）：零新增包、不动锚。否掉的理由是名字骗人、且 `SystemReason` 无处可去——留一份复制就还是「漂了没人红」。
- **塞进契约包**：全员可达，零新增包。否掉的理由是 ADR-0044 把契约定为「只装纸」，加函数要改那条 ADR，而纸的边界一糊，以后什么都能往里塞。
- **不建包，只把 `isIPv4` 收进 `mask`，其余留切换后**：改动最小。否掉的理由是它只解决六条里的一条，且留下了最难的那条（`SystemReason`）。

## 复审

- 方法纪律：判断这个包有没有变成抽屉，看它装的每一样能不能指出「第二处用它的那个包」，指不出来的就该搬走。
- 未证实：`os.LinkError` 一支在真实路径上是否会被走到，未验证——现有 A/B 不覆盖，只按老版源码对齐。
