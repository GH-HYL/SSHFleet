## 节点清单

清单就是一份纯文本，**一行一台服务器**，英文逗号分隔。用记事本或任何编辑器都能写。

```csv
# 以 # 开头的是注释，空行会被跳过
192.168.1.10
192.168.1.11
192.168.1.12
```

**只写 IP 就够了**——端口、用户名、密码都从配置里取（见 [配置手册](配置手册.md)）。

如果某台机器要用不一样的值，往后接着写。总共 6 列，按顺序：

| 列 | 内容 | 必填 | 不写时取哪里的值 |
| --- | --- | --- | --- |
| 1 | IP 地址（**必须是标准 IPv4**，域名不行） | 是 | —— |
| 2 | SSH 端口 | 否 | 配置里的 `port` |
| 3 | 登录用户名 | 否 | 配置里的 `user` |
| 4 | 密码 | 否 | 配置里的 `password` |
| 5 | 私钥路径 | 否 | 配置里的 `key` |
| 6 | 私钥口令 | 否 | 配置里的 `key_password` |

第 4 列和第 6 列**同一套规则**：默认（不加密）时填**明文**，打开加密之后填**文件的绝对路径**（见 [加密与密钥](加密与密钥.md)）。

中间某列不用、但后面那列要写时，留空即可（逗号不能少）：

```csv
# 第 3 列留空（用配置里的用户名），第 4 列单独给密码
192.168.1.10,,,node10pass

# 用私钥登录：前面留空，第 5 列给私钥
192.168.1.11,,,,/home/ops/.keys/id_rsa

# 私钥本身带口令：第 6 列给口令
192.168.1.12,,,,/home/ops/.keys/id_rsa,口令明文
```

**清单里的路径可以简写**：只写 `id_rsa` 这样的短名字，会拼到配置的凭据目录下；写绝对路径则原样使用。（配置文件里的路径必须写绝对路径，见 [配置手册](配置手册.md)。）

**取值顺序**：清单这一列 > 配置文件。清单里写了就覆盖配置。

从别处导出的清单如果**第一行是表头**（第一列不是 IP），工具会自动跳过它，并在终端提示一行。

### 一份都不用建：直接写一行

临时测一台机器时，`-f` 可以直接接一串服务器信息，不用建文件：

```bash
SSHFleet -f "192.168.1.10" -c "uptime"
SSHFleet -f "192.168.1.10,22,root,你的密码" -c "uptime"
```

写法与清单的 6 列一一对应：`-f` 后面的东西是已存在的文件就当清单文件，以 IP 开头就当内联的一行节点。

### 缺东西怎么办：报错，不问你

端口、用户名、密码这些，如果清单没写、配置里也没有，工具**不会停下来问你**——它会在**开工前**把问题一次报全，然后退出：

```text
发现以下错误:
行 3 (IP: 192.168.1.12): - 密码不能为空
行 7 (IP: 192.168.1.16): - 端口必须是1-65535之间的整数，当前值为：abc
```

报错会点到**第几行、哪一列、什么问题**。改完再跑一次。**检查通过就一定会尝试连接。**

## 四种操作

每次执行**只能选一种**：`-c` / `-s` / `-u` / `-d` 四选一。都配了 `-f`（清单）。

### 执行命令 `-c`

```bash
SSHFleet -f nodes.csv -c "df -h"
```

命令会在每台服务器上执行一次，输出实时回传。

**命令会套一层登录用户的 bash**（环境变量、`&&` 等行为与终端一致）。想直接执行原始命令，加 `--no-bash`。

**不能执行循环类命令**（`for` / `while` / `until` / `if` / `case` 开头）——请写成脚本用 `-s` 执行。

### 执行脚本 `-s`

```bash
SSHFleet -f nodes.csv -s deploy.sh
```

把本地脚本发到每台服务器执行，只支持 `.sh` 和 `.py`。需要 root 权限时加 `--sudo`。

### 上传 `-u` + `-p`

```bash
SSHFleet -f nodes.csv -u ./app.tar.gz -p /opt/
```

`-u` 是本地文件或目录，`-p` 是**服务器上的目录**。三条硬要求：

- `-p` 必须是**绝对路径**，且**以 `/` 结尾**（如 `/opt/app/`）。
- **远端目录必须已经存在**，工具不会替你创建；写错会在那台机器上报"远程路径不存在"并跳过它。
- 只接**一个**路径，不支持通配符。想传目录内容，直接写目录本身（`-u /本地/abc`，不要写 `/本地/abc/*`）。

**上传目录时保留内部的子目录层级，但目录自身那一层不会重复出现**：`-u /本地/abc -p /opt/` 得到的是 `/opt/<abc 里面的内容>`。想要 `/opt/abc/…` 这种结果，把 `abc` 的**父目录**传上去。

**远端已有同名文件时不覆盖**：逐个传，传到那个同名文件就停下——排在它前面的已经传上去，它自己和排在后面的都不传。有传成也有没传成的，那台机器的分类是"部分成功"；一个都没传成是"远程文件已存在"。两种情况在统计里**都算失败**。要覆盖就先把远端的旧文件清掉再传。

### 下载 `-d` + `-p`

```bash
SSHFleet -f nodes.csv -d /opt/logs/app.log -p ./downloads
```

`-d` 是**服务器上的路径**（必须绝对路径），`-p` 是**本地已存在的目录**。每台服务器下载下来的东西按 IP 分目录存放。

两条限制：

- `--sudo` 模式下的下载，**文件读取仍以登录用户身份进行**。权限 `700` 这类 root-only 的文件会读失败——先用 sudo 命令模式把文件搬到登录用户可读的位置，再下载。
- 下载用的目录枚举依赖目标机的 GNU `find -printf`（多数 Linux 发行版自带；busybox / BSD 环境不兼容）。

### 软链接怎么处理

上传和下载都**一律过滤软链接**（含 Windows 目录联接、`.lnk` 快捷方式），不传输也不中断执行。被过滤的条目会写进那台机器的结果明细里。

只有一种情况会报错：**过滤之后一个可传文件都不剩**（比如整个目录全是软链接）。上传时还会在终端额外提示一句：

```text
[提示] 上传源中有 3 个软链接/快捷方式被过滤（不上传）：...
```

## 参数表

| 短 | 长 | 说明 |
| --- | --- | --- |
| `-c` | `--command` | 命令模式：在每台服务器上执行一条命令 |
| `-s` | `--script` | 脚本模式：上传本地脚本并执行 |
| `-u` | `--upload` | 上传模式：把本地文件或目录传到服务器 |
| `-d` | `--download` | 下载模式：从服务器下载文件或目录到本地 |
| `-f` | `--csv-file` | 节点清单：文件路径，或直接写一行节点信息 |
| `-p` | `--path` | 目标路径：上传时的服务器目录 / 下载时的本地目录 |
| `-k` | `--key` | 这次用密钥登录（不加 = 用密码） |
| `-t` | `--timeout` | 命令跑完、文件传完的最长等待（秒） |
| `-T` | `--connect-timeout` | 连上服务器的最长等待（秒） |
| `-n` | `--number` | 并发数：同时操作几台（不填 = 全部并行） |
| `-r` | `--remark` | 任务名，用作结果目录名的后缀（不填自动生成） |
| `-a` | `--answer` | 代填：看到触发词就自动填内容（可给多条，或一个 CSV 文件路径） |
| | `--sudo` / `--no-sudo` | 用 root 身份 / 用登录用户身份执行 |
| | `--no-bash` | 命令模式：不套 bash，直接执行原始命令 |
| | `--yes` | 跳过确认，直接执行 |

## 代填 `-a`

有些脚本会停下来问你——选哪个架构、要 deb 还是 rpm。加上 `-a`，工具看到你写的触发词就自动把内容填进去：

```bash
./SSHFleet -f nodes.csv -s deploy.sh -a "1,请选择架构"
```

**值的写法**：逗号分隔，第 1 段是要填进去的内容，后面每一段都是触发词（看到它就填）。一条可以挂多个触发词：

```bash
-a "1,请选择架构,请选择CPU架构"
```

**多条一起用**：`-a` 可以重复给，也可以给一个 CSV 文件的路径——一行一条，第 1 列是内容、第 2 列起是触发词，列数不限，空行与 `#` 开头会被跳过。两种来源可以混用，顺序就是你给的顺序：

```bash
./SSHFleet -f nodes.csv -s deploy.sh -a "1,请选择架构" -a answer.csv
```

**多条是并行匹配的**：谁的触发词先在输出里出现就先用谁，与书写顺序无关（脚本会跳过提问，比如那台本来就是 deb、根本没问包格式）。脚本是顺序提问的，所以工具报「触发词未命中：第 1、2 条」时，**看最小的那个序号就够**——那是第一个出错的地方。防乱序填错靠的是把触发词写得有区分度，不是靠顺序。

**三条边界**：

- 每条**至少要有一个触发词**——触发词是唯一的门，不写等于无条件盲填，工具会直接报错
- 代填内容与触发词里**都不能出现逗号**（逗号是分隔符，写了会被拆成多个触发词）
- 第 1 段**留空**是合法写法，代表只按一个回车：`-a ",请按回车继续"`

**触发词要有区分度**：远端开着回显，你填进去的内容会被打回来，工具一样会拿它去匹配。

**两条收尾规则**（都算失败，在统计块里单独计数）：

| 分类 | 含义 |
| --- | --- |
| `触发词未命中` | 命令结束时还有代填没送出去：脚本没问，或问的话没认出来 |
| `代填用尽后超时` | 代填都送完了，脚本再没出声直到 `-t` 到点（卡在没配触发词的提示上、或任务本身就长，工具分不出） |

**密码过期的机器会被当场终止**：`-a` 运行里认到"密码过期"的提示就立刻结束该机器的会话、归「密码过期」，不会白等到超时。

`-a` **不能**和 `--no-bash`、`-u`、`-d` 一起用——原样下发与传输两类都没有「代填要喂进去的那条会话」，工具会明确报错而不是悄悄忽略。

## 密钥登录

工具**默认用密码登录**。要用密钥，加 `-k`：

```bash
SSHFleet -f nodes.csv -c "uptime" -k
```

私钥从清单第 5 列取，没写就取配置里的 `key`。密钥失败就是失败，不会回退用密码再试。

- 加了 `-k`，但清单和配置里都没有私钥 → 报错退出，并告诉你缺什么。
- **没加 `-k`，但清单第 5 列写了私钥** → 用密码登录，同时给一行提示（提醒你配了私钥却没启用）。
- 私钥本身带口令 → 在第 6 列给口令（或配置里配默认口令）。工具不检查第 6 列（它无从判断你的私钥加没加密），但如果解析时发现私钥是加密的、又没有口令，会明确告诉你该怎么办。

## 执行身份

默认取配置里的 `sudo` 字段。一次执行想临时改：

```bash
SSHFleet -f nodes.csv -c "systemctl restart nginx" --sudo      # 用 root
SSHFleet -f nodes.csv -c "whoami" --no-sudo                    # 用登录用户
```

## 并发与超时

默认**全部节点一起连**。服务器或网络扛不住时限流：

```bash
SSHFleet -f nodes.csv -c "uptime" -n 10
```

超时分两个：`-T` 管连接，`-t` 管执行与传输（按模式取配置里的默认值）。

```bash
SSHFleet -f nodes.csv -c "uptime" -T 15 -t 60
```

上传时工具会按**上传总大小**给一个并发数建议（不超过节点数；与当前值相同就不问），在参数屏之后决定要不要采纳。

## 备注

`-r` 给这次执行起个名字，它会成为结果目录名的后缀：

```bash
SSHFleet -f nodes.csv -s deploy.sh -r 发布v2
# → history/2026-09-22_14-30-00_script_发布v2/
```

不填会自动生成（命令模式取命令的首个词，脚本 / 上传 / 下载取路径的文件名）。

## 执行前你会看到两屏

顺序是固定的：**先危险提示，再参数确认**。

**第一屏（可能没有）：危险命令提示屏。** 工具在执行前会检查命令内容（命令模式检查 `-c` 的内容，脚本模式检查脚本全文），命中规则时列出每一条：

```text
╔════════════════════════════════════════════════════════╗
║                   ⚠  发现危险命令  ⚠                    ║
╠════════════════════════════════════════════════════════╣
║    来源: 命令                                          ║
║    行号: 1                                             ║
║    内容: rm -rf /var/log/*                             ║
║    规则: 递归删除系统目录                              ║
║    级别: 禁止                                          ║
╠════════════════════════════════════════════════════════╣
║    这条命令有风险，请确认你确实要执行它                 ║
╚════════════════════════════════════════════════════════╝

确定继续？ [y/N]
```

几个级别共用同一套版面，区别只在颜色；页脚文字按级别调整（禁止级是"此命令被禁止执行，程序将立即退出！"，直接退出、不给确认）。来源与行号用来定位命中（命令模式下来源是"命令"，脚本模式下是脚本路径 + 行号），内容显示你敲的原文。没命中任何规则时，这一屏不出现。

同一条命令命中多条规则时，只显示风险最高的那一条——所以 `rm -rf /var/log/*` 同时撞上"删除日志文件"（中）与"递归删除系统目录"（禁止）时，上屏的是禁止级。

**第二屏：参数屏。** 把这次要执行的东西摊开给你看——执行身份、操作内容、节点清单、节点数量、并发数、超时。看完确认：

```text
以上确认无误，开始执行？ [Y/n]
```

**上传模式在参数屏之后还有一步**：按上传总大小给出并发数建议；采纳的话，参数屏会**再显示一遍**（并发数那一行凸显）。

**级别决定后果**：`禁止` 级直接拒绝执行、工具立即退出；`高` / `中` / `低` 需要你确认一次。

规则写在 `config/dangerous_keywords.conf` 里，每条包含名字、示例、正则、级别。不想被某一条打扰，把它改成 `enabled = false`，或者用 `#` 注释掉整条。

## 不要任何确认

```bash
SSHFleet -f nodes.csv -s deploy.sh --yes
```

适合脚本和定时任务。加了这个，参数屏与确认全部跳过，直接执行。危险命令的处理不受影响：`禁止` 级仍然拒绝，其余级别放行但会在工具日志里留一条记录。

## 执行完，结果在哪

每次执行都会在 `history/` 下建一个目录，名字是「时间 + 操作类型 + 备注」：

```text
工作目录/
├── latest_history                      指向最新那一次的历史目录（快捷方式 / 软链接）
└── history/
    ├── SSHFleetTools.log               工具自己的运行日志（滚动保留全部历史）
    └── 2026-09-22_14-30-00_command_看磁盘/
        ├── terminal-output.txt         终端显示的文本记录
        ├── terminal-output.xlsx        同上，Excel 格式
        ├── report.txt                  汇总报告
        ├── results.xlsx                每台机器的结果明细
        ├── SSHFleetExec.log            本次执行的明细日志
        └── assets/                     本次用到的清单、脚本与代填文件的备份
```

回看历史有两个入口：进 `history/` 找对应时间的目录，或者直接打开工作目录下的 `latest_history`（它总是指向最新那一次）。

**哪台机器出了问题、细节是什么，都在那一次的目录里**——终端上只给汇总，逐台明细只写在 `results.xlsx`、`SSHFleetExec.log` 与 `terminal-output.txt` 里。

终端上，执行过程中会实时显示进度；结束后输出统计：总耗时、节点数量、成功与失败台数、失败原因分类。分类后面可能跟着一段"提示"（该分类的可能原因）。

明细在命令 / 脚本模式下会实时打在终端；上传 / 下载模式下终端只有进度条与个别提示，逐文件的结果写进 `SSHFleetExec.log` 与 `terminal-output.txt`。
