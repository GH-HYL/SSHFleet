# 地图：把新工程建起来，直到能顶替老工程

## Destination

走完这张图，`modules/SSHFleet2_Go/` 能顶替 `modules/SSHFleet_Go/`：五条命令五种模式真机跑通，产出与老工程逐字一致，退出码一致；切换那天只改发布脚本里一行目录名。

**和上一张图的分别**：上一张图只产决策、不写代码；这张图要写代码，工作量大，所以按**阶段**推进，一个阶段一个议题。

## 怎么推进（这张图的特殊之处）

1. **一个阶段一个议题**：下面的阶段表里每一行，开工时**单独新建一个议题目录**，它有自己的 `spec.md` 与工单；本议题只当总图与账本。
2. **一张工单一个会话**：阶段议题里的工单，以「一个全新会话装得下」为唯一拆分硬指标；一单一会话，做完把结论回填到该阶段议题的 `## Comments`。
3. **阶段做完回填这里**：在下面阶段表把状态改成「已结」，并追加一句结论到 `Decisions so far`。
4. **授权开工**：写代码要「授权开工」四个字，一次管一个阶段；交付后再动要重新授权。
