# 04: 起不来与拒绝

**要做的**：把闸门那两种失败做出来，并且**是两种类型**：前提缺一样（配置读不到、空的、格式错、必须项没配）叫「起不来」，谁都能造；前提齐了只是不放行（参数不合规、危险命令、人当场喊停）叫「拒绝」，只住闸门。做完这一条，工具在「不该跑」的时候能停住并且说清为什么。

**Blocked by**：03

**Status**：ready-for-agent

- [ ] 配置文件不存在、格式错、必须项空着，三种各跑一次：给出一句「起不来」，退出码与老工程一致
- [ ] 参数不合规（不认识的选项、缺值）、危险命令、确认屏上按 N，三种各跑一次：给出「拒绝」或取消，退出码与老工程一致
- [ ] 两种失败在类型上分得开：起不来的类型住通用类型包，闸门之外也能造；拒绝的类型只住闸门
- [ ] 闸门不写字、不打屏：那句话随「拒绝」交回塔尖，由塔尖交给终端包
- [ ] 红线区测试：闸门的入口只收一张纸、只交一张纸或一个拒绝
