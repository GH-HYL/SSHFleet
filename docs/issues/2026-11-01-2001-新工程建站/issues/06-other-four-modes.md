# 06: 另外四种模式

**要做的**：脚本、上传、下载、批量改密四种模式照命令模式那条路补齐。每种模式在契约里是各自独立的类型，装在一个带标签的格子里，标签与内容对不上由闸门验；结算只为五种模式写一套算法（通用格），模式多出来的东西放附加格原样递给报告。

**Blocked by**：05

**Status**：ready-for-agent

- [ ] 四种模式各跑通一次（真机或可接受的环境），屏幕过程、报告、落盘产出与老工程一致
- [ ] 标签与内容对不上时（比如声明上传却塞了命令）由闸门验出并拒绝
- [ ] 结算只算通用格；附加格一个字段都不打开，原样递给报告
- [ ] 改密的「每台走到哪一步、哪台要人工」在报告里出得来
- [ ] 报告里没有版本行（版本只随帮助出）
