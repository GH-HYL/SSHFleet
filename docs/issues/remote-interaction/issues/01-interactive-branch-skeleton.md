# 01: 交互分支骨架与 `-a` 贯通（内联单条）

Status: done
Blocked by: 无

**要做的**：给 `-a` 时走新的执行路径，让一条内联代填在真实远端交互上端到端生效——按触发词命中把内容填进去、按 `-t` 收尾；普通路径行为一字不变。

选路在 `batch` 的 `work()`，按「是否给了 `-a`」分流；新实现放新文件，不给既有执行函数加 `if`。入口收显式小结构（代填表 + 两个匹配开关），不塞进传输层的 `Config`。

**含**：`cli.Args` 加 `-a` 字段（pflag `StringArray`，不能用 `StringSlice`）与最小内联解析；`[interactive]` 段（`regex` / `case_sensitive`，默认均关，必填字段）；`-a` 与 `--no-bash` / `-u` / `-d` 互斥报错；帮助的选项行与示例行；CHANGELOG 开 `[7.0.0]` 段并抬 `appVersion`（新增必填配置字段属不兼容改动，按规范四抬主版本）。

**执行骨架**：PTY `xterm` 200×50、tty 模式传 `nil`；正文 base64 编入命令行、远端 `base64 -d` 后作内层解释器的 `-c` 参数（仅本分支）；`Start` + 写侧钩子 + `Wait()`；钩子入口去行尾 `\r` → 写 `lockedBuffer` → 喂匹配器 → 命中只发信号，送内容与 `session.Close()` 都由调用方执行；匹配只看游标之后、不按行、多条并行、命中后游标推进到触发词末尾；送出内容 = 代填内容 + 一个 `\n`（第一段留空 = 只发一个回车）；代填用尽后不做任何动作；超时与中断自带一份与既有同契约的包装（超时返回 `命令执行超时(%v)`、外部取消返回 `parent.Err()`）。
