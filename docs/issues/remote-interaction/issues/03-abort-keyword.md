# 03: 中止词

Status: resolved
Blocked by: 01

**要做的**：`-a` 分支内置的保险判据。关键词取错误判据文件「密码过期」分类（`KeywordsOf`，两块并集），匹配口径随 `[interactive]`。命中 → 立即终止该节点会话，`error` 写命中的原文行、退出码置 `nil` → 分类归「密码过期」。不参与代填匹配、不占代填条目、每节点至多触发一次。

中止词命中过的节点，收尾不做「触发词未命中」判定（见 04）——否则即时归因会被兜底分类盖掉。

依据：实测 M2 / M4 / M5——警告文本在第 0 秒出现、过期机器的对话必然挂死、警告期机器无警告文本。

判据文件第一组「密码过期」keywords 补两条实测原文：`WARNING: Your password has expired.`、`You must change your password now and log in again!`

- [ ] 密码过期的机器在会话开始即被终止，分类「密码过期」，明细里能看到命中原文行
- [ ] 警告期（未过期）机器不受影响，命令照常执行
- [ ] 中止词命中的节点不出现「触发词未命中」
- [ ] `go vet ./...` 干净、`go test ./...` 全绿
