# 03: 出厂配置收缩为两行 + 语言段

**要做的**：新装的工具，配置文件里 `[env]` 只剩两行——`PATH` 与压制彩色的 `TERM`；语言是另一段里的一个开关，编码不在配置里出现。用户往 `[env]` 里加自己的变量照旧生效，写 `LANG` 也照旧导出。

- [x] 用出厂配置实跑一次，下发行里没有 `LANG` / `LC_ALL`，有 `PATH` 与 `TERM`
