# 01: 下发行自带编码判断

**要做的**：目标机 locale 不是 UTF-8 时，工具让这条命令按字符算——`cut -c` 切中文不再切坏；本来就是 UTF-8 的机器上，这段判断运行时一个变量都不设。命令模式、脚本模式、代填三种下发形态同时生效，因为它们共用同一个环境段。

**Blocked by**：无，可立即开工
