# 卡点（本轮技能本身哪里不顺手）

1. **锚表有两份，必然漂**。`1.6` 要交接清单里放「锚，编号，标授权来源」，`2.2` 又要每份提示词带「大方向锚」。我照两处各写一遍，提示词那份在转述时把锚 2、锚 8 的「作者明示」削掉了——**分发审的 G11 抓的就是这个，而且它直接制造假硬伤**。建议：锚表只存交接清单一处，提示词写「锚见交接清单第三节，逐字引用」。
2. **`2.3` 说「不给分发审被证伪的历史」，但提示词包里本来就有一节背景**。要么把背景从提示词包里挪出去（子 agent 另给），要么在 `2.3` 明说「背景节随包给不算预设，只审设计」。我这轮选了口径自己判，属绕过。
3. **`3.3` 要求「自己核过的写明怎么查的」，但没说落哪个文件**。回执是只读的、`报告.md` 是三段式，没地方放核对过程。我自建了 `核对记录.md`，建议进 `1.6` 的产物清单。
4. **`2.4` 要求用 `my-grill` 问，但 `my-grill` 又要求先调 `grilling`**，两个技能的轮次口径没说能不能合并。本轮「测试环境」与「重点哪几条」是两个独立分支，我一轮问了，严格说违反了 `grilling` 的「一轮只问前沿、不混分支」。
5. **入场判据 `1.1` 的第三样「ADR 头部『实施载体』」在本轮不存在**——ADR-0030 根本没有这个字段（ADR-0024 才有）。三样里缺一样时是「不是主场」还是「字段不适用」，`1.1` 没说。
