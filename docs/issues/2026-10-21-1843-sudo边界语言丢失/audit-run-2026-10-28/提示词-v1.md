## 轴 2：片段语义（`ssh/command.go` 的片段 + 本地 shell 实测）

轴的切法来自代码结构：这一段是**唯一**碰目标机 shell 语义的地方，其余全是拼字符串。

覆盖：

1. `encodingFragment` 与 `LocaleFragment` 的**逐字行为**：在 `dash`（`/bin/sh`）、`bash`、`busybox ash` 下各跑一遍；分别造「charmap 是 UTF-8」「不是 UTF-8 且有候选」「不是 UTF-8 且无候选」三态。
2. 锚7 三条不变式逐条验：只动 `LC_CTYPE` 吗（`LANG`/`LC_ALL`/`LC_MESSAGES`/`LC_COLLATE` 有没有被碰）？会降级吗？**有没有往 stdout / stderr 漏字**（工具把两者合并采集，漏出去的字会进 `Output`、进日志、参与失败分类）？漏字要在「目标机缺某条命令」「候选不在」等场景下逐个看。
3. 副作用面：片段里用到的**变量名**在 `sh -c` 这一层留下的痕迹；片段的退出码会不会影响后面的解释器；`set -e`/`set -u` 有无影响（外层是我们自己的 `sh -c`，但用户脚本可能自带 `set -e`）。
4. 挑名逻辑：`grep -Eixm1 "c\.utf-?8|en_us\.utf-?8"` 对各类 `locale -a` 输出（`C.utf8`、`C.UTF-8`、`en_US.utf8`、`EN_US.UTF-8`、带尾随空格、两个都在）的取舍；挑到的名字回填 `LC_CTYPE` 是否被 glibc 认。
5. 字节与进程：实测片段字节数、`sh -c '<片段> <解释器>'` 整条字节数（锚8 的数字对不对，条件写没写清）；每次执行多起几个进程（锚「影响」节写 2–3 个）。
6. 位置与 sudo：片段在 `[env]` 的 `export` 段**之后**、`sudo` **之前**——这个位置按锚1/锚7 判对不对；`LC_CTYPE` 过 sudo 的 `env_check`/`env_keep` 这条路有没有被这轮改动碰坏（只按 ADR-0024 已证的机制看代码，不重跑 sudo）。

**文件域**：`modules/SSHFleet_Go/internal/ssh/command.go`（只这一份的片段与 `envHead` 相关部分）+ `command_test.go` 里对应断言；`build/audit_run_2026-10-28/轴2/` 下的实测脚本。**不碰** `cli/`、`batch/`、`config/`、手册。

## 轴 3：拼装链路与覆盖面（跨模块不变量）

轴的问题：这个包的全部约束是「**量的串 = 发的串 = 日志的串**」，而本轮给下发行加了一段恒在的片段、一个开关。哪条路没跟上？

覆盖：

1. 开关与片段的值从配置到下发**逐跳**走一遍：`config.Locale.English` → `cli.Args.English` → 各拼装入口 → `CommandSpec`/`DownlinkSpec` → `BuildCommand`/`InteractiveCommand`/`DescribeCommand`。有没有哪一跳漏了、有没有哪条路**根本拿不到**这个开关。
2. **五种模式**（命令 / 脚本 / sudo+命令 / sudo+脚本 / 代填 `-a`）逐一对照；另看**上传 / 下载 / 批量改密**这三条不拼 `sh -c` 的路——它们受不受影响、该不该受影响，按锚判。
3. `--no-shell`：锚8 说它不生效；代码里每一处分支是不是都守住了（含日志侧）。
4. **日志与下发同源**：`DescribeCommand` 打印的「命令行」与真下发那条是不是同一个值；「说明」那几行（`envNote` / `commandWho` / `scriptWho`）说的与命令行做的是不是一回事。
5. `-a` 的下发行在**解析/合规阶段**就拼好并存进 `Args.Downlink`，那条串现在多了 162–184 字节——长度检查量的还是同一条串吗？上限还够不够？
6. `CommandSpec` / `Options` 这两次重构（`a3dee5e`、`e8c47a7`）有没有把「执行与日志共用一份」真的做成单点，还是留了第二处填字段的地方。

**文件域**：`internal/cli/*`、`internal/batch/batch.go`、`internal/ssh/interactive.go`、`command.go` 的 `BuildCommand`/`DescribeCommand`/`innerCommand`/`scriptStdinInner`、`internal/output/*` 里引用「命令行」的文案。**不碰** 片段本身（轴 2）、`config/*.conf`（轴 4）、ADR（轴 5）。
