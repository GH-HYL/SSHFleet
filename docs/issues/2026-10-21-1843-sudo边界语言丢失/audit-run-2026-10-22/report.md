## 三、冲突点（双方原话抄录，不改写）

### C1 · A2 的支撑是否构成「锚质疑」

- **[轴 3]** `03:H4`：「冲突点不是「A2 错了」，而是：**A2 所依赖的那条实测（3.1）在其指定底本里被明确记为未做，且议题 spec 也把同一件事记为未验证。** 这属于「锚与议题 spec 冲突」的出口条件。」
- **[轴 1]** `01:§8`：「本轴没有发现需要动用「锚质疑」出口的证据。」
- **[轴 2]** `02:锚质疑`：「A2（拼接形态不变）：没有被实测推翻；3.1 的穿透在两台机器上成立。问题是证据只覆盖两台……属"证据不足"而非"与实测冲突"。」
- **[轴 4]** `04:锚质疑`：「A1、A2、A4 未发现与白名单内材料冲突。」

### C2 · A3 是否构成「锚质疑」

- **[轴 1]** `01:H2`：「A3 与文首的冲突是**文件内部**矛盾，不是锚与证据冲突，故记 H2，不动锚。」
- **[轴 4]** `04:锚质疑`：「质疑 A3：落点在 0016 不存在……A3 假设两份上游 ADR 都有「更新记录」容器。0015 有；0016 没有。」
- **[复核员]** `06:§3`：「A3 把「不碰正文」定为纪律，而 0015 的正文里正躺着一个 A1 会改掉的值；两者只能保一个。」

### C3 · 3.8 三个数字的定性

- **[轴 3]** `03:H5`（【硬伤】）：「3.8 的三个数字不可复核，且量级随未公开参数从 30.5% 漂到 100%……不能判 85% 为假，只能判「不可复核」。」
- **[复核员]** `06:N1`（【未发现问题】）：「85% vs 90% 的差属语料与实现不同，**不足以判 ADR 数字错**。缺的是**产物**……这条应记「无产物但可复算」，而不是「从未产出」或「数字可疑」。」

### C4 · 文首「收窄 0015」与决定 3 的定性

- **[轴 1]** `01:H2`（【硬伤】）：「同一件事（0015 的「影响」一节是否被收窄）出现「收窄」与「不收窄」两种说法。派生 spec 时无法判断该不该动 0015 的那段正文。」
- **[复核员]** `06:J1`（【判断题】）：「两者可以并存——如果 `0024:24` 的「收窄」指**语义上缩小适用范围**、「正文」指**文本不许动字**。但冷读者读不出这层区分。」

### C5 · 12.2 的「补法」列

- **[轴 4]** `04:H8`（【硬伤】）：「本节自述与内容自相矛盾」；同回执 §3：「按 `doc-guide.md` 第六节……**是**。它有命令、有观察对象、有判定口径……正因为它可执行，它是**工单形态**。」
- **[复核员]** `06:J2`（【判断题】）：「12.2 的「补法」是不是**待办**，取决于怎么读：它可以是「这个未证实项的**可观测判定条件**」（合法），也可以是「下一步要跑的命令」（即待办，越界）。」

### C6 · 6.1 四句「永远」

- **[轴 2]** `02:H2`（【硬伤】）：「是四句全称。前两句在"locale 相关"范围内成立，后两句作为字面全称被 python / node / uutils `wc -m` 直接推翻。」

### C7 · 2.2 的命令能否照抄复现

- **[轴 4]** `04:H5`（【硬伤】）：「外层是**双引号**，`$LANG` / `$LC_ALL` 会先被本地 shell 展开……按原文照抄，无论 sudo 怎么重置都观察不到「`LANG` 被重置成 `C.UTF-8`」。2.2 记的观察只能来自另一个（未记录的）写法。」

### C8 · 「最后核对：无复审」

- **[轴 4]** `04:H3`（【硬伤】）：「同一份文件的两处元数据对「有没有复审过」给出相反答案。」

### C9 · 第四节「工具不产生乱码」的范围

### C10 · 9.1 与 9.3 的版本并存

- **[轴 3]** `03:H2`（【硬伤】）：「`0024:321`「Ubuntu 26.04（coreutils 9.5）」 vs `0024:331`「uutils 0.8.0」。两者不能同真。」
