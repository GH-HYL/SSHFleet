# 01: 把改密这条路接到真机上（不含喂入）

Status: resolved
Blocked by: None

**要做的**：`--change-password <密码>` 成为第 5 档执行模式，并让这条路真实走到目标机上——建立会话、分配 PTY、下发 `exec :`、拿回退出码。此时**还不喂任何输入**，所以过期机器会挂到 `-t` 超时（下一票解决），这一票要证明的是"路通了"。

参数与合规：模式五选一（与 `-c`/`-s`/`-u`/`-d` 互斥）；与 `-a`/`-p`/`-k`/`--no-bash`/`--sudo`/`--no-sudo` 互斥并写明原因；允许 `-f`/`-n`/`-t`/`-T`/`-r`/`--yes`。取值随 `credential.encrypt`：`false` 时参数就是明文密码，`true` 时是密文文件路径——走现有凭据读取件拿明文，**不做**"文件还是文本"的自动判定。它的值**不进**路径规范化与空格禁令（密码可含空格）。纳入 `batchParamsGiven`（与密钥管理命令同理，避免参数被悄悄丢掉）。

模式名 `passwd`：进 `cli.Args.ModeName()`，归档目录名即 `<时间>_passwd`（备注默认为空），报告「执行参数」、执行期日志文案、统计口径各处都认它。

执行体：新实现文件，照抄交互分支的超时与中断契约（到点 `session.Close()`、外部取消返回上级错误），会话形态与实测一致（PTY 200×50 + `exec :`）。**绝不传中止词**——「密码过期」那几个词在改密里是入场信号，带上中止词会在第 0 秒把自己的会话杀掉。

脱敏与版本号跟着这一票一起落，**不能先落一个会泄密码的版本**：新密码在工具日志（含「原始命令行参数」那行）、报告、参数屏一律按 `common.MaskSecret` 脱敏（明文密文都脱）。`common.MaskCommandLine` 现在只按"内联清单形状"脱敏，要**按旗标名**补一条规则（`--change-password` 与 `--change-password=X` 两种写法）。版本抬 `7.1.0`（CHANGELOG 段头 + 入口常量同一次提交同步改），CHANGELOG 开新段。
