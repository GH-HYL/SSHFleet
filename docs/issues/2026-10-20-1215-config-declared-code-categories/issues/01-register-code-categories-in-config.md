# 01: 由程序定性的失败分类，改由配置登记名字

**要做的**：跑一次改密、目标机一句话都没回就超时，统计块里「没等到提示」这类分类出现在「失败分类统计 >>>」那一行（与其它已知分类并排），而不是缩进混在"未归类"里；并且决定这件事的只有配置文件——把那条名字登记删掉、它的提示语一起消失，登记写上它就在正常位置。代码里不再有一张"这些名字不用登记"的名单。

**被谁阻塞**：无，可立即开工。

**状态**：done（2026-10-20 实施）

- [x] 判据配置补登记：改密判据配置里加上「提示词没认出」「没等到提示」「远端无响应」（只留名字与提示语，不带关键词）；通用判据配置里加上「部分成功」。
- [x] 判定包里那张"代码定性名字"的手写名单删除；"是不是兜底原文"只剩一条规则：判据表登记了名字就算已知（两块并集）。
- [x] 统计块渲染：上述分类落在「失败分类统计 >>>」行；不认识的报错原文照旧单排并给"把特征词补进配置"的引导。

- [x] 用例：`部分成功`、`提示词没认出` 判为非兜底；一段不在配置里的报错原文判为兜底；`""` 与「原因未知」仍判为已知（既有语义）。
- [x] 用例：加载一份"有名字无关键词且未标明定性"的判据表 → 失败且报错含该分类名；标明定性后 → 加载通过。

- [x] 升级验证：拿改动前的旧配置（没有这四条新登记）启动，程序正常启动、不报配置错误。
