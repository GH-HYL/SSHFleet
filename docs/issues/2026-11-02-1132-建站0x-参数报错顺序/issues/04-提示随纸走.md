# 04: 提示随纸走，由确认段印

**要做的**：「第一行不是 IP，已当表头移除」与「清单里配了私钥、本次没加 `-k`」这两句，不再在路上当场打；随纸带下来，由闸门在确认段开头印。于是被拒绝的那次、这次根本不出屏的那次，屏幕上不再先冒出这两句；`--yes` 跑成功的那次照印，排在「跳过确认」那行与参数屏之前。

同一个决定还有半句口径：`--yes` 只关「问」不关「说」。陈述「工具对这次输入做了什么、没做什么」的是事实，照说；陈述「你以后该怎么做」的是教学，`--yes` 下不说。这条判据写进 `message` 的说明。

**Blocked by**：02（要借「这次别出屏」那条路，才有「不出屏的那次」可验）。
