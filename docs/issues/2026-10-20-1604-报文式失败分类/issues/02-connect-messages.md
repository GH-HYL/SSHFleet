# 02: 报文格式落地（含全部结构性分类）+ 校验规则改到终态 + 建连一摊先改

**要做的**：这一刀切穿全部五层，做完之后**框架就定死了**，后面四张只是照抄。具体是三件事捆在一起做，因为它们互相依赖：

1. **报文格式与生成能力**：`sshfleet.<环境>.<环节>: <英文描述>` 在最底层的公共包有一处声明；七种环境取值写进代码注释。
2. **结构性分类改为发报文**：11 个中文分类常量全部退役，其中 10 个改由看见事实的那一处在收尾时发一句陈述事实的报文（第 11 个「密码过期」是远端说的话，不走报文，见 ADR-0021 决定第 9 条）。**这一条必须在 02 就做完**——否则 `code_defined` 删不掉，校验规则也就改不到终态。
3. **校验规则改到终态**：`code_defined` 字段与它配套的「写了名字却没关键词就报错」一并删除；此后配置里一条分类只要写了 `name` 就合法（没有关键词 = 永远匹配不上、落到未归类，由使用者自己负责）。

`connect` 一摊是这次端到端演示的样本：连一台**端口没开**的机器，屏幕上那行错误从 `建立连接失败 - dial tcp …: connect: connection refused` 变成 `sshfleet.connect.refused: dial tcp …: connect: connection refused`（原样，不翻译），统计块里那一类的名字仍是「拒绝网络连接」——名字来自配置。

**被谁阻塞**：01（摸底清单）。

## 验收

- [ ] 报文格式与七个环境取值在最底层的公共包有一处声明，判定包与各生成方都只引用它，谁家都不自己拼前缀。
- [ ] **11 个中文分类常量全部退役**，其中 **10 个改为发报文**（部分成功、触发词未命中、代填用尽后超时、密码未过期、提示词没认出、没等到提示、远端无响应、改密未完成、任务已取消、建连被取消），报文内容陈述事实（`sshfleet.transfer.finished: 6 of 10 files transferred`），**不写 `partial` / `failed` 这类结论词**。
- [ ] **第 11 个「密码过期」不发报文**（ADR-0021 决定第 9 条）：它是远端说的话，不是工具的话。它的分类改为走输出原文匹配，但**入场信号与中止词不能一起丢**——两者都按分类名查判据表（这条依赖保留）。所以删这个常量时，把「按名查表」的入口从「常量」改为「取关键词那处入口里的字面量」，并在注释里写明它为何不能改。
- [ ] **报文由执行侧各摊的收尾处发**，每摊「形态 → 报文」抽成一个**导出的纯函数**（入参是布尔与计数，不是整个结果结构），并给它包外测试——「不测私有函数」这条约定不接受包内私有口子。
- [ ] 判定里「一级定性」那段分支删除；不再有任何「按结构字段直接给分类名」的路径，也不再靠「报错原文空不空」去挑分类名（`提示词没认出` / `改密未完成` 两条分支消失）。**改密「干净收场」判断里那条「报错原文为空」保留**——报文只在非成功形态下写，它读作「没有事实要陈述」。
- [ ] 成功规则只多一条，且只加在命令 / 脚本 / 代填上：**报错原文里出现报文（以 `sshfleet.` 开头）即不算成功**。回归测试要证明「代填没送完但命令退出 0」仍归「触发词未命中」、不会被判成成功。传输与改密两条成功规则不动：前者失败数必须为 0，后者「干净收场」已经要求原文为空。
- [ ] **一处都不许把已有内容盖掉**：报错原文那一格在写报文之前可能已经有权威原文（建连被中断时是 `dial tcp …`，传输部分成功时是最后一条逐文件失败原因），报文一律**追加在后**，顺序「原文在前、报文在后」。
- [ ] `code_defined` 字段、它的校验、以及「写了名字却没关键词」这条概念一并删除。配置里一条分类只写 `name` 就合法。
- [ ] `connect` 一摊的中文前缀改为报文：建连失败、握手超时、密钥解析失败、认证失败相关。
- [ ] **`*ssh.ExitMissingError` 不再被丢弃**：按 ADR-0021 第 8 条「只许无损翻译」，由执行侧翻成 `sshfleet.session.exit_missing`，配置里那条关键词从库的提示原文改为报文。
- [ ] **不新增译文层**：终端明细、`output.txt`、`report.txt`、`results.xlsx`、执行日志一律显示报文原文，前缀不摘、术语不翻。
- [ ] 认不出的报文照旧显示原文，不吞、不猜；统计块里分类名没匹配上时回落成报文原文（与今天回落成中文原文同一个位置）。
- [ ] 判据文件里 `握手超时`、`无法建立会话` 两族的条目按报文改写；`拒绝网络连接`、`连接超时`、`握手超时` 等分类归属与改造前**完全一致**（分类语料全绿）。
- [ ] 既有测试里以中文错误文本作输入的用例改为以报文作输入，期望分类不变；断言措辞的期望值同步更新；断言分类语义的不动。
- [ ] `go build ./...`、`go test ./...`、`go vet ./...` 通过。
