# 09: 中断、拒绝与起不来那几场

**要做的**：做完之后，「跑到一半按 Ctrl+C」「被闸门拦下」「压根起不来」这三类收场在新老两版上一致：哪几台落盘、统计写什么、磁盘上留不留归档目录、退出码多少。

**Blocked by**：01、02、03、04、05

**Status**：ready-for-agent

- [ ] 中断一场（两台规模）：发一次 SIGINT，两侧都是「提前收工」——已完成的落盘、未跑完的不造行、统计里写「未执行：N（执行被中断）」
- [ ] 中断那场的退出码按既定口径（130 或 0）两侧相同
- [ ] 拒绝一场：危险命令答否，两侧屏相同、退出码相同，磁盘上都不留本次归档目录
- [ ] 起不来两场：配置读不到、必须项缺，两侧那屏相同、退出码同「起不来」
- [ ] 中断窗口造不出来就写明理由并记成「未验到」，不许拿「跑完没报错」顶上
- [ ] 各场结论逐行进 `audit.md`

**不在这单**：改密 `no_prompt` 与那几句只有代码没有用例的报文——造不出条件，本阶段不为它们硬造环境。
