# 实测报告：阶段 09 的两版对照

**这一份对的是哪两版**：老工程 `modules/SSHFleet_Go` 自 `e943029c1727` 未动；新工程 `modules/SSHFleet2_Go` 为 `0731b73e2f574d94dc5920aaede9ea7cb9ee2e09`（含端口修正、清单副本保真、字符串引号三笔）。两侧都用 `go1.26.10 linux/amd64` 在 WSL 里编出来，二进制同名 `sshfleet`，构建标识同为 `v1.0.0+0731b73 (2026-11-06 17:37:56)`。

**怎么复跑**（沙盒 `build/建站09_AB_2026-11-06_1535/`，不进仓库）：

```
wsl -d Ubuntu-26.04 -- su - ubuntu -c 'bash <沙盒>/run.sh'          # 不碰机器的场面
wsl -d Ubuntu-26.04 -- su - ubuntu -c 'bash <沙盒>/run.sh --all'    # 连要机器的也跑
```

`run.sh` 读 `scenes.tsv`（由 `gen_scenes.py` 生成，字段用 `\x1f` 分隔），每场两侧先复位再跑，`cmp.py` 归一化后比屏幕、退出码、`report.txt`、`terminal-output.txt`、`SSHFleetExec.log`、两张表、`assets/`、`latest_history`。

**归一化只动**：两种时间戳写法、两种耗时写法（含两张表里的耗时——`results.xlsx` 的 G、H 两列数值格，`terminal-output.xlsx` 详情里那句 `0.0xxs`）、沙盒路径与两侧目录名／各自 HOME、归档目录名里的秒级时间戳、xlsx 的 zip 时间戳与列宽。

**自检**：把 a1 的屏幕多打一行，`cmp.py` 报「差异：屏幕」且退出码 1；改回后退出码 0。表里的「一致」不是白跑的。

## 清单副本：定成「cp 加遮罩」（2026-11-06，开发者定）

开发者原话的意思：那份东西本质是**副本**，就该原封不动搬过去，一个字节都不该动；只因为安全性才加遮罩，那就**只动遮罩那几处**。

原实现不是这样：整行按 CSV 读出来、再按 `csv.Writer` 的规矩拼回去，BOM 在读的时候被吃掉、原本带引号的值被改成不带（或反过来）。改法（`cff7a9a`）：按行定位凭据那两段（第 4 列密码、第 6 列口令）在原行里占的字符区间，就地替换，其余字节照搬。

| 输入 | 老版副本 | 新版副本 |
| --- | --- | --- |
| `10.0.0.1,22,root,hunter2,/k/id_rsa,sekretpass` | `10.0.0.1,22,root,hu****r2,/k/id_rsa,se****ss` | 同左（逐字节一样） |
| 同上但带 BOM | 整行原样，**密码明文留在副本里** | BOM 留着、密码遮成 `hu****r2` |
| `10.0.0.2,22,"root,ops",pw12345,,pass99` | 引号按 CSV 规矩重排 | 引号原样，只换 `pw****45` 与 `pa****99` |

**带 BOM 那一行两版仍不同**：新版遮、老版不遮。老版这里是个安全缺陷（明文密码跟着备份），不是这次改出来的；按规格第二节「结构优先于一致」，登记为允许的不一致，理由就是「老版那行为本身是错的，回改等于再存一份明文」。复跑：`build/建站09_AB_2026-11-06_1535/probe_bom.sh`。

## 配置取值的引号：定成「按值的类型判」（2026-11-06，开发者定）

开发者定的口径：**要不要引号看值的类型**——数字（`2201`）、布尔（`true`／`false`）不带引号，字符串一律要带。

按这条回看，出问题的是新版：新工程自解析的词法器（`internal/parse/toml.go`）拿到 `password = /tmp/x` 这种裸值照收（`unquote` 拿不到成对引号就把原文当字符串），老版用 TOML 库当场报语法错。改法（`0731b73`）：原文表存**原文**（引号留在里面，`rawView` 不再提前剥），取字符串走 `stringOf`——必须成对引号；int、bool 那两格带引号本来就过不了 `Atoi`／`true`/`false` 那道关。

裸值配置两侧现在都「起不来」、退出码同为 1，话不同：老版转述 TOML 库那句（`toml: line 11 (last key "account.password"): expected value...`），新版点名哪一格、怎么改（`account.password 取值非法：/tmp/fleet09-pw（字符串值要带引号）`＋提示行）。**屏上的字属允许的不一致**——老版那句是库的原文，抄它等于给自己的解析器套别人的报错；判「没扩大」看的是：同为起不来、同为退出码 1、都带一句提示。复跑：`build/建站09_AB_2026-11-06_1535/probe_quote.sh`。
