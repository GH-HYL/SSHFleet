# 规格：比对口径收紧

**状态**：ready-for-agent（01–06 已落、31 档自检全绿；07 收口复跑被 4.5 挡住）
**底本**：`docs/issues/2026-11-09-0945-切换前回顾审计/修复面盘点.md` §4.4（2026-11-09 15:10 裁 A）与 §五乙批；事实底本 `docs/issues/2026-11-09-0945-切换前回顾审计/audit-run-2026-11-09/回执/03-等价口径.md`（E1–E13）
**边界**：只改尺子、只出一份新结论；不动被测代码（4.5 九条另议）。

## Problem Statement

「可切门槛第三条：逐字比对最近一次通过」靠的是 09 那把尺子——`build/建站09_AB_2026-11-06_1535/cmp.py` 与 `ab.sh`。审计逐项对过，这把尺子自己放宽了六处：`results.xlsx` 的 G、H 两列整格不比；单元格类型不比；「逐字节」实为 UTF-8 有损解码后的逐字符；工作表名不在比对面；十九场没有归档、只比了屏幕与退出码；屏幕面全程没有 TTY。它判出的「通过」在那些面上永远成立。轮二、轮三靠实跑另抓到的五条差异全部落在 37 场之外，正是这个后果。

## Solution

在新沙盒里复制一份改严的尺子，历史沙盒按审计边界一字不改。改完之后：能比的面比原来多；不比的面临结论里逐条写明代价，不再出现「清单没登记而实现改了」的情形。只复跑受口径改动影响的场次，TTY 面补上场景；新结论单独出一份，旧结论原样留档并标明它依据的是哪把尺子。

## User Stories

1. 作为维护者，我希望「逐字节一致」真的是按字节比，而不是先按 UTF-8 有损解码再逐字符比——否则两侧出现不同的非 UTF-8 字节会被报成一致。
2. 作为维护者，我希望单元格类型参与比较：端口那一格从数字变成文本能被判出来（07 阶段就是把这一类判成真差异并改了代码）。
3. 作为维护者，我希望耗时两列按语义比——归一化之后仍然比，而不是整格跳过、还把这笔登记成「归一化耗时」。
4. 作为维护者，我希望工作表名参与比较：交接清单把它写成等价要求，判据里就该有它。
5. 作为维护者，我希望每一场都写明「本场应产出哪几样」，该有的没有要报，而不是两侧都没产出就算一致。
6. 作为维护者，我希望结论里逐场写实际比了几样，不再出现「每场都比这八样」这种与实测不符的表述。
7. 作为维护者，我希望工具日志参与比较，这样已知差异第一条的「没扩大」才有判据可依。
8. 作为使用者，我希望屏幕那一面（进度面板、折行帮助）也有场景覆盖，而不是只证明了非 TTY 输出等价。
9. 作为维护者，我希望新口径的结论与旧结论分开存放，各自标明依据的口径，不拿旧数字对新代码。
10. 作为维护者，我希望这套脚本能自己证明还活着：改一处即报差异、改回即绿。

## Implementation Decisions

- **新沙盒**：`build/比对口径_<时间戳>/`，车架从 09 沙盒复制；`build/建站09_AB_2026-11-06_1535/` 不改（审计边界）。
- **按字节比**：三份文本件与屏幕改为「作用在 `bytes` 上的归一化 + 按字节相等」，不做 `decode(..., "replace")`。
- **单元格身份**：一格 = 列行 + 类型 + 值。`t="s"` 查回文本后仍带「字符串」标记，数字格带「数字」标记；样式索引、列宽、zip 条目时间仍不比，理由进登记表。
- **耗时两列**：按语义比——类型必须相同，数值归一后仍参与比较；不采用「按列名整格跳过」。口径若确有不成立处，只许在结论的登记表里逐列写明理由，不许静默跳过。
- **工作表名**：读 `xl/workbook.xml` 的 sheet 名与顺序入比对面；`sharedStrings` 本身仍不比（去重副作用，09 已踩过）。
- **归档面**：场景表增一列声明本场应产出几样；`cmp.py` 依这一列断言，不依「两侧都空」判一致；`c1`（被拒不许建归档目录）声明为 0 样。
- **TTY 面**：伪终端采集与现有重定向采集并存，两种屏幕都进比对面。
- **登记表**：脚本 docstring 与实际动作一致，多抹一样必须在结论登记表里有一行。

## Testing Decisions

- 接缝只有一个：脚本对外的命令行口子（`cmp.py <场景名>`、`run.sh`、`selftest.sh`）。不测脚本内部函数。
- 每条改动的判据一律是「副本里改一格产物 → 报差异且退出码 1；改回 → 退出码 0」。
- 先例：09 沙盒的 `selftest.sh`（比对脚本的自检）、04 阶段的伪终端整屏比对。
