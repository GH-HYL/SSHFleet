# 09: 脚本模式在目标机上跑起来

**要做的**：`-s` 给的脚本在目标机上跑完、收回输出与退出码，屏幕上出一条结果行、盘上留一份明细，分类按判据表给。做完之后，脚本模式端到端可用。

**Blocked by**：03（解释器与正文）、01（纸）。

**Status**：ready-for-agent

- [ ] 下发串与命令模式同形，差别只有两处：正文走 stdin、`$0` 补脚本文件名（脚本常从自己的名字里取信息）
- [ ] 集成用例：`u1` 上跑一个打印 `$0`、参数与 stdin 读到内容的脚本，输出与老版一致
- [ ] 判定：会话起来了、退出码为 0、没超时没取消、报错原文里没有工具自己的报文 ⇒ 成功
- [ ] 执行期日志带「登录方式」（`NodeResult.AuthMethod` 由建连那一步填）
- [ ] `gofmt -l .` 空、四项检查与 `go test -race` 绿

**不在这单**：代填（10）、传输（11–13）、改密（14）。
