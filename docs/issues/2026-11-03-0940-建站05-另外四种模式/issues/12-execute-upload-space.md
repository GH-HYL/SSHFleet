# 12: 传之前先看一眼空间

**要做的**：写第一个文件之前先看目标侧与暂存侧还剩多少，装不下就停在原地——目标机上不会有本次的任何东西；探不到就少判一侧，绝不因此挡住上传。

**Blocked by**：11。

**Status**：ready-for-agent

- [ ] sudo 与非 sudo 两侧各按自己的峰值判：目标侧按本次总量，暂存侧按最大单文件
- [ ] 探不到数时降级（少判一侧）；两侧都探不到等于没有预检
- [ ] 位置在本地文件可读性预检**之后**：本地读不了是更近的原因，不该被「磁盘满」抢先报
- [ ] 写到一半失败后再探一次、确实不够才改口——**必须在回滚之前探**，回滚会把空间还回去
- [ ] 集成用例：容器里挂一个小容量 tmpfs 当目标目录，传超量文件 ⇒ 那台目标机上零残留
- [ ] `gofmt -l .` 空、四项检查绿

**不在这单**：不改上传的主流程与回滚口径。
