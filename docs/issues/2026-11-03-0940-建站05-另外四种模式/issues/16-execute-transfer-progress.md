# 16: 传输类换成逐节点进度面板

**要做的**：上传与下载跑起来时，屏幕上那块从「一行总进度」换成逐节点视图：第一行总进度（条 + 速度 + 已传／总量），第二行节点进度（条 + 耗时 + 台数 + 成功失败），一条分隔线，下面最多 20 条逐节点（条 + 速度 + IP + 文件数）。命令、脚本、改密仍用原来那一行。

**Blocked by**：12、14（要有真实字节进度可画）。

**Status**：ready-for-agent

- [ ] 已完成节点让出显示位，排队中的按序补位；同时在显示的节点不超过 20 个
- [ ] 速度按 2 秒滑动窗口算；总进度按台数求和（**不许**用「已传字节 ÷ 已开始节点的字节总量」——那会先冲满再回落）
- [ ] 非终端不出面板，结果明细直接落流（老版同一判据）
- [ ] 进度事件按 200ms 节流，节点完成时立即渲染一帧
- [ ] 面板渲染有断言（形状与显示位数）；`gofmt -l .` 空、四项检查绿

**不在这单**：不改命令模式那一行面板的形状（04 已定，逐字节 A/B 过）。
