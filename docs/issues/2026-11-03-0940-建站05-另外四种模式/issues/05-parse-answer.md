# 05: 代填表读得出来

**要做的**：`-a` 的值（一条内联，或一个 CSV 文件）解析成代填表：第 1 列是内容、第 2 列起是触发词，一行一条。做完之后，这张表躺在纸上，执行站照着喂；报告照着印。

**Blocked by**：01（需要 `Answers` 那一格）。

**Status**：ready-for-agent

- [ ] 来源判定与 `-f` 共用一处：先按路径交给系统、不是文件再看能不能当一条记录读
- [ ] CSV 读法与清单共用同一份实现：`#` 注释、空行、BOM、引号成对、变长列，口径一致
- [ ] 四种错各有能照做的一句话：缺触发词、触发词为空、一条都没有、文件读不到／是二进制
- [ ] 正则模式下触发词在本地预编译，语法错当场拦下（不留到运行期静默不匹配）
- [ ] 代填表进纸（命令与脚本载荷各一份 `Answers`）
- [ ] `gofmt -l .` 空、四项检查绿

**不在这单**：三条互斥与下发行长度（08 号单，闸门判）、下发行与交互会话（11 号单）、确认屏的代填行（09 号单）；「这个解释器支不支持代填」也不在这单——那张表住执行站，判在 11 号单。
