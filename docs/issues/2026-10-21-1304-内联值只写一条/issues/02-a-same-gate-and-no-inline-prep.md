# 02: `-a` 与 `-f` 同一套判定，装载期不再整备内联值

**要做的**：`-a` 的取值与 `-f` 走同一个判定、同一套报错：路径就交给系统找，不是文件再看能不能当一条代填读，都不是就报「文件不存在」。内联值不再有任何整备步骤——`;;` 与字面 `\n` 都只是普通字符，真换行直接拒绝；代填 CSV 文件那一侧的口径一个字不动。
