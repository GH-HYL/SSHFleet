# 01: 内联值改认 `;;` 分行，字面 `\n` 回到普通字符

**要做的**：命令行里用内联方式给 `-f` 清单或 `-a` 代填时，用 `;;`（两个连续分号）分行；写 `D:\new\pw.bin`、`D:\nodes\x` 这样的 Windows 路径不再被切开。内联里的字面 `\n` 按普通字符原样保留，不再有转义语义。代填侧的 `.csv` 文件能力不受影响，带真换行的内容仍走文件。
