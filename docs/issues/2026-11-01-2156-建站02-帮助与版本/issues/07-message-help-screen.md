# 07: `message` 把帮助排成一屏

**要做的**：把「程序名 + 版本串 + 选项表」排成一整屏帮助文本，宽度给了就折行。做完之后，终端只要把它打到屏幕上，使用者看到的就是说明书那一屏。

排版规则全部照老版：**列宽按四列各自的最大宽度算，说明列从固定的起始列开始，宽度不够时在说明列内折行**——折行不许串到别的列去。

**Blocked by**：02（要它那套量／截／折）。

**Status**：done

## 判据

- **屏的结构**照老版八段：首行（工具名与一句说明）、版本行、空行、`用法:` 与两行用法、空行、`选项:` 与空行、五组选项（组间空行）、`示例:` 与八行、结尾一句。
- **缩进与列距**：组标题缩进 2 个空格，选项行缩进 4 个；短名与长名之间 **1** 个空格，其余列之间 **2** 个空格；四列各自按本列最大宽度右补空格。
- **说明列起点**由「缩进 + 短名列宽 + 1 + 长名列宽 + 2 + 标记列宽 + 2」算出来；可用宽度是「终端宽度 − 起点 − 1」，**保底 24 列**；终端宽度为 0 时整行不折。
- 折行后的续行从说明列起点开始，不用再补前几列的空格。
- **示例块**：标签列按最宽标签右补空格，再空一格接命令；结尾一句指向 `docs/`。
- **示例整块归这里**（标签与命令都是文案），但里面出现的选项名必须与选项表对得上——两处各写一份迟早漂移，用一条断言把它钉住。
- 选项事实的类型与构造入口住在这个包（解析站照着它填），一个字的文案都不许解析站自己拼。
- 这一屏不上色。

## 验收

- [x] `go test ./...` 绿；`go vet ./...`、`gofmt -l .` 干净
- [x] 宽度 0（不折行）与宽度 80 两档，各用一份固定木偶数据逐字断言整屏；期望串录自老工程同一份数据，不用被测代码自己算
- [x] 一条断言专判「说明列折行不串列」：造一条长说明，折出来的第二行起始列等于算出来的列起点
- [x] 一条断言专判「终端太窄时保底 24 列」：给一个很小的宽度，说明列仍按 24 列折
- [x] 一条断言专判「示例不漂移」：示例里出现的每个 `-x` 与 `--xxx` 都能在选项表里找到，找不到就红
- [x] 一条断言专判「空标记不留双空格」：整表都没标记时，那一列宽为 0，两个 2 空格照旧不塌陷也不多出一列
- [x] 拼出来的屏里不出现制表符，也不出现超过宽度的行（宽度 0 档除外）
