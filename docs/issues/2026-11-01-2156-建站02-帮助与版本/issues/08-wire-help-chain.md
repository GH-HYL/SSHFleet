# 08: 把塔尖→解析→拼句→终端接起来，让 `-h` 出一屏

**要做的**：敲 `sshfleet -h`，屏幕上是那一屏帮助，进程以 0 退出；一个参数都不给也一样；`config/SSHFleet.conf` 读不到时是一句话加非 0 退出。做完之后，新工程第一次有了一条从入口走到屏幕的完整链。

**Blocked by**：01（塔尖要读 `os.Args`）、02、03、04、05、06、07。

**Status**：done

## 判据

- **塔尖只做三件**：把 argv 交给解析站、把回来的那句话交给终端、按结局给退出码。它不拼句子、不判「该不该看帮助」、不读配置文件。
- **解析站的入口只有一个函数、两个参数**：argv 与那个版本号；返回「一句话」加「是不是起不来」（零值表示不是）。不导出任何第二样东西（出口白名单）。
- **终端宽度与配置由解析站自己取**：宽度问 `console` 要，配置用标准库读当前目录下的那份——塔尖不往解析站里递任何东西，除了 argv 和号。
- **三种触发**出同一屏：`-h`、`--help`、空参数。认法是「按表里带不带值跳过值」，所以 `-c "-h"` 不会被当成要看帮助。
- **其余用法一律走「起不来」**，文案明说本阶段还没接上（阶段 03 起被真正的解析与合规检查取代）。这条**是过渡形态**，不许写进任何手册或 CHANGELOG。
- **退出码**：帮助 0，起不来 1。1 是过渡值，阶段 03 换成退出码表的查表结果。
- **红线三条**按 `redline_` 前缀加进名单与指纹：塔尖的进程出入口、解析站的入口、拼句包的那一件事；只管形状，不判措辞。
  - 塔尖那条要起真进程：先编到 `build/` 下当天沙盒再跑（可执行文件**不许落在仓库外**，也不许落在模块根——安全软件会静默删掉工作区外的可执行文件）。
  - 解析站那条不注入任何假件：靠切换工作目录，分别在「配置在」与「配置不在」两处跑一次。
- **终端包补一个打印入口**：收一个 `message` 造得出的类型、写到标准输出；本阶段只需要它打「一屏文本」与「一句话」。类一只许这里碰标准输出，别处连构造那句话都做不到。
- **塔尖新增一行顶格常量**：`const appVersion`，初值取老工程当前发布号（`1.0.0`）——两套并存期间发布脚本只改老工程那一行，所以这里**不许自己编号**，也不许引用 `debug` 那类东西（拼装归解析站）。
- 塔尖仍然薄：依赖清单不变（白名单只多 `os.Args` 一格），不出现字符串拼接。
