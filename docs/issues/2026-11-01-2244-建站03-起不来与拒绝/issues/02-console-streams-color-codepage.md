# 02: `console` 管两条流、管颜色、管码页

**要做的**：错误那句话能从 stderr 出去、正常输出从 stdout 出去；颜色码的去留照老版判据（重定向时**照旧输出转义序列**，只有「是控制台但 VT 开不起来」才不输出）；Windows 控制台的中文不再乱码，退出之后码页回到原样。做完之后，后面每一屏都有地方可打，而别处仍然一个字都写不到终端。

**Blocked by**：无，可立即开工。

**Status**：done

## 判据

- **只有 `console` 碰标准输出与标准错误**（类一）。它按 `contract.Text` 上那一格「写到哪条流」选流，一个字都不改。
- **颜色在打这一步决定去留**：`message` 拼屏时一律带色码，`console` 打之前按老版 `common.ANSI`／`detectColor` 的判据决定留着还是去掉，判据**照搬、一个字不改**——Windows 上先看这条流是不是控制台：不是控制台（重定向、管道）**照旧输出转义序列**；是控制台就看 VT 位，位开着照旧输出，没开就替它打开，开不起来才整场不输出转义序列；非 Windows 恒输出。**所以重定向到文件时文件里仍有转义序列，与老版一致。**
- **码页适配归 `console`，两个无参入口**：一个「切过去」（Windows 把输出码页切成 65001，其它平台空动作）、一个「还回去」。塔尖在步骤 0 调前者、在每个退出点调后者，**不持有任何句柄**；「改过没有」这个状态只在 `console` 里，且只有它自己读写。
- 三条导出各干一件事：打一屏、量终端宽度（02 已有）、码页适配。**不新增通用「原样输出」的口子**——那等于给所有想绕开 `message` 的人开一道门。
