# 10: 三套话——起不来、拒绝、危险框

**要做的**：把「一句话」这一个包扩到本阶段需要的三套版式：起不来那一屏（`[ERROR]` 头 + 环节标签 + 三段话 + 末尾日志行）、拒绝那一屏（输入不合规的 `[ERROR]` 外壳带日志行、禁止档那张框、喊停那句）、危险提醒那张框（`⚠`／`✕` 两种，多命中全列按风险降序）。

**Blocked by**：01（`Text` 那格「写到哪条流」）、02（颜色去留的判据在 `console`，这里只管拼出带色码的字）。

**Status**：done

## 判据

- **字只在这一处成形**（ADR-0032 第四条）：别处交来的只有事实——环节、问题／原因／提示三段、命中了几条规则、风险等级、日志路径。
- **逐字照老版**：`[ERROR]` 与 `[function:<环节>]` 的标点与空格、红黄两色、三段话的「原因：」「提示：」标签、末尾「日志：<路径>」、危险框的 `═` 宽度（56）、字段截到 46 列、装饰符不带变体选择符（`⚠` U+26A0、`✕` U+2715）。
- **颜色一律拼进去**，去留在 `console` 打的时候做——所以这里的期望串在「带色」这一档断言，「去掉」那一档由 `console` 的测试管。
- **「判据缺失」不另立版式**：那三处判据表的老版原话本来就说的是「东西不齐、工具判断不了」，照搬即满足 ADR-0034 决定七 要的口径；外壳各处原样（危险规则那两处带 `危险关键词内容检查未通过`，另两处不带），不统一、不新增说法。
- **「日志：」那一行是个可加的尾巴**：日志路径由调用方给（空串表示这一次没有日志，那就不加这一行）。老版是「日志建起来了才加」，新版按同一判据。
- 帮助那一屏（02 已有）不动；新增的三套各一个构造点，**不提供通用的「原样输出」**——那等于给想绕开排版的人开一道门。
- 塔尖一个字都不拼：这几屏由造它的站调这里拼好，塔尖只搬。
