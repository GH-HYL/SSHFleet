## 还没修、按重要性排

1. **H1／H2／H3 谁拼话**：闸门 `internal/gate/run.go` 有 13 处、解析站 `internal/parse/config.go`／`material.go`／`tables.go` 有 23 处裸拼「问题／原因／提示」，塔尖 `main.go:31` 还自己拼了一屏。撞 ADR-0034 决定八（闸门不写话）、ADR-0028 决定一／五（标签只许在构造点）。**改法**：把三段话的成形收进 `message`，站只交事实（哪一条没过、哪一段原文）——这是本单最大的一块。
2. **H5 `-p` 与 `-c`／`-s` 相撞是死码**：纸里没有 `-p` 那一格，`pathValue` 只读下载那一处，所以 `-c ls -p /tmp` 新版静默丢 `-p`。要回契约加一格（或把 `-p` 原值放进纸）。
3. **H6 `--sudo` 与 `--no-sudo` 同给无落点**：解析处后者覆盖前者，纸上只有一个布尔。要么记事实、要么加一格。
4. **H8 选项名两张表**：`options` 认值、`helpEntries` 排版各写一串名字。合成一张。
5. **H9 命令行被读两遍**：`helpRequested` 不认 `=` 内联，`--command=ls -h` 结局与老版相反。两套扫法收成一套。
6. **H10 危险判定丢了路径归一**：老版 `dangercheck/text.go` 会合并 `//`、去尾 `/`、解 `..`，新版只把路径收成文件名，`rm -rf //`、`rm -rf /etc/`、`rm -rf /tmp/../etc` 三类漏报。照老版补归一，别用现在这套近似。
7. **H21 测试缺口**：闸门与三套屏零断言，判据表与材料自检没有坏样。撞 spec 的 Testing Decisions。
