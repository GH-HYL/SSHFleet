# 05: 配置取值与路径——端口、超时、阈值、变量名、解释器、四条路径

**要做的**：配置里字段在但值不对（端口 70000、超时 0、`large_file` 比 `small_file` 小、变量名带横线、后缀没带点、路径写成相对路径或 `~/`），每一种都拿到老版同一句话并以 1 退出，不等到跑到一半才炸。

**Blocked by**：04。

**Status**：done

## 判据

- **取值范围照老版逐条**：`account.port` 1–65535；三个超时为正整数；`upload.small_file`／`large_file` 为正整数且后者不小于前者；`medium_parallel` 为正整数。
- **`[env]` 三条**：键名须是合法 shell 变量名；空键或空值丢弃（等于这条不生效）；值不能以奇数个反斜杠结尾。
- **`[interpreter]`**：`command` 非空、不含换行；`script` 至少一条、后缀带点、值非空、不含换行、同后缀不重复（忽略大小写），读进来后后缀归一小写。
- **四条路径**（`credential.key`、`credential.secret_dir`、`account.password`、`credential.key_password`）：加密关着时后两条是密码本身、只去首尾空白；其余一律归一成本机绝对路径——分隔符统一 `/`、盘符大写，`~` 单独成句报「不支持」，相对路径、异平台形态（Windows 盘符或 UNC 在 Unix 上）各有一句自己的话。
- **`secret_dir` 跟着加密开关走**：关着加密时它没有用途，写成什么都不是错。
- 每句报错都是「问题／原因／提示」的形态，由 `message` 的构造点拼，解析站只给三段内容（ADR-0028）。

## 验收

- [ ] `go build ./...`、`go vet ./...`、`gofmt -l .`、`go test ./...` 全干净
- [ ] 按取值逐条造坏样（至少八条：端口越界、超时 0、阈值反了、变量名非法、反斜杠结尾、后缀没点、相对路径、`~/`），报错逐字等于老版
- [ ] Windows 上写 `/home/ops/.keys`、Unix 上写 `D:/Keys` 各报一句「不是本机的绝对路径」，措辞按平台
- [ ] 加密关着时 `secret_dir` 写成相对路径不报错
- [ ] `[interpreter].script` 后缀大小写混写（`.SH` 与 `.sh`）判为重复
