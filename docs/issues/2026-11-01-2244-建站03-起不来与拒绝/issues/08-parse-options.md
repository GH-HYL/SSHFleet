# 08: 认全 20 条选项——取值、默认值、认出五种模式，认不出的当事实记下

**要做的**：命令行被认成一份可判的事实：哪个模式、给了哪些选项、各自的值是什么、哪些选项的值来自配置默认值；不认识的选项、缺值、值认不出（`-n abc`），都作为**解析时发现的问题**记下来，不当场下结论。

**Blocked by**：05（默认值要从配置里取）。

**Status**：done

## 判据

- **选项表还是 02 那张**（20 条、13 条带值、7 条开关），帮助与认值共用一份，不另立第二张表。
- **认法照老版语义**：短名与长名等价；`-c=x`／`--command=x` 两种等号写法都认；带值选项吃掉下一个 token；`--` 之后全是位置参数；位置参数不拦（老版允许与选项混排）。
- **默认值从配置来**：并发取「全部」、三个超时取 `[execution]` 三格；命令行给了就以命令行为准，并记下「这是显式给的」还是「这是默认值」——后面写报告、写日志要分得清。
- **五种模式**：`-c`／`-s`／`-u`／`-d`／`--change-password`，零个或多个都**不在这里报错**，只如实记下「给了哪几个」。
- **语法错只记事实，不下结论**：不认识的选项、缺值、值认不出，各记一条「哪个选项、原值、哪一处对不上」（01 号工单的判据：停归闸门）。禁得住：本单里没有一个「拒绝」、没有一个「起不来」。
- **`-f`／`-a` 只收原值**，不当场读文件、不当场判是不是文件（09 号单判形态，内容随 04／05）。
- 解析站仍然只露一个入口函数；本单**不导出任何类型**，事实通过第一张纸交出去。

## 验收

- [ ] `go build ./...`、`go vet ./...`、`gofmt -l .`、`go test ./...` 全干净
- [ ] 20 条选项各认一次，短名与长名结果相同（成对的逐对断言）
- [ ] `-c "-h"`、`--command="-h"` 不被当成要看帮助；`-h` 与空参数仍出帮助（与阶段 02 的 A/B 结论一致）
- [ ] `-n abc`、`-t 0`、`--unknown`、`-c`（没给值）四种各记下一条事实，接口返回的「起不来」为 nil
- [ ] 默认值样本：不给 `-n` 时并发是「全部」，给了 `-t 30` 时记成显式值
- [ ] 零个模式下也返回一张纸（模式为空），不下结论
- [ ] 红线不加新条目（解析站入口那条已有，本单只换实现）
