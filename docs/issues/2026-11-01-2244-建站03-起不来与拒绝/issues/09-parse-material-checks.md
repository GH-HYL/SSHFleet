# 09: 材料自检——脚本、上传源、下载目录、清单原值

**要做的**：这一层管的是「使用者给的这份料，工具到底拿不拿得到、能不能当文本用」：脚本读不到、是目录、是空的、是二进制、不是 UTF-8；上传源读不到、是符号链接、目录里没有真文件；下载的 `-p` 在本机读不到或不是目录；清单值既不是一个文件、也当不了一条记录。每一条都拿到老版同一句话，并以 1 退出。

**Blocked by**：08（要先知道哪个选项给了什么值）。

**Status**：done

## 判据

- **这些都归「起不来」**（ADR-0034 决定一：缺一样前提就是跑不了），由解析站造，不由闸门造：闸门审的是「这件事该不该做」，不看文件里有没有乱码，也不知道本机有没有这个目录。
- **判据只有一条，写进口径里**：缺的是**工具要用的东西**（材料）→ 起不来；对不上的是**这次给的东西**（参数搭配、取值、危险命令）→ 拒绝。
- **外壳句逐字照老版**：这几条在老版里都经 `fatal("cli", wrapFatal("选项/参数合规性检查未通过", err))` 那层壳打出，新工程照打——哪怕它按新分类落在「起不来」那一支。理由是 09 的逐字比对要过。
- **判二进制归解析**（迁移地图第三条）：它是「这份料能不能当文本用」，不是某个站的业务判断。判完不造字，只把「第几行不是文本」这类事实交给上屏那一处。
- **脚本正文读一次就够**：13 号单的危险检测要用同一份正文，别读两遍。
- **清单与代填只判原值形态**：既不是文件、也当不了一条记录，报一句；读进来的内容一行都不解析（随阶段 04／05）。

## 验收

- [ ] `go build ./...`、`go vet ./...`、`gofmt -l .`、`go test ./...` 全干净
- [ ] 脚本五条坏样各跑一次（读不到、是目录、空文件、含 `\0`、非 UTF-8），报错逐字等于老版
- [ ] 上传源三条（读不到、符号链接、目录里只有符号链接）、下载 `-p` 两条（读不到、不是目录）各跑一次，报错逐字等于老版
- [ ] 清单原值两种怪形态（一个既不存在也不是记录的值）各跑一次，报错等于老版
- [ ] 全部七种失败都走「起不来」（`CannotStart` 非空、`Refusal` 为空），退出码 1
- [ ] 脚本正文只读一次（读文件次数由自定义区测试钉住）
- [ ] 红线不加新条目
