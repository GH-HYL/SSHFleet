# 11: `ask` 问一句、收一行

**要做的**：危险提醒档要问的那一句有地方问：把问题摆出来、收一行回答；答否交回「不许走」，回车按缺省，读到输入结束交回「没答完」并打那句「输入结束，操作已取消」；带 `--yes` 时**不问**、直接交回「按缺省放行」这个事实。

**Blocked by**：02（`console`）、10（`message` 摆问题用的那一屏）。

**Status**：ready-for-agent

## 判据

- `ask` 只干一件事：**摆出一屏、收一行回答，它不判断答案的含义**（ADR-0032 第四条权限表）。放不放行归闸门。
- 三个出口照老版交互器：非交互（`--yes`）→ 不读输入、交回「按缺省放行」这个事实；读到输入结束 → 打出「输入结束，操作已取消」并交回「没答完」；正常 → 回车取缺省，答否交回否。
- **不写日志**：`ask` 的依赖白名单只有契约、`console`、`message`（ADR-0032 第四条），写不进 `log`。留痕由闸门拿「按缺省放行」这个事实去写——老版是交互器顺手写，新版把那笔挪到闸门，行为不变。
- **不许自己退出、不许 panic**（类三、ADR-0034 决定四）：拿不到答案就把事实交上去。
- 打只有一个出口：问句与那半句取消提示都由 `message` 造、`console` 打；`ask` 不自己写终端（类一）。
- 非交互时那些「教学类提示」静默，报错不受影响（老版 `Notice` 的口径）——本阶段只用到「问一句」，其余通道留到用得上的阶段再落。

## 验收

- [ ] `go build ./...`、`go vet ./...`、`gofmt -l .`、`go test ./...` 全干净
- [ ] 答 `n`／答 `y`／只回车（缺省否）／读到输入结束，四种各断言一次
- [ ] 读到输入结束时屏幕上有那半句「输入结束，操作已取消」，且交回的是「没答完」
- [ ] `--yes`：不问、不读输入、交回「按缺省放行」（断言事实，不涉及日志）
- [ ] `ask` 的 import 只有契约、`console`、`message`（依赖检查自然覆盖，`## Comments` 点明）
- [ ] 问句与老版同一句（含末尾那两个提示括号的形态）
- [ ] 红线：`ask` 那一件事（15 号单一起加）
