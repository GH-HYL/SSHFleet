## 八、顺带（文档，只提报不改）

1. **规范三.3 的 import 白名单没跟上 ADR-0032 的 2026-11-02 更新记录**：条文只写「标准库、契约，以及被它钉的那一个包」，而该更新记录明示「红线测试的 import 白名单相应把 `message` 与契约同级（它不是『被钉的第二个包』，是造话的工具）」，代码与检查器（`check_testsite.go:14-18,40`）都按后者做。两个文件（`redline_ask_test.go`／`redline_report_test.go`）因此合 ADR 而不合规范原文——这是规范该补一句，不是代码该改（J10 是另一件事：射程）。
2. **`GLOSSARY.md:61` 写横切片「共八个」，实际九个**：`interrupt` 是第九个（ADR-0032 的 2026-11-05 更新记录「横切包从八个变九个」），代码与交接清单（§1.5）都按九个算，`guard/rules.go:10` 的 `KindCrosscut` 注释也是「九个叶子包」。
3. **`GLOSSARY.md:40`「那一处函数」与实际四处分叉**：词表按单数写，代码是四个函数（J7）。三种可能——词表口径该放松、代码该收成一个、或者四个函数本就是一处——留开发者定。
