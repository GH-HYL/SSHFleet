## 五、发现

### 09-1【硬伤】危险放行留痕不进归档执行日志——塔尖收到那句话，只落工具日志

**位置与证据**

- `main.go:105` 收闸门递回的两样：`refusal, note := gate.Run(plan)`；`:106-108` 只做一件事——`lg.Warn(note.Text())`，`lg` 是**工具日志**（`main.go:57` `log.Init(toolDir, toolFile)`）。
- 归档执行日志的落点 `paths.ExecLog` 到 `:119` 才拿到，`:126` 直接交给执行站；`:136-139` 只在收尾时追加一行统计，**没有任何一处把 `note` 写进 `paths.ExecLog`**。
- 老版两处都写：`SSHFleet_Go/main.go:449-450` `if dangerNote != "" { execLog.Warn(dangerNote) }`（执行期日志），另一处 `:387`／`:369` 由 `logger.Warn` 落工具日志。
- 判据原文：`docs/issues/2026-09-11-1336-Go重写/issues/21-output-files.md:10`——「**执行日志**……危险命令放行留痕也写这里（spec D46）」。
- 塔尖自己的注释也写着「由这里落盘」（`:107`），但「这里」只剩工具日志一条路。

**计数**：留痕三个档位里 **1 档**受损——危险提醒档、非交互（`--yes`）放行。禁止档老版本来只落工具日志（`:358`，那时归档还没建），新版一致；提醒档交互确认那一支由闸门交回空 `message.Line`（`internal/gate/run.go:324`），属闸门侧，归 08，本轴不判。

**伤**：**行为变了**（维护者可见面：归档目录里的执行期日志少一行）。使用者屏幕、`report.txt`、退出码均不变。

**为什么不是「跑一条命令」**：属行为类的窄边——要造一个「危险命令 ＋ `--yes`」场景再比对归档内的执行期日志。按授权本轮不上真机，故按代码与老版原文对照给证据。

### 09-2【判断题】「这一屏带不带『日志：』行」的形状判断落在塔尖

**位置**：`main.go:78-81`

```go
logPath := toolPath
if fail.NoLog {
    logPath = ""
}
```

**事实**：`contract.CannotStart` 里有 `NoLog` 这一格（事实在纸上），而 `message.Fatal(where, body, logPath)` 收的是**路径字符串**（`internal/message/screens.go:46-49` 负责决定带不带那一行）。两头的类型对不上，中间的翻译就落到了塔尖：塔尖因此知道「配置那一步那一屏不带日志行」这条**屏幕规则**。

**伤**：腐蚀架构（A8「它不下任何业务判断」）。塔尖现在多知道一条屏幕措辞层面的规则；将来多一种无日志的起不来，得回塔尖改这段。

**代价**：把 `NoLog` 直接递给 `message`（例如让 `Fatal` 收一个「带不带」的布尔），塔尖就只剩搬；`message` 会多一个参数。**取舍由开发者定，本轴不改。**

**计数**：1 处。

### 09-3【判断题】同一件事（开执行期日志）两处两种失败口径：一处 fatal，一处静默吞

**位置**：`main.go:136-139`

```go
if execLog, lerr := log.InitExec(paths.ExecLog); lerr == nil {
    execLog.Info(message.ExecSummaryLog(ledger))
    _ = execLog.Close()
}
```

**事实**：`lerr` 既不上报、也不落日志、也不改退出码——直接跳过。同一份文件在 `internal/execute/reporter.go:44-46` 第一次被打开时是**硬失败**（返错 → 执行站交「起不来」→ `main.go:127` fatal）。

**为什么算判断题而不是硬伤**：新版此处是「追加一行」的第二个失败点，老版没有等价点（老版句柄一直开着，`:438` 建、`:449` 写）；且第一次打开已成功过，这条路要求「跑完之后文件突然不可写」。**但它确实是一处无声**：维护者日志缺一行，没有任何人知道。

**伤**：只是架构取舍（一处宽容、一处严格，宽容的那处不留痕）。若要按 `spec.md`「缺评估/理由/点头就按行为变了报」的口径升级，属开发者定；本轴按「失败点不同、旧版无等价点」记判断题。

**计数**：1 处；同一操作在本工程共 3 个打开点（`main.go:136`、`execute/reporter.go:44`，另 `log.Init` 是工具日志不在此列）。

### 09-4【判断题】塔尖自己算了一个事实：`time.Now()`

**位置**：`main.go:119` `archive.Create(contract.HistoryDir, string(plan.Mode), plan.Run.Remark, time.Now())`

**事实**：老版这一步是 `output.CreateArchive(args)`（`SSHFleet_Go/main.go:430`），「现在几点」由归档包自己取；新版签名改成收 `now time.Time`（`internal/archive/archive.go:58`），于是「现在」由塔尖取。同处还有一次 `string(plan.Mode)` 的类型转换（把站与站之间的枚举翻成目录名用的字符串）。

**伤**：腐蚀架构（A8「自己算」的边界，很轻）。收益是可测（归档包不再读时钟，`guard` 的时钟白名单少一格）；代价是塔尖手上多了一个与业务无关的取值。

**计数**：1 处（含 `time.Now()` 与 `string(plan.Mode)` 两小格）。不改，只登记。
