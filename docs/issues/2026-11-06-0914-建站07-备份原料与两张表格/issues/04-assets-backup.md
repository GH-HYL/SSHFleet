# 04: 备份原料与清单脱敏副本

**要做的**：做完之后，那一次的 `assets/` 里答得出「这次我给了工具什么」——脚本与代填的原件在里面、清单的脱敏副本也在（密码那两列已遮），而被上传的文件一个都不在里面。

**Blocked by**：01、02。

**Status**：ready-for-agent

- [ ] 脚本模式跑一次：`assets/` 里有脚本原文件，与源文件逐字节同、文件名不变
- [ ] `-a` 给的是文件：`assets/` 里有代填原文件；`-a` 给的是内联文本：`assets/` 里没有它
- [ ] `-f` 给的是文件：`assets/` 里有同名副本，第 4 列与第 6 列已遮成前 2 后 2，注释行、列数与引号原样，副本能直接当清单再跑一次
- [ ] `-f` 是内联记录：`assets/` 里不产清单文件
- [ ] 上传模式跑一次：`assets/` 里没有那几个被上传的源文件
- [ ] 备份失败（例如 `assets/` 不可写）时按「起不来」收场，退出码 1，屏幕那句带原因
