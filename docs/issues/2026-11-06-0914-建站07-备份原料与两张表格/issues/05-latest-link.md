# 05: 「最新一次」链接

**要做的**：做完之后，工作目录下多一个 `latest_history`，点它就进最新那一次的目录；Linux 上是软链接、Windows 上是能双击进去的目录联接。工作目录里本来就有一个同名普通文件时，工具不碰它，只警告一句。

**Blocked by**：无，可立即开工。

**Status**：ready-for-agent

- [ ] 连跑两次，`latest_history` 指向后一次那个目录
- [ ] 工作目录里先放一个普通文件叫 `latest_history`：跑完之后那个文件还在、屏幕一句警告「当前目录已存在同名文件 latest_history，跳过链接创建（如需快捷入口，删除该文件后重跑）」、退出码 0
- [ ] 工作目录里已有一条指向旧目录的链接：跑完之后指向新的一次（旧链接先删再建，目标目录不受影响）
- [ ] POSIX 上 `cd latest_history` 能进；Windows 上它被识别成目录联接（`os.Readlink` 读得出目标）
- [ ] 历史根为空时跑不崩、不建链接
