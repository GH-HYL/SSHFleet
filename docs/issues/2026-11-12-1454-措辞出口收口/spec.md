# 规格：措辞出口收口

**状态**：done
**底本**：`docs/issues/2026-11-09-0945-切换前回顾审计/修复面盘点.md` §4.2（三件）；`docs/adr/0044-纸只装结构化事实.md`（纸收完了，屏没跟上）

## Problem Statement

使用者翻一遍运行记录会发现：同一件事，有时是工具自己的一句中文，有时是系统原话——`建归档目录失败（…）：mkdir …: permission denied` 这种半句中文半句英文的，就是塔尖把站交上来的 error 原样贴到屏幕上。改口吻的人更难受：`message` 里明明已经把「起不来」那一族的句子收成了一处，屏幕上那条 `[ERROR]` 的正文却还是一个裸字符串，谁都能塞，塞进去的字不一定是从 `message` 来的。

使用者感受不到「谁拼的句子」，但他能感受到「同一副外壳里，字有的是人话，有的是机器的」。

## Solution

那一屏的正文不再是随便一个字符串，而是一个只有 `message` 造得出来的值。造不出来就传不进去：站里想往屏上放一句，只能先说出「哪一类、什么参数」，由 `message` 取模板成形。系统原文照样能上屏，但它得走一条**数得出来**的口子，不再随手 `err.Error()` 就贴。

改完之后屏幕上每一个字节与现在相同；变的只是「以后要贴一句系统原文，得先过 `message` 这一道」。

## User Stories

1. 作为使用者，我希望屏幕上那条报错的正文是人话，混进系统原文时看得出哪一段是系统的。
2. 作为使用者，我希望这一版改了内部结构，屏上所见一字不差。
3. 作为维护者，我希望「随便拼一个字符串塞进那一屏」在类型上做不出来，而不是靠注释提醒。
4. 作为维护者，我希望系统原文进屏的地方数得出来——现在几处、以后多一处会红。
5. 作为审计者，我希望「`.Error()` 直接当正文」能被一条结构断言抓住，而不是靠逐个读调用点。
6. 作为维护者，我希望进度界面那条字节流的口子写明了「它不承载句子」，下一个想拿它打印的人先看到这句。

## Implementation Decisions

- **正文改成具名类型 `message.FatalBody`**：与 `message.Line` 同一道闸——字段不导出，只有 `message` 能造。`Fatal` 与 `TraceRefusal` 只收它。`Refuse*` 那 25 个、`Shell`、`CannotStartBody` 都改成返回它；`CannotStartText` 留一个取字的方法给测试与日志，底层同一份实现，不各拼一遍。
- **塔尖那两处系统原文收进类别**：建归档目录失败、报告写不出来——现在是把站的 `error` 原样上屏。改成「系统原文」这一类别（`Kind` ＋ `Origin`），模板只有一句「原样交出 Origin」，所以字节不变。**这是过渡口子，不是终局**：站里那两句中文（`archive` 的 `fmt.Errorf`、`report` 的三条）迁进类别表之后，这一类别就没有调用者了。它的存在由下一条断言数着。
- **形状断言落在类一（写终端）旁边，不新开类**：加一类要开发者点头（ADR-0037 影响段）。判据是语法形状：`Fatal`／`TraceRefusal` 的正文不许是 `.Error()` 调用的结果，也不许是当场拼的字符串连接；`message` 内部只有「系统原文」那一类的模板能碰 `Origin`。新增一条测试不算改红线（三.3），但要进名单、留指纹。
- **`console.Writer` 只补注释**：判据已经有了（类一第三条，`writerHome = execute`），全工程只有执行站一处调用。补的是那句话——「只承载字节流，不承载句子」，以及为什么（画帧要独占一条流，而句子只从 `message` 出）。
- **不迁站里那 54＋93 处自拼中文**：那是「措辞集中」的后续批次，本规格只收出口。

## Testing Decisions

- **接缝是包边界**，不是进程出入口：这一版改的是类型，屏上字节不变——用既有的 `message`／`gate`／`guard` 包测试就够，不必跑 37 场。真要跑，是为了证明「字节没变」，不是因为接了新逻辑。
- 反向验证照 05 号单的老办法：故意在站里写一处 `Fatal(where, err.Error(), …)`，确认编译不过；再故意绕过类别往屏上塞一句，确认断言报红。
- 断言只判形状，不判字面量、不数字节——判据写成「名字／调用形状」就能判的，别去看字符串内容。
- 指纹变化逐条记进 Comments。

## Out of Scope

- 站里 54 处（`execute`）＋ 93 行（`parse`）自拼中文的迁移（4.2 的后续批次）。
- `console.Writer` 判据本身（已有，不动）。
- `archive`／`report` 两条错误原文改由类别表成形——本规格只把它当系统原文收下，那两句中文仍在站里。
- 04 号单留的 `Problem.Detail`、报文格式 `sshfleet.<env>.<stage>:`（架构取舍，另议）。

## Further Notes

- 这一版之后，「谁能往屏上放字」的口子只剩两个：`message`（造）与 `console.Print`（打）。
- 审计 11-09 那张单上写的「16 处 `err.Error()` 能搭 `Fatal` 上屏」是 0044 落地前的数；0044 收了纸面之后，今天实测只剩塔尖两处。规格按今天实测写，不按旧数。
