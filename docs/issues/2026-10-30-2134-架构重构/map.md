# 地图：前端流水线架构重构

## Destination

走完这张地图，手上要有三样东西，**代码一行未动**：

1. **结构定义**——五站各管什么、收什么、交什么；横切包各自能做与不能做；塔尖薄到什么程度。
2. **迁移地图**——老工程 13 个 internal 包与 `main.go` 的每一块搬到哪个新包，一行一块，搬完能对账。
3. **切换判据**——到哪一步算新工程能顶替旧工程，切换前要跑哪些验收。

**ADR 不在这三样里，它是过程产物**：哪张工单定下的判断满足三道门槛（难回头 / 没上下文会困惑 / 真做过取舍），当场另起一篇，不等十张定完。总纲那篇是 `docs/adr/0032-按五站分层重构工程结构.md`，已经落了。

**动工是这三样之后的事，不在本图范围内。**

## Decisions so far

开图前已定，不占工单：

- **只做结构，不动实现**：现有工具能正常使用，重构不夹带功能、不修缺陷、不改行为。
- **五站分层**：摄入 → 闸门 → 执行 → 整理 → 呈现，形状照上一轮教学骨架。
- **契约独立**：`contract` 包只放类型与常量，一个函数都不许有。
- **横切五个叶子包分开**：`console` / `log` / `ask` / `archive` / `exitcode`，不合成 `common`。
- **交接件规则**：阶段之间传新造的交接结构体，不许传上一站的原结构体；下站缺字段时去上游纵切加，不许跨阶段回取（作者 U10 原话：「一改改一条线，这是必须付出的代价，并不是拿它去衡量取舍，它就应该是这样」）。
- **新工程单开目录** `modules/SSHFleet2_Go/`，不改老目录名。
- **老工程冻结**：只修紧急缺陷，新功能一律进新工程。不拆仓库、不开长期分支，退路靠提交点。
- **配置原样搬一份**：新工程自带 `config/`，格式、字段、出厂值与老工程完全一致，切换时整目录拷过去即可跑。
- **走探路**：先画这张图，决策定完再落规格与工单。

工单已结：

- **塔尖薄不薄看依赖清单，不看行数**（05）。塔尖只做分叉、搬、退三件；它是编排不是横切。分叉的依据只能是摄入递回来的东西。帮助文本归摄入、版本拼装归呈现、常量留塔尖。见 ADR-0032 第五条。
- **五种模式不聚成包**（02）。第一刀横着切站、第二刀竖着切站内文件，模式不汇成包。载荷用一个带标签的格子装五种内容，对不上由闸门验。密钥管理独立成包、自己读自己那块配置；凭据读取再单列一个叶子包，两边共用。塔尖留一个分叉：走流水线还是那三条小命令。见 `docs/adr/0036-五种模式不聚成包.md`。
- **交接件按「棒」定形状**（03）。信封只有一份，随站换三次口径：摄入→闸门→执行讲「要做什么」（闸门原样递，只加结论）；执行→整理讲「发生了什么」，按模式五份；整理→呈现讲「总共怎么样」。载荷五份不合并（认下重复）。**同口径往下传时后一张必须比前一张窄**，一样宽就不该造两次；换口径那两棒只装下一站要用的。单台归类留在执行、全体汇总归整理。判据表进第一张纸；契约不放函数、合法性由闸门验；塔尖只搬不装。见 `docs/adr/0035-交接件按棒定形状.md`。
- **闸门的拒绝权只覆盖「计划成形之后」**（01）。归闸门四类：参数不合规、危险命令、人当场喊停、判据缺失；计划成形之前的失败叫「起不来」，不归闸门——任何站都不许自己退，退出动作只在塔尖。**判断散着、话走报错构造点、停只一处**；闸门不写话也不打屏。起不来与拒绝用两种类型，**起不来放通用类型包谁都能造，拒绝只住闸门**。闸门三个出口：放行 / 放行但要说一句 / 拒绝。见 `docs/adr/0034-拒绝与起不来分成两种失败.md`。
