# 04: 老工程 13 个包怎么摊进五站——尤其 output 那 2249 行怎么劈

**Type**：grilling
**Status**：resolved
**Blocked by**：无，可立即开工

## Question

老工程 `modules/SSHFleet_Go/internal/` 现有 13 个包，非测试代码合计 13147 行，按行数排：`ssh` 3589、`output` 2249、`cli` 1739、`credential` 1180、`batch` 698、`common` 694、`nodelist` 628、`dangercheck` 597、`config` 577、`confirm` 463、`verdict` 452、`result` 159、`log` 122。加上根目录 `main.go` 512 行（十步主干）。另有 51 个 `_test.go` 文件散在 12 个包里。

初步摊法（要在这条工单里核实）：

| 老位置 | 新落点 |
| --- | --- |
| `config` + `cli`（解析部分）+ `nodelist` | `ingest` |
| `dangercheck` + `confirm` + `cli`（校验部分） | `gate` |
| `ssh` + `batch` | `execute` |
| `verdict` + `result` | `appraise` |
| `output` | `present` + `archive`（横切） |
| `common` | 拆散，按「产不产业务数据」分流 |
| `log` | `log`（横切） |
| `credential` | `credential`（独立垂直切片） |

注意这张表没有一处是干净的：`cli` 要劈成解析与校验两半、`result` 与 `verdict` 要合、`common` 要拆散。表上每一行都是一次判断，不是一次搬运。

**这张工单还背着四件别处推过来的事**，谈的时候一并定，别当漏项：

- **五站与横切包的最终命名**（02 号推的）——骨架里 `ingest` / `gate` / `execute` / `appraise` / `present` 是临时叫法，摊完包才看得出叫不叫得准。
- **执行站入口的形状**、**结算站怎么把五种结果合成一份报告**（同为 02 号推的）——都依赖摊完之后的实际代码。
- **四次交接各装哪些格子**（ADR-0035 推的）。
- **包的头注释**（07 号推的）：摊完一个包，就地写一句「这个包只干哪一件」，写不出来的说明这一行没摊对；那句话随后成为包注释，后面接一句「判据见 ADR-0032 第四条」。

**最大的单点风险是 `output` 那 2249 行**：呈现、报告、xlsx、归档全在里面，而新分法要把它劈成 `present`（五站之一，产结论给人看）与 `archive`（横切，只发路径字符串）。这一刀切在哪，决定呈现站的接口宽窄。

要定的：

1. 上面这张表对不对，有没有哪一块摊错了或摊不进去。
2. `output` 怎么劈：按「终端输出 / 文件输出 / xlsx / 归档」分，还是按「呈现 vs 落盘」分？`internal/common` 里那些无状态小工具（字节格式化、颜色、CSV 文本）归谁——呈现站，还是横切。
3. 有没有哪一块**在五站里找不到家**——那说明五站这个切法在这个工程上不成立，这是最坏的情况，得早发现。
4. **每一格的那一句话。** 迁移地图每行要能写出「这个包只干哪一件」，一句话，写不出来、或者得用「和」把三件事串起来的，那一行的摊法就还没想清（03 号工单的判据同一条）。这句话建包时原样成为包的头注释，后面会接一句「判据见 ADR-0032 第四条」——见 07 号工单第二笔。

答案要能落成一张完整的迁移地图，一行一块，一行一句，搬完能对账。

## Answer

### 迁移地图

**五站定名**：解析（`parse`）/ 闸门（`gate`）/ 执行（`execute`）/ 结算（`settle`）/ 报告（`report`）。

**`output` 那 2249 行怎么劈**：按**发生在什么时候**劈，不按「终端还是文件」劈。跑的时候（进度、每台一行、三去向分发）归执行站；跑完之后（屏幕统计、报告文件、两张表格）归报告站；建目录、备份原料、维护最新链接归归档包。按「终端 vs 文件」劈会劈出两堆各含两个时刻的东西，站的名就对不上时候。

一行一块，右列是这一块**只干的那一件**。这句话搬完之后原样成为包或文件头部的说明；写不出来、或者得用「和」把三件串起来的，说明这一块摊错了，退回重摊。

### 摊的过程中撞出来的三件

**十三块都有家。** 没有哪一块在五站里找不到位置——要找的只有下面这三处的归属。51 个测试文件跟着它测的那个包走，不单独摊；测的是哪个包，就搬到哪个包里。

**旧 ADR 的路径**：15 篇旧 ADR 里 41 处 `internal/*` 路径，按这张地图逐条换成新落点；不在旧文里就地改，在各自末尾追加「更新记录」。这批改动随建包一起做，不另立工单。

**一、脱敏清单的「第 4 列是密码」是清单的格式知识，不是归档的。** 所以清单副本由 `mask` 写（它认得出秘密，也认得出数据行），归档只发路径、只做原样复制。**这条要是推翻，归档就得懂清单的列，它就是第二个解析站。**

**二、IP 判定两边都要用**：解析认清单、`mask` 认数据行。各写一份，不合并。

**三、`IsBinaryContent` 两个站都要用**：解析读代填、闸门查内容。放 `display` 叶子，两边都依赖它。

### 没摊进去的

- **执行站对外露什么口子、四次交接各装哪些格子**——转 15 号，和「交接件多宽、以后改贵不贵」一起谈。
- **结算交报告那张纸怎么把五种模式合成一份**——转 15 号，它吃的是那张纸。

## Comments

- 2026-11-01：**五站定名：解析 / 闸门 / 执行 / 结算 / 报告。** 第五站不再叫「呈现」——它的产物是报告文件、表格、屏幕统计三样，都落在「报告」的字面内；「汇报」带人味，且装不下表格。第一站不再叫「摄入」——它不只把料收进来，还要装成一份计划、判料齐不齐；「摄入」只说了第一件。第四站从「整理」改成「结算」——它不只把结果摆整齐，还要算。
- 2026-11-01：**备份执行资源、更新「最新一次」目录链接，归归档包**。这两件不出给人看的东西，是落盘目录自己的事。报告站只剩三件：报告文件、两张表格、屏幕统计。
- 2026-11-01：**「判定」与「统计」不整包搬去结算**。判据表加载归解析，逐条结果定分类归执行（实时上屏要用），加总归结算。老代码本来如此：分类在执行的协程里定，统计只读结论。
- 2026-11-01：**危险警告整件事归闸门管，但闸门不写字。** 不许跑时把「拒绝 + 那张表」交回塔尖，塔尖打出来再退；要提醒时把「要问的事」交给 `ask`，`ask` 摆出来再问；表怎么排只有 `message` 一处。`ask` 因此多一条依赖 → `message`。ADR-0032 第四条已补。
- 2026-11-01：**不加「打印站」。** 打印不产业务数据，属横切；那类字要在五个时刻出，一个站只占一个位置。靠 `message` 拼、`console` 打两片叶子收口。缺的「除 `message` 外不许拼句」检查，待验明可机械判 + 开发者点头后再补进 07。
- 2026-11-01：**`common` 拆出两个新叶子**：一个管按显示宽度排版（量、截、折，字节格式归它），一个管遮秘密。其余各有归属——错误文案归 `message`、问人归 `ask`、颜色与码页归 `console`、CSV 读与 IP 判定归解析、二进制判定归解析。权限表由七个变九个。
