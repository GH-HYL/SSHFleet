## 三、驳回（下一轮免报清单）

1. **「选了包注释却没交代 README 为何落选」** —— 原 Question 把「新工程的 `README` **或**包注释」并列为同一个候选，选其一不算漏答。
2. **「判据唯一出处在 ADR-0032 第四、五条」编号指不准** —— 该 ADR 通篇用中文数字「一、二、三…」编号，「第四条」「第五条」指得准。
3. **「执行交整理，03 说五份、ADR-0035 说一份」** —— 两个对象：ADR-0035 决定一的「一种信封结构」说的是外壳，五份说的是载荷格子。
4. **「信封合法性、契约不放函数各被定了五次」** —— 五处口径一致，是各工单在引用同一条，不是两个来源。
5. **「配置两份怎么对齐，链上空白」** —— `map.md` 的「Not yet specified」已列（「迁移期两份配置会不会走样」），子 agent 未获该文件。
