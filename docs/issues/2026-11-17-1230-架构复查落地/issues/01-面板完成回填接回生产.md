# 01: 传输面板的完成回填接回生产

**要做的**：跑一次上传（或下载），屏幕上那块逐节点面板的「已完成／总数」「成功 N／失败 M」随机器跑完而变，传完的机器让出显示位；跑完收场时留在屏上的是满格那一帧；被中断的那一趟仍停在没跑完的状态，不落满格。

**Blocked by**：无，可立即开工。

**Status**：done

- [ ] 先建复现回路：一条从执行站入口进来的用例，在面板收到的快照里断言「完成台数」大于 0；它在改之前红。
- [ ] 节点结果在收口处交回聚合器，成败取执行站已有的那个成功判定（分类函数也在用的那一个），不另写一套。
- [ ] 面板不重复算成败：收口处算一次，随结果一起交回。
- [ ] 收场定格帧的条件不再恒假：跑完那一趟 `Completed` 等于总台数，中断那一趟不等于。
- [ ] `go test ./...` 全绿；改前那条新用例红、改后绿。
