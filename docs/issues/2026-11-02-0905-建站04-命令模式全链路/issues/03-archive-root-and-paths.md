# 03: 归档包——建本次运行的根、发路径

**要做的**：每次跑起来的产物要落进一个独立目录。做完之后，执行站与报告站能向归档包要到「这次的全部路径」，日志、终端输出、报告、执行期日志都往那里面写。使用者跑完在 `history/` 下看到本次那个目录，与老版同名同结构。

**Blocked by**：无，可立即开工。

**Status**：done

## 要落什么

- 一个入口：给「模式 + 备注 + 时间」，建 `<history>/<时间-模式[-备注]>/` 与它的 `assets/`，交回一组路径字符串（目录、`assets`、报告、终端输出、执行期日志）。
- 目录名的构成、备注里不能进目录名的字符怎么换，**逐字照老版**（`output/archive.go` 建目录那半）。
- 横切叶子包：**只返回字符串**，不返回句柄，不设包级变量记住「这次建了哪个目录」；不替任何人写文件。

## 验收

- [x] 建出来的目录名与老版同一输入下逐字相同（三种：不带备注、带备注、备注含非法字符）
- [x] 入口只回字符串：类型里没有一个 `*os.File`、没有 `io.Writer`
- [x] 红线：一条新测试钉住「只发路径、不写文件、不留包级状态」
- [x] `go build ./... && go vet ./... && gofmt -l . && go test ./...` 全绿；`go.mod` 无新增 `require`

## 不在这单

`assets/` 里资源的原样复制、「最新一次」那条链接——随 07。本阶段只建目录与 `assets/` 空目录。

## 做完之后

04（执行期日志）、12（终端输出）、15（报告）都向它要路径；03 规格里「日志路径由解析纯计算」那条过渡形态在本单落地后作废。

### 2026-11-02：交付

**落了什么**：`archive.Create(root, mode, remark, now)` 建本次目录与 `assets/`，交回五个落点（目录、`assets`、`report.txt`、`terminal-output.txt`、`SSHFleetExec.log`）。目录名照老版 `<yyyy-MM-dd_HH-mm-ss>_<模式>[_备注]`；四个文件名是本包的内置常量。

**三个形状上的判断**：

1. **根目录由调用方给**（`root`），不由本包写死 `"history"`：本包按权限表不依赖契约（ADR-0032 第四条），而那个名字在契约里已有一处出处。硬写一份就是第二个来源。
2. **模式进来是字符串，不是 `contract.Mode`**：同一个原因——为一个类型名去改依赖白名单不值当，塔尖转手 `string(plan.Mode)` 即可。
3. **备注过滤住本包**（`remark_unix.go` / `remark_windows.go` 按构建约束分开）：POSIX 只换 `/`（它是路径分隔符，留着会让 `-r a/b` 多出一层目录），Windows 换九个非法字符并挡保留设备名。两侧分开写，是因为那九个在 Linux 上完全合法，换掉是丢信息。
