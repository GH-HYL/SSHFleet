# 07: 闸门确认屏——顺带落下 `mask` 的「遮秘密」那一半

**要做的**：命令与参数都合规、危险检测也过了之后，闸门把「这次对谁、做什么、几个并发、什么身份、多久超时」摊成一屏，问一句要不要继续。做完之后：答 y 往下走，答 n 当场喊停（退出码 1），带 `--yes` 不问直接走、屏上留一行「[非交互模式] 跳过执行选项/参数确认环节，直接执行」、日志里也留痕。

**Blocked by**：01（纸上要有节点与参数）、05（要有人可摊）。

**Status**：done

## 要落的

- 那一屏的内容与版式**逐字照老版**（`confirm/confirm.go`）：表格列、字段顺序、空值怎么显示、末尾那句问句。
- 问人走 `ask`，闸门自己一行都不写（ADR-0032 第四条）。
- 答否：交回 `gate.Refusal`（当场喊停那一类），塔尖从退出码表换码退。
- **`--yes` 那一行屏**：老版是 `SkipLine`，与「不问直接跑」是两件事，别只做后者。
- 屏幕上要显示的秘密（内联清单里的密码）**遮过再显示**——老版就是这么办的，照搬。

## 顺带落 `mask` 的「遮秘密」一半（横切包，本阶段只做这一半）

三处都要遮：本单的确认屏、12 号单的结果行、15 号单的 `report.txt` 第一段。**不许拿解析站的内部实现顶**——站不许依赖站。所以这一半在本单落地：认出秘密（内联清单里的密码那一列、`-p`／`-k` 之类带凭据的取值）、把它遮住，交回一个遮过的字符串。

- 只有这一件事，不导出别的 helper。
- 清单的**脱敏副本**（要认得出清单的列、要写文件）不在这单，随阶段 07。
- 横切叶子包：只许依赖标准库与契约。

## 验收

- [x] 三种情形各一次：答 y（放行）、答 n（拒绝非空、退出码 1）、`--yes`（屏上有那行 `SkipLine`、日志有那一行、且**没有**问句）
- [x] 确认屏整屏逐字断言，期望串从老工程同一份输入跑出来录；遮过的密码在屏上确实不是明文
- [x] `mask` 那件事单独一条断言：遮过之后的字符串里找不到原密码，未遮的部分一字不变
- [x] 闸门仍不写终端：写终端那一类检查不新增违规
- [x] `go build ./... && go vet ./... && gofmt -l . && go test ./...` 全绿

## 不在这单

「这份清单是空的」这类材料问题（06 在解析站就拦了）；危险提醒档那次问人（03 已落，不重做）；清单脱敏副本（07 阶段）。

## Comments

### 2026-11-02：交付

**落了什么**：`message.ConfirmScreen` 排那一屏（横幅 + 两列表 + 分块空行），`ask.AskWith` 收「屏 + 问句」两样（危险框那句与确认屏那句不是一句话），闸门的 `confirmRefusal` 把它们串起来：答 y 放行、答 n 交拒绝 + 留痕、读到输入结束也算当场喊停、`--yes` 不问只打那一行并留痕。

**与老版逐字对过的两路**（`build/建站04_05_2026-11-02_1015/run2`）：答否那一路**整屏一字不差**（连横幅边框长度、列对齐、亮黄色问句都对上了）；`--yes` 那一路的前两行（跳过确认 + 空行）一字不差。此后两版分岔是意料之中——新版接上执行站之前会打「还没接上」。

**对着比出来的三处，都已改回**：

1. **边框长度按字符数算，不按显示宽度**：老版是 `len([]rune(title))+10`，用显示宽度会把边框撑长 8 列。
2. **执行模式那一格写「命令模式」，不是「执行」**：两者在名字表里是不同的字段（ScreenLabel 与 ActionName），我起初取错了。
3. **问句用亮黄（93），不是普通黄（33）**：只有这一句是亮黄，取消那句仍是 33。

**顺带修掉一个 03 留下的真缺陷**：`-t`／`-T`／`-n` 没给时，`positiveValue("")` 返回 `(0, true)`，代码直接把 0 写回了纸——**配置里的三个默认超时被抹成 0**。以前看不出来是因为确认屏之前没人把这几个数显示出来。现在改成「没给就不动」。

**备注自动生成也在这一单落地**：没给 `-r` 时按老版规则生成（命令取首词、脚本与上传取文件名、下载按远端规则切），再过一遍平台的字符过滤——过滤那一段从归档包导出（`archive.SanitizeRemark`），两处用同一份，不各写一套。

**一处推迟**：`[locale] english = true` 与代填值写中文的冲突那道门（老版在确认之前拦）没做——它要 `-a` 代填的内容层，而 `-a` 随阶段 05 的其余模式，语言开关随 08。两层到了再接，位置就在确认之前。

**红线**：闸门那两条红线用例的纸补了 `Yes: true`（它们判的是「拦不拦」，不该真去等一行输入）；符号引用没变，指纹没动。

**验收**：`go build`／`go vet`／`gofmt -l`／`go test ./...` 全干净；17 包零违规、红线 30 条、放行台账 0 条。
