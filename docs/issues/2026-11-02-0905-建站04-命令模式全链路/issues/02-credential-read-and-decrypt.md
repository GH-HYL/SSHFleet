# 02: 凭据包——读主密钥、解密码、报齐不齐

**要做的**：加密开着时，配置里的密码与私钥口令是**密文文件的路径**。做完之后，执行站拿着清单里那一格，能向凭据包要出明文密码；主密钥没读到时，凭据包交回「不齐」这个状态，由塔尖或解析站去说话——它自己不造屏、不退出。

**Blocked by**：无，可立即开工。

**Status**：ready-for-agent

## 边界

- 加密关着：本包**不参与**，凭据位置本身就是密码／口令（此时它的入口不该被调用）。
- 主密钥从环境变量 `SSHFLEET_KEY` 读，读不到、格式不对，一律交回状态，不报错、不中断。
- 三条密钥命令（生成、看状态、转换）**不在这里**，随阶段 08 落 `keytool`。本包只有读、解、报状态。
- 横切叶子包：只许依赖标准库与契约（ADR-0032 第四条）。零第三方依赖——加解密走标准库。

## 验收

- [ ] `testdata/` 里一份明文与一份密文样本，密文用固定主密钥算出；期望明文写死在测试里，不用被测代码自己解一遍再比
- [ ] 主密钥缺失／格式错两种情形，入口交回的状态能被调用方分辨（不是只有 error 一个值）
- [ ] 红线：一条新测试钉住「只回状态、不写终端、不起进程」
- [ ] `go.mod` 无新增 `require`；`go build ./... && go vet ./... && gofmt -l . && go test ./...` 全绿

## 不在这单

密钥管理那三条命令（08）；私钥 PEM 的解析与口令（随 05 的上传下载一起验，本阶段只到「密码能解出来」）。

## 做完之后

09 号单（连一台）用它解出的密码认证；真机验证时沙盒里 `--gen-key` 造一把临时主密钥。
