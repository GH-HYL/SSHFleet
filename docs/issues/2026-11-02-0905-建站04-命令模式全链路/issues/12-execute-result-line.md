# 12: 执行站出那一行——拼一次，去三个地方

**要做的**：每跑完一台，立刻出这一行：屏幕上一行、`terminal-output.txt` 一行、执行期日志一行，三处同一个样子。做完之后，跑一台就看得到一行；中途被强杀，盘上已经有痕迹。

**Blocked by**：11（这一行里要有分类）、03（路径）、04（执行期日志）、07（那一行要过 `mask`）。

**Status**：ready-for-agent

## 要落的判断

- **只拼一次**（13 号工单 §四／§五）：句子由 `message` 造，执行站拿它交 `console` 打屏、写进终端输出文件；执行期日志那一行另交 `log` 写。三处不是各拼一遍。
- 13 号单会把「打屏」这一步换成 `console` 交出的同一个 writer（进度界面要独占屏幕，见那张单）——**本单先按 `console` 打，行为不变，那张单只换出口**。
- **来一条写一条，不攒**：这是目的，不是优化——防的是被强杀时盘上什么都没有。
- 落盘不节流，屏幕也不在本单节流（进度界面随 13 号单）。
- 执行站自己不碰标准输出：写终端那一类检查不许出现新违规。
- 终端输出文件的路径向归档包要；文件名只在执行站这一处出现（结算站与报告站的代码里出现它，就是有人在重写）。
- 那一行里的秘密（内联清单的密码之类）**用 07 号单落下的 `mask` 遮过再拼**——执行站不自己写一份遮法。
