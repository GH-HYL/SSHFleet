# 15: 报告站——屏幕统计块与 `report.txt`

**要做的**：跑完之后出两样：屏幕上一段统计块（总台数、成功失败、连接成败、失败分类与提示语、成功分类、总耗时），与本次归档目录里的 `report.txt`（第一段是这次敲的命令与执行参数，后面跟着每个分类的机器清单与原文）。做完之后，使用者跑完看屏、事后翻文件，都与老版一个样。

**Blocked by**：14、03（路径）、01（第三张纸与运行上下文）、07（`mask`）。

**Status**：done（已完成）

## 要落的判断

- **屏幕统计块**逐字照老版（`output/terminal.go` 统计块那半）：分类排序、提示语那一行、末尾「没跑」那一句。
- **`report.txt`** 逐字照老版（`output/report.go`）：段标题、字段顺序、时间格式、每个分类下面怎么排。
- **运行上下文的用法**：报告站是**唯一**解开它的地方（ADR-0035 决定九）。解不开就是加解密两处漂了——这条直接报出来，不许退回到「拿别处的值顶」。
- **第一段那三样**：执行命令（原值，先遮后写）、执行参数、以及「节点清单：…」那一行——最后这一行的清单路径来自第三张纸随行件里的「执行资源」，别再回头问解析站要。
- 遮秘密一律走 07 号单落下的 `mask`，报告站不自己写一份遮法，也不用解析站的内部实现。
- 报告站是四处可写终端的地方之一（ADR-0032 第四条）：它上屏的那一段仍走 `console`，不自己 `fmt.Print`。
- 不写 xlsx、不备份资源、不写清单副本（07）。

## Comments

### 2026-11-02：开工前的两处缺口（要开发者定，代码未动）

照老版 `output/terminal.go` 的统计块逐行核过，报告站缺两样**纸上没有的东西**，一样都绕不开：

1. **`enable.show_category_tips` 这个开关**。老版统计块按它决定末尾出不出「提示：」那一段（关掉时退回「常见退出码」那一行）。配置项解析站读得到（`parse/config.go:275`），可没往纸上带——报告站手上只有第三张纸，读不到配置。**不加这一格**，统计块就只能恒显提示，与使用者关开关的意图不符（那是改行为）。
2. **判据文件的展示路径**。「未归类」那三行里有一句「可把它的特征词补进 `<判据文件路径>`」，老版用 `config.DisplayPath(config.BuiltinPaths.ErrorKeywords)` 算。新工程里这个路径只有解析站知道，报告站同样拿不到。

两处都是「加一格契约」，按规矩属单独点头档（14 号单刚加过一格 `ResultPaper.Resources`，那是有 04 规格第二节做依据的；这两格没有，所以停在这里问）。

建议的加法（各一格，都进第一张纸的「执行参数」那一段，随纸一路带到第三张）：

- `RunParams.ShowCategoryTips bool` —— `enable.show_category_tips` 的原值；
- `RunParams.ErrorKeywordsPath string` —— 判据文件的展示路径原值（解析站已按老版 `DisplayPath` 算好，报告站只管印）。

不加的退路（都不好看）：统计块恒显提示（改行为）；路径那句改成写死「判据文件」（丢信息）。

### 2026-11-02：两格进了运行上下文，报告站一次全拿到

开发者的口径（原话）：「report.txt 这块我记得是单独走个加密的上下文，之前决策过」；「上下文里面就是给 report.txt 用的，他要什么，分析站就给什么，反正一个分析站就直接全获取了，直接打包好加密」。**「分析站」即解析站。**

据此改了加法：**不加 `RunParams` 两格**，改加进 `contract.RunMetaBody`——`ShowCategoryTips bool` 与 `ErrorKeywordsPath string`。三条理由：

1. 两样的消费者只有报告站（`ShowCategoryTips` 用在 `report.txt` 与屏幕统计块两处，判据文件路径只用在屏幕「未归类」那三行引导里）；
2. 进 `RunParams` 等于让闸门、执行站也揣着两样永远用不上的东西——那正是当初把这一格封起来要拦的样子；
3. 运行上下文是「第二类格子」，不参与「后一张不许比前一张宽」的计法，**第一张纸一格都没变宽**。

代价两条：`RunMetaBody` 的口径从「使用者敲了什么」扩成「报告站出那两样要用的原值」（含呈现口径），已改头注释；封与解两处各有一条固定密文样本，随之重录（`RunMetaVersion` 没动：两侧同步改，盘上没有旧数据）。ADR-0035 末尾追加了更新记录。
