# 06: 解析站预检——IP 格式、重复、空行

**要做的**：清单读出来之后，先把「这份名单本身有没有毛病」判一遍：IP 不是 IPv4 字面量、同一台写了两遍、整行是空的。做完之后，这些毛病在确认屏之前就报出来，不会跑到一半才发现清单写错。

**Blocked by**：05。

**Status**：ready-for-agent

## 边界

- 预检归解析站（ADR-0032 决定一：校验归最懂那份材料的那一站），**闸门不重判**。
- 只判「材料本身对不对」，不判「这件事该不该做」——那是闸门。
- 报的时候只交事实（第几行、哪一处），句子由 `message` 造。

## 验收

- [ ] 三类坏样本各一条：坏 IP、重复行、空行；每种交回的事实能被区分（不是一句笼统的「清单有错」）
- [ ] 三种坏样本的屏上原文与老版逐字相同（从老工程同一份输入跑出来录）
- [ ] 一份干净清单预检之后不产生任何事实，节点数不变
- [ ] `go build ./... && go vet ./... && gofmt -l . && go test ./...` 全绿

## 不在这单

清单字段的合法性（端口范围、用户名为空）——老版在哪一步判就还在哪一步判，本单不搬新的判断进来。
