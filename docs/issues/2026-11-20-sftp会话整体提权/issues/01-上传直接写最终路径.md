# 01: --sudo 上传直接写最终路径

**要做的**：`--sudo` 上传时，`sftp` 会话以 root 跑，文件直接写到最终路径——目标机上不再出现 `/tmp/.SSHFleet_tmp/` 下的暂存目录，也不再走 `sudo mv`。做完之后，往一个 700、属主 root 的目录上传能成，失败时不再有 `tmp_failed`／`sudo_failed` 这两种环节名。

**Blocked by:** 无，可立即开工。

**Status:** done

- [ ] `--sudo` 上传到 700、属主 root 的目录成功，落位文件属主是 root
- [ ] 上传结束后目标机上不存在 `/tmp/.SSHFleet_tmp/`，过程中也不出现
- [ ] 探不到 `sftp-server` 时，该台失败，报错原文含 `sshfleet.transfer.client_failed` 与 `sftp-server not found under sudo`
- [ ] sudo 拒绝提权时，该台失败，报错原文含 `sshfleet.transfer.client_failed` 与 `sudo refused to run sftp-server`，并带 sudo 原话
- [ ] 非 `--sudo` 上传行为不变：既有上传用例全绿
