# 02: 报告站的失败出口换成「起不来」的纸（红线区）

**要做的**：`report.Run` 失败时不再交 `error`，改交 `*contract.CannotStart`——写报告文件、备份执行资源、存清单副本、运行上下文解不开这四种失败各归一个类别，句子由 `message` 出。塔尖那一处照执行站同形接纸。

**Blocked by**：`docs/adr/0057-报告站失败出口交纸.md`（红线区，规范一.1 第七条：议题＋ADR 两样齐了才动手）。

**Status**：done

- [x] `report` 包里不再用 `fmt.Errorf` 拼屏上的话；`report/runmeta.go` 交 `contract.CannotStartReason` 加一个「坏没坏」，与解析站封侧同形
- [x] `contract` 有四个新类别（写报告、备份资源、清单副本、运行上下文解不开那一族四条），`message` 有对应模板，拼出来与改前逐字一致
- [x] `main` 那一处改接纸（`fatal(cannot.Where, message.CannotStartBody(*cannot), toolPath)`）
- [x] 红线 `TestRedlineReportScreenAndPath` 的出参断言改成「要留痕的话 + 纸」，头注释同步
- [x] `guard/redline.go` 那一行登记照报错里印出的照抄（符号表加 `contract.CannotStart`；喊失败次数不变，还是 5——换掉的是被钉的那个类型，没有多一条断言）
- [x] 本包用例改判「哪一类、带哪些格」，不再断言 `err == nil`
- [x] 判据仍绿：`go test -count=1 ./internal/report ./internal/message ./internal/guard`；`go test -count=1 -run TestRedlineReportScreenAndPath ./internal/guard`

## Comments

**2026-11-17 落地**：`report.Run` 出参改成 `([]message.Line, *contract.CannotStart)`，`Where` 一律 `contract.WhereOutput`（与执行站一致）。`openRunMeta` 与 `runMetaGCM` 改成 `(值, contract.CannotStartReason, bool)`，与 `parse` 封侧同形；建不出密码器／GCM 复用 `CannotStartRunMetaCipher`／`CannotStartRunMetaGCM`，不另开类别。

登记表 `TestRedlineReportScreenAndPath` 的符号表加 `contract.CannotStart`；次数仍是 5——红线的报错把新旧两行都印了出来，照抄的只有符号表。

**与拆单时说的一处不同**：工单原写「喊失败次数跟着加一」，实测没有。新断言是替换 `reflect.TypeOf((*error)(nil)).Elem()` 那一条表达式，`t.Fatalf` 仍是五处。

**屏上字节**：拿改前那八句（含 `runmeta` 两条复用类别）逐条比过一次，全等——一次性用例跑完即删，没有留在仓库里。
