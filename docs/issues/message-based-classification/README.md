## 这是什么

工具自己编的中文错误（`建立连接失败 - dial tcp …`）与写死的中文分类名（「部分成功」「任务已取消」），现在由代码直接给分类名；使用者改配置改不动它们。这件事要把它们统一成 `sshfleet.<环境>.<环节>: <英文>` 报文，交给判据文件匹配——**分类名从此只有一个来源：配置匹配到什么就是什么**。

## 怎么开始

1. **先做 01**。它是摸底，产出一份 `audit.md` 清单，**不改任何代码**。做完停一下——后面每一刀都要照这份清单动手。
2. **再做 02**。这一刀最重也最关键：报文格式、发报点与纯函数、10 个结构性分类的报文、`code_defined` 删除、校验规则改到终态，全在这里落定。**做完 02，框架就定死了**，03–06 只是照抄。
3. **03–06 顺着做**。每张只往配置里补报文条目，不再动校验规则。
4. **07 收尾**。核对残留、跑五种模式的端到端验收、更新 CHANGELOG 与手册。

## 三条最容易踩的坑

- **别把「结构性分类」当成报文**。部分成功、改密四档、任务已取消这些是**结构事实**，由看见事实的那一处发一句陈述事实的报文（`sshfleet.transfer.finished: 6 of 10 files transferred`）；**「密码过期」是唯一的例外**，它是远端说的话，不发报文（ADR 决定第 9 条）。
- **报文里不许出现结论词**。用 `finished` 不用 `partial`，用 `canceled` 不用 `failed`。叫不叫「部分成功」是配置里 `name` 的事。
- **判定层不许自己给分类名**。`Judge` 只查表；删掉所有「按结构字段直接给名字」的分支。

## 验收的硬标准

- 分类语料（`modules/SSHFleet_Go/testdata/error_classification_cases.toml`）**33 条全绿，期望分类一个都不许变**。其中 **17 条**的 `error` 字段是工具自编的中文，要换成报文输入。
- `go build ./...`、`go test ./...`、`go vet ./...` 全过。
- 07 的端到端验收：五种模式各跑一次，统计块是配置里的分类名、错误详情与 xlsx/日志是同一份报文原文。
