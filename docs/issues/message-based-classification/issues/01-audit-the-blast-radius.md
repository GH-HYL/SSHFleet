# 01: 摸底：把改造面清成清单

**要做的**：动代码之前，先产出一份实施清单，回答四个问题——① 工具自己编中文的地方到底有多少、分别在哪；② 现有测试里哪些断言的是「分类语义」（必须保绿），哪些断言的是「字符串措辞」（要跟着改）；③ 哪些代码位置依赖「密码过期」这个中文名；④ 每个结构化分类的**事实来源**是什么，报文该在哪一处发。做完之后，后面每一刀都能照着清单动手，不用再回头搜一遍。

**实施入口**：`docs/issues/message-based-classification/README.md`。

**被谁阻塞**：无，可立即开工。

Status: ready-for-agent

## 验收

- [ ] 清单落进本议题目录下的 `audit.md`，含：工具自编中文的完整清单（按包分组，标注是否参与关键词匹配）、`sshfleet.<环境>.<环节>` 的归类建议（每条报文属于哪个环境）、测试断言的分类（语义 / 措辞）。
- [ ] 中文点要**给出精确计数**，不许写「约」。已知量级（2026-10-20 初核，须逐条落表核实）：`ssh` 包 `Error = strPtr("…")` 中文 11 处、中文 `fmt.Errorf` 21 处、`fmt.Sprintf` 拼中文 15 处；`batch` 包中文 `fmt.Errorf` 10 处；判定包 11 个中文分类常量。**每条都要标明「会不会落进报错原文那一格」**——这是「改还是不改」的判据（进输出明细的跳过行不归报文管）。
- [ ] **逐条标出判定性质**：这条是「文本判定」（读报错原文）还是「结构判定」（读布尔字段 / 计数）。11 个分类常量逐个列出它读哪些字段，作为「谁在哪一处发报文」的依据。
- [ ] 把**不归报文管**的少数点单独列出来，说明为什么保持中文：参数校验（`触发词不是合法正则：…`、`未提供有效的认证方式…`、`这把私钥有口令，没有给口令`）、启动期写进工具日志的诊断提示、逐文件的成功 / 跳过行（`a.txt: 已跳过（符号链接）`）。
- [ ] 列出所有读「密码过期」中文名的地方（改密入场信号、代填中止词、`main.go` 守卫），以及它们各自真正需要的是什么。**结论应当是：它们要的是「远端那句提示的关键词」，不是分类名由代码给出。**
- [ ] 列出判据文件里以中文前缀为关键词的条目，与工具自编中文逐一对应。已知有 **8 条**（本地文件一族 4 条 + 无法建立会话一族 3 条 + `握手超时` 1 条 + `命令执行超时` 1 条，最后两条与前三者跨族），核实有没有遗漏。
- [ ] 清点**SSH 库已经分好类但代码没用上的错误类型**（`*ssh.ExitMissingError`、`*ssh.OpError` 系列等），说明按 ADR-0021 第 8 条「只许无损翻译」各自该翻成什么报文。
- [ ] 清点**出厂报文全集**：逐条给出环境、环节、报文原文、发报的包与函数，落成一张表（这是「出厂报文有哪些」的唯一清单）。用户自己写的分类关键词不算在内。
- [ ] 列出**所有写报错原文的语句**（现在是清一色的 `result.Error = strPtr(...)`），逐条标明改造后是「整句换成报文」还是「在已有原文后面追加报文」——后者一处都不能写成覆盖。
- [ ] 列出**每个结构形态读哪几个字段**，以及「形态 → 报文」那个纯函数该收哪几个入参（改密四档 + 密码未过期、代填两条、传输 `finished`、取消两条），供 02 落成纯函数。
- [ ] 列出**所有把「报错原文是不是空的」当判断依据的地方**（`verdict.go` 的 `cleanStop`、`提示词没认出`、`改密未完成` 三处），标明改造后各自由哪条报文接管、凭什么条件发出；`cleanStop` 那条保留，另两处消失。
- [ ] **测试断言的语义 / 措辞分类**：逐个测试文件标注，哪些断言分类语义（必须保绿）、哪些断言字符串措辞（要跟着改）；凡以中文错误文本作**输入**的用例，列出来并给出改造后的报文输入。
- [ ] 不改任何代码与配置。
- [ ] **本工单不宣称可独立演示**：它交付的是清单，后端到端验证由后续工单承担。
