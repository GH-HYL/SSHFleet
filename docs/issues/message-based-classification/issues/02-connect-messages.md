# 02: 报文格式落地，建连这一摊先改

**要做的**：连一台**端口没开**的机器，屏幕上那行错误从 `建立连接失败 - dial tcp …: connect: connection refused` 变成译文形态的中文；而归档的 xlsx 与执行日志里能查到 `sshfleet.connect.refused: dial tcp …: connect: connection refused` 原文。分类仍然是「拒绝网络连接」。走通这一条，报文格式、生成、翻译、呈现四条都通了，剩下的批次只是照抄。

**被谁阻塞**：01（摸底清单）。

**状态**：ready-for-agent

- [ ] 报文格式与七个环境取值在代码里有一处声明，新增报文照此写（按 ADR-0021「决定」第 1、2 条）。
