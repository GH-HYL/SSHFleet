# 01: 检查器的地基——把源码读成包与语法树，违规按一种话说出来

**要做的**：检查器能从「一个模块根」读出「哪些包、哪些文件、每个文件 import 了什么、里面有哪些花样」，并把一条违规按固定四样说出来。做完之后，任何人写一条新的判据，只要交一个 `Target`、拿回一串违规，不用再碰读源码那一层。

这一单不判任何一类越界——六类都还是空的。它交付的是**尺子**与**说法**。

**Blocked by**：无，可立即开工。

**Status**：ready-for-agent

## 判据

- 走目录与 `go list ./...` 同口径：跳过 `testdata`、以 `.` 或 `_` 开头的目录、`vendor`；根上的包就是塔尖。
- 源码用 Go 自带的语法树库解析。**不按文本搜**：注释里写的、字符串里带的都不算越界。
- 每个包对规则表的一行（`guard/rules.go` 那张）。对不上是第六单（依赖方向）的事，本单只负责把「对不上」这个事实交出去。
- 一条违规写清四样：类名、位置（模块内相对路径＋行）、哪里绕开了、该走哪一处；开头一句「这是结构约束，不是功能测试」。
- 样本模块住 `guard/testdata/`，一个假模块一个目录；假模块不要求能编译，能被解析就够。

## 验收

- [ ] `go test ./...` 绿；`go vet ./...`、`gofmt -l .` 干净
- [ ] 一条测试对着 `modules/SSHFleet2_Go` 跑，数出**十七个包**，且塔尖对的是模块名 `sshfleet2` 那一行
- [ ] 一条测试对着 `testdata/` 下的假模块跑，数出的包数与目录里的一致（跳过的 `testdata`、`.`、`_` 三条各有一只样本）
- [ ] 违规的输出里同时出现类名、位置、哪里绕开、该走哪一处；少了任何一样，这条测试自己红
- [ ] 注释里写 `fmt.Println("x")` 不产违规；字符串里带 `os.Exit(1)` 不产违规

## 不在这单

六类判据（02–06）、名单与台账（07）、旧 ADR 路径（08）。
