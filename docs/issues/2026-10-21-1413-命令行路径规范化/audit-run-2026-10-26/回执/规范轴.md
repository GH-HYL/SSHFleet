### H2 `CHANGELOG.md:15` 有两处对「改之前是什么样」的陈述不成立

**位置**：`CHANGELOG.md:15`（`[12.0.2]` 段两条 Changed 里的第一条）

**(a)「（以前原样交给远端，由远端决定成败）」——不成立，以前是本地压平掉的。**

`git show 0da83af:modules/SSHFleet_Go/internal/cli/args.go`：

```text
441:		*val = normalizePath(*val)      // 作用对象含 &a.Path 与 &a.Download
505-521:	// normalizePath … path.Clean …
510:	endsSlash := strings.HasSuffix(p, "/")
520:	cleaned := path.Clean(p)
```

所以升级前的 `12.0.1` 里：`-p /opt//app/` → `path.Clean` → `/opt/app/`（末尾 `/` 还被补回），`-d /var/log/../log` → `/var/log`，**两条都能跑通，而且指向被静默改过的路径**。条目把旧行为写成「原样交给远端」，恰好把这条改动最该说清的一句（「以前是悄悄压平，现在会拦」）说反了。

**(b)「任何路径两端带空白」会报错——在 Windows 上漏一格。**

**改法**：把「以前原样交给远端，由远端决定成败」改成「以前被本地压成 `/opt/app/`、`/var/log` 从而跑得通」；把「任何路径两端带空白」限定成「本机路径的前导空白、远端路径的两端空白」。

### J2 `cli/check.go:321-341`：拿报错文案串当分支条件

**位置**：`modules/SSHFleet_Go/internal/cli/check.go:325-341`

```go
	reason := ""
	switch {
	case strings.ContainsAny(p, " \t"):
		reason = "不能含空格或制表符，当前值："
	…
	case !strings.HasPrefix(p, "/"):
		reason = "必须是绝对路径，当前值："
	…
	}
	if reason == "必须是绝对路径，当前值：" {          // 337 行：字符串相等决定走哪套句式
		return fmt.Errorf("%s 参数指定的%s必须是绝对路径，当前值：%s\n提示：…", …)
	}
	return fmt.Errorf("%s 参数指定的%s不干净：%s%s\n提示：%s", …)
```

`reason` 同时承担三件事：分支标记、文案片段、以及「当前值：」这种排版尾巴。**代价**：`reason` 的值一旦被改动（本议题两轮里这类文案已经改过多次——`args_test.go:809` 就去追着改过一处断言），337 行的相等判断会**静默失效**：不报错、不 panic，四种形态里偏偏「绝对路径」那一类会掉进「不干净：必须是绝对路径，当前值：…」这套句式，报出「-p 参数指定的上传目录不干净：必须是绝对路径，当前值：/x」这种自相矛盾的话。编译器拦不住，现有测试也只断言 `strings.Contains(cerr, "必须是绝对路径")`（`args_test.go:857-885`），两种句式都能过。

**改法**：用一个具名常量或 `switch` 直接产出 err（同一分支里 `return`，不落回公共尾巴）。

### J3 `main.go:134-135`：`wrapFatal` 名为「包装」，实为字符串拼接，error 链断了

**位置**：`modules/SSHFleet_Go/main.go:134-135`

```go
func wrapFatal(head string, err error) error {
	return errors.New(head + "：" + strings.TrimRight(err.Error(), "\r\n"))
}
```

`errors.New` + 字符串拼接会丢掉底层 error：此后 `errors.Is` / `errors.As` 在内层链上都取不到东西。当前唯一的消费点是 `fatal(where, err)`（打印 + 写日志 + `os.Exit(1)`），所以**今天不出错**；这也是我把它放在判断题而不是硬伤的原因。**代价**：这个名字会让人以为它做了 Go 意义上的包装；将来任何一处想在最外层加一层 `errors.Is` 判断（例如把某类错误改成非零退出码之外的处置），拿到的是一个不带链的 `errorString`，且不会有人想到是这三十行之前的一层拼接断掉的。Go 的惯用写法是 `fmt.Errorf("%s：%w", head, err)`。

**改法**：要么改用 `%w`，要么把名字改成 `joinFatalHead` 之类不带「包装」含义的词。
