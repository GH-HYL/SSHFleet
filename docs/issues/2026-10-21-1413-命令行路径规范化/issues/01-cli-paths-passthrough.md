# 01: 命令行路径原值直通，四个选项不再被改写

**要做的**：`-s` / `-u` / `-p` / `-d` 给的路径，程序一个字节都不改就交给对应的系统：本机路径交给本机文件系统，上传的 `-p` 与 `-d` 当字符串原样下发。原先那个会去两端空白、把 `\` 换 `/`、把盘符归一成 `C:/`、压掉 `..`、补回结尾 `/` 的环节整个消失。本地路径打不开时，报错按三行写：哪一项、什么问题、当前值 / `原因：` 系统原文 / `提示：` 怎么改；屏幕上一屏只有一个「原因：」（外层包装改成冒号收尾）。**删的只是命令行这套字符串规范化**——危险检测里那个名字相近的「路径片段整备」是另一件事，别顺手一起删。
