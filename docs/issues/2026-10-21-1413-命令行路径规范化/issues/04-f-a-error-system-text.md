# 04: `-f` / `-a` 的报错带上系统原文

**要做的**：`-f` 与 `-a` 给的值既不是文件、也不像一条内联记录时，报错与本地路径同一套形态：第一行说清哪一项、什么问题、当前值，第二行给系统原文（不带路径重复），第三行给这一侧的去路——`-f` 是「把节点写进 CSV 文件再指过来」，`-a` 是「直接写代填内容就用逗号分隔」。现在系统那句话被丢掉了，只说「文件不存在」。**同样的丢失还有两处，一并收进来**：`-f` 指的 CSV 确实存在却读不了、`-a` 指的文件确实存在却读不了，这两条现在也只剩「不可读」三个字。外层的「一屏只有一个原因」由 01 统一改，本工单只保证内层这三行。
