# 规格：判据叶子包

**状态**：done
**底本**：`docs/issues/2026-11-09-0945-切换前回顾审计/修复面盘点.md` §4.3
**决策**：`docs/adr/0051-判据叶子包.md`

## Problem Statement

同一条判据要在两个包里用的时候，全工程没有地方放它，只能各写一份。现在有六条各写两份：合法 IPv4（解析站与 `mask`）、剥掉 `open <路径>:` 前缀（`message` 与凭据包）、单引号转义（三处两种形状）、`identityLabel`、解释器名归一、解释器名表。

复制本身不致命，致命的是**紧的那份丢了没人知道**：`010.0.0.1` 曾被当成合法节点送进凭据预检（06-H1）；凭据包那份剥前缀的函数少一支 `os.LinkError`，注释还写着「改这里要一起改那边」，而老版 `common.SystemReason` 两支都有。

类二只判依赖方向，对「同一条判据两份」这件事没有落点——两份漂开时没有任何东西会红。

## Solution

新建第十个横切叶子包 `criterion`：零业务，只放判定与取值这类纯函数，五站与其余横切包都可依赖它。

第一版只搬两条有证据的：合法 IPv4（06-H1 的实跑差异）与剥系统前缀（已经漂了的那条）。搬完这两条在全工程只有一份，测试跟着包走（自定义区），把判据本身钉死——前导零、`os.LinkError`，谁放宽了跑测试就红。

## User Stories

1. 作为维护者，我希望「是不是合法 IPv4」全工程只有一份，改判据时不必去找第二份。
2. 作为维护者，我希望「剥掉系统前缀」只有一份，且与老版一致，不必靠注释「改这里要一起改那边」。
3. 作为审计者，我希望这两条判据的边界有测试钉住，任何人放宽都当场红。
4. 作为下一个要写判据的人，我希望有一条明确的路可走，而不是复制一份。
5. 作为使用者，我希望 `010.0.0.1` 这类写法被认成非法 IP，而不是被当成一条内联记录收下。

## Implementation Decisions

- **包名 `criterion`，横切、叶子**：只依赖标准库，连契约都不依赖——它不产数据、不造话，与 `interrupt` 同一行形状。
- **准入判据**：两个以上包要用同一条判据、且任何一方都不该替对方提供时，才搬进来。不是「看着通用就放进来」。常量不进这里，仍归 `message`／`contract`。
- **`IsIPv4`**：判据照 `netip.ParseAddr` ＋ `Is4`，函数内自己 `TrimSpace`，与现状逐字同；`010.0.0.1`、`256.0.0.1`、四段不足一律不认。
- **`SystemReason`**：取 `message` 那份（`*fs.PathError` 与 `*os.LinkError` 各剥一支，其余原样），与老版 `common.SystemReason` 逐字同；凭据包那份删除。
- **四处改为调用**：解析站三处、`mask` 两处、`message` 与凭据包各一处，本地副本一并删除；`parse/nodelist_test.go` 里直接调本地函数的用例改为调 `criterion`。
- **凭据侧向老版收拢**：它此前少 `os.LinkError` 一支，只有真碰到 `LinkError` 才有差；这是修漂，不是改行为。
- **不搬另外四条**：单引号转义（三处两种形状，接口还没定）、`identityLabel`、解释器名归一、解释器名表——各有更合适的家或形状未定，留到切换后。

## Testing Decisions

- **接缝**：新包只有两个导出函数，从公开函数直接测——这是能提的最高接缝，不必穿过五站。
- **进自定义区，不进红线区**：这两条断的是「值算得对不对」（哪些串算合法 IP、哪一截该剥掉），规范三.3 把值断言划出红线区。测试跟着被测包走，`package criterion`，与 `mask` 的做法一致。
- **两条测试**：`TestIsIPv4`（前导零、超界、段数不足、IPv6、带掩码、空、前后空格、正常值）；`TestSystemReason`（`*fs.PathError`、`*os.LinkError`、普通错误各一）。期望值全是写死的字面量，不与被测代码同源。
- **反向验证**：把 `IsIPv4` 放宽成「含点即真」、把 `LinkError` 一支删掉，两条各红一条；改回即绿。
- **真工程整跑**：`TestProjectIsClean` 零违规，包数从十八变十九——规则表不跟着改，这一条当场红。

## Out of Scope

- 另外四条同族判据（单引号转义、`identityLabel`、解释器名归一、解释器名表）。
- 06-H1 那句「第一列不是合法 IP」的报错文案：审计 4.5 裁过，但代码里还没有这句话，另案（见交接件 §七.2）。
- 类别名、解释器名这类常量——留在原处。
- 阶段 10 切换。
