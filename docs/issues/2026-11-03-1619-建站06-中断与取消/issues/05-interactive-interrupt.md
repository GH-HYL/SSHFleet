# 05: 代填与改密跑到一半被中断，说的是「被中断」不是「没送完」

**要做的**：代填正在等远端问话、改密正在等提示的时候按 Ctrl+C，屏幕上与报告里说的是「被中断」——不许把中断说成「代填没送完」或「密码没改成」，改密也不许被中断拖成「干净成功」。

**Blocked by**：01、02（要能取消、统计要认缺额）。

**Status**：ready-for-agent

- [ ] 真机代填中断：`-c` 配 `-a`，远端脚本问一句后停住，跑到一半发 `SIGINT` → 那台归「任务已取消」，不是「代填未命中」；`Answer.Missed` 不因中断而写成「没送出去」
- [ ] 真机改密中断：容器里 `chage -d 0` 的账号，改密场次停住时发 `SIGINT` → 那台不判成功（干净收场的四条里「没被中断」挡着），归「任务已取消」
- [ ] 两者的报错原文都带 `sshfleet.abort.canceled: interrupted after session established`，次序与其余通道一致
- [ ] 中断那次的 `report.txt` 执行参数段照常印（代填明细 / 新密码脱敏形态），不因中断缺段
- [ ] 正式对新老两版归 06 统一比；本单只判行为——那台归哪一类、报错原文里有没有那句报文
- [ ] `gofmt -l .` 空、四项检查与 `go test -race` 绿

**不在这单**：改密 `no_prompt` 一档（容器里造不出来，仍归手工）。
