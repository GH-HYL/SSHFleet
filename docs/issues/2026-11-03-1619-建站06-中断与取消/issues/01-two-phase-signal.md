# 01: 塔尖按 Ctrl+C 分两段收场

**要做的**：按 Ctrl+C 时，执行前与执行中走两条不同的路——执行前立刻退、码 130、不建归档目录；执行中把取消交给执行站，走正常收尾。做完之后，中断不再是「进程被系统杀掉」。

**Blocked by**：无，可立即开工。

**Status**：ready-for-agent

- [ ] **动手之前先拿到 `guard` 那张塔尖符号表的点头**（规格第六节：加 `os.Signal`／`os.Interrupt`／`signal.Stop`／`signal.NotifyContext` 与 `syscall` 一格）；没点头之前不碰塔尖——塔尖一加信号，四项检查那一条立刻红
- [ ] 启动段（控制台摆正之后、交棒之前，含解析、闸门、确认屏）收到 `SIGINT`：还控制台、退 130、**不建归档目录**
- [ ] 交棒点在建归档目录之前，次序是**先建执行期的 `context`、再 `signal.Stop` 并关闭早期通道**（照老版，两个阶段之间不留空档）
- [ ] 执行期那条 `context` 交给执行站（`context.Background()` 那处换掉）；取消后第二次 Ctrl+C 不额外退出
- [ ] 执行中的中断仍走正常收场，退出码 0（节点有失败也是 0）
- [ ] 真机：确认屏停住时发 `SIGINT` → 码 130、`history/` 下没有新目录；`-c 'sleep 30'` 跑到一半发 `SIGINT` → 进程自己退、码 0
- [ ] `gofmt -l .` 空、四项检查与 `go test -race` 绿

**不在这单**：纸上那格 `Interrupted`、屏幕那句提示（02）；两条通道的报文（03）。
