# 规格：39 条架构取舍的判定

**状态**：ready-for-agent（判定表已定；09-3、11-J9 已裁并办完，剩九条「动」待拆单）
**底本**：`docs/issues/2026-11-09-0945-切换前回顾审计/修复面盘点.md` §2.3（原 42 条，扣掉 11-H1／11-H2／11-H4 三条已办或已判）；逐条细则在 `…/audit-run-2026-11-09/报告.md` §2.5 与各回执。

## Problem Statement

切换前那次审计留下 42 条「只是架构取舍」：每一条都不是 bug，是当初在两条路里挑了一条、代价没写进任何地方。它们散在十来份回执里，只有一句话摘要——下一个人要么重读审计，要么当它不存在。审计之后这三条已处理，剩下的 39 条一直没结论。

## Solution

逐条判「动」或「留」，一族一族判、不一条一条问。**判的依据是审计那一句话与位置**；判「动」的进工单，判「留」的把代价写在这张表里——这就是它唯一的存档处，不再另开 ADR（单条代价不够格，整批记在这里）。

**这一版没读细则**：判「动」的九条在动工前要先按 `报告.md` 那一条的细则核一遍现场；判「留」的二十八条以摘要为据，若日后有人发现摘要失实，改这一行即可。
