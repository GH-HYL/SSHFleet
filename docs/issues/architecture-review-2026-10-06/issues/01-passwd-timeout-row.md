# 01: 改密模式的超时行补上

Status: resolved
Blocked by: None

**要做的**：把改密模式的超时行补进参数确认屏与报告文件。

**现状**：`confirm/confirm.go:127-133` 与 `output/report.go:83-89` 的 switch 只认两类——命令/脚本 →「执行超时」、上传/下载 →「传输超时」，**没有 `default`**；改密哪一类都不算，所以按下确认前和报告里都看不到 `-t` 的值——而超时是改密唯一的兜底手段。默认值早已备好（`args.go:270-275`，改密不传 `-t` 时取 `timeout_execute`，来自 8.0.0 的 `a372304`），只是这两处不认它。

**改法**：两处的被判对象从「看哪个选项非空」换成 `a.ModeName()`，加第三路：

```
ModeCommand / ModeScript → 「执行超时」
ModeUpload  / ModeDownload → 「传输超时」
ModePasswd  → 「改密超时」
```

措辞定**「改密超时」**，不写「执行超时」——用户看的是「这次改密等多久」，写成「执行超时」会让他以为在跑命令。**不改配置键**，`-t` 默认仍走 `timeout_execute`。

顺带：这两处换成 `ModeName()` 后，不再新增「看哪个选项非空」的散落判定，与将来集中化（工单 05）同向，届时不必再改这两处。

- [ ] 改密模式参数屏出现「改密超时：Ns」行（不传 `-t` 时显示默认值）
- [ ] 改密的 report.txt「执行参数」段出现「改密超时： Ns」
- [ ] 其余四种模式的超时行措辞一字不变
- [ ] `go vet ./...` 干净、`go test ./...` 全绿
