# 术语对照表（翻译统一口径）

本目录是 Matt Pocock 技能集的中文学习版。翻译规则如下：

1. **文件名、目录名**：保持原英文，不改动。
2. **链接**：一律不改动，即使指向的文件已被翻译成中文。
3. **frontmatter 字段名**（`name:`、`description:` 等）：保持英文；`description` 的**值**翻译成中文。
4. **正文中的专业术语**：中英对照，格式为「中文（English）」，首次出现时给出，之后沿用中文。
5. **白话叙述**：直接翻译成中文，不做对照。
6. **代码块、命令、路径、标识符**：保持原样，不翻译。
7. **非 .md 文件**：原样保留，不翻译。

## 已知的取舍

- `harness` 在 `diagnosing-bugs` 里指「测试装置」，在 `ask-matt` 里指「宿主环境」，两处按词义分别定名，均带英文对照。
- `code-review` 的 `## Standards` / `## Spec` 两个轴名，以及 `to-spec`、`triage` 模板里的标签值（如 `ready-for-agent`），**保留英文未译**——它们是被程序或 agent 直接引用的字面量。
