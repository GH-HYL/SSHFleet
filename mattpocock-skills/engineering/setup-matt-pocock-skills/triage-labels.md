# 分诊标签（Triage Labels）

这些技能用五个标准分诊角色（triage role）来说话。本文件把这些角色映射到本仓库问题追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们追踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整写明规格，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要由人来实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当某个技能提到某个角色时（例如「应用 AFK-ready 分诊标签」），使用本表中对应的标签字符串。

按你实际使用的词表修改「我们追踪器中的标签」这一列。
