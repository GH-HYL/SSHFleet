# 阶段边界

一个**阶段（phase）** 是会话内部的一整块工作：拷问、实现、QA。这个定义是故意模糊的：当你觉得*「好，这块我们做完了」*的时候，一个阶段就结束了。

**阶段边界（phase boundary）** 是两个阶段之间的间隙，也是这个决策唯一该待的地方。阶段中途没有什么可决策的：要么继续，要么把剩下的工作拆给子 agent。在阶段中途压缩，会让 agent 丢掉线索。

## 五个选项

| 选项           | 它做什么                                                        |
| ------------ | --------------------------------------------------------------- |
| **继续（Continue）** | 留在这次会话里。完全不切换上下文。                    |
| **`/clear`** | 清空上下文窗口，从零开始。                  |
| **`/handoff`** | 写一个可携带的 markdown 文件，用它把会话播种到任何地方。 |
| **子 agent（Subagent）** | 把任务送到它自己的上下文窗口，拿一份报告回来。     |
| **`/compact`** | 压缩当前上下文，用这份摘要给一个新会话播种。  |

## 决策树

在边界处自上而下走。第一个**是**获胜。

**1. 你能在这次会话里继续吗？** 两件事会让答案是「是」：下一阶段需要当前阶段作为**一手来源（primary source）**，或者你剩下的[智能区（smart zone）](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）还够下一阶段装得下。拷问 → 实现是标准的「是」：实现想要的是原原本本的推理，而不是它的摘要。继续不花代价也不丢东西，所以先把它之外的一切排除掉。

**2. 当前上下文跟接下来要做的事无关吗？** 这次会话里的一切（探索、决策、死胡同）都是可丢弃的吗？如果是，就 **`/clear`**。它是棋盘上最便宜的一步：不花时间，还把整个窗口交还给你。`/clear` 也不是终结性的：旧会话仍然可以恢复。

搞错这一步的代价是单向的。清掉一个*相关*的上下文，你就丢掉了你所构建之物背后的**为什么**，而再怎么回读那个 diff 也换不回来。

**3. 你需要交接吗？** `/handoff` 很窄。只有当你处于下列情形时才需要它：

- 切换到**新的宿主环境（harness）**（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把工作发给一位**同事**，
- 或者，把你**在阶段中途**发现的支线任务分叉出去，同时不跑偏你正在做的事。

这个清单就是全部条件。`/handoff` 买到的是**可携带性**：一个能旅行的文件。如果没有任何东西要旅行，你就不需要它。

**4. 这个任务能 AFK 完成吗？** 它的范围是不是收得足够紧，可以在你离开键盘、无人引导的情况下跑？那就把它送到一个**子 agent**，让这次会话不受打扰。自动化复查是标准情形：agent 读 diff 然后报告，它读的时候用不着你。

**5. 否则，就 `/compact`。** 相关上下文、同一个宿主环境（harness）、同一个目录，而且你需要留在回路里：这就是决策树落点所在，而且它经常落在这里。给它传一条指令（`/compact we're going to QA this area`），好让摘要保留下一阶段需要的东西。

`/compact` 是**默认项，不是第一个够到的**。它待在底部，因为排在它上面的四个问题都比它更便宜或更精确。人们从它开始时的失败模式，是得到一个对某个被摘要抹平了的决策自信地判断错误的新会话。

## 一手来源与二手来源

除了**继续**以外的每一步，都把一份**一手来源（primary source）** 变成一份**二手来源（secondary source）**：真实发生过的会话，被它的摘要取代。这笔交易形状总是一样的：

| 来源                            | 信息 | 噪音 | 腾挪空间 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续）                | 完整        | 多  | 小       |
| 二手（`/compact`、`/handoff`） | 有损       | 较少  | 大         |

这就是为什么第 1 个问题排在最前。只有当留下来的代价超过它省下的，你才付这份有损的账。

## 这些都是判断题

这些问题不是客观的：每一个里面都有品味成分，同一个边界在两天里可以给出两种答案。价值在于**按顺序**问它们，并且在边界处问，而不是在工作中途问。
