---
name: research
description: 针对高可信度的一手来源（primary sources）调研某个问题，并把发现记录成仓库里的一个 Markdown 文件。当用户想调研某个主题、收集文档或 API 事实，或者把阅读的苦力活派给一个后台 agent 时使用。
---

启动一个**后台 agent** 去做调研，这样它读它的，你继续干你的。

它的职责：

1. 针对**一手来源**（primary sources，官方文档、源代码、规格、第一方 API）调研这个问题，而不是看别人对它们的二手转述。每条论断都要回溯到拥有它的那个来源。
2. 把发现写进单个 Markdown 文件，为每条论断标注来源。
3. 存到仓库已有的存放此类笔记的地方；沿用现有约定，如果没有约定，就放到某个合理的位置并说明放在哪。
